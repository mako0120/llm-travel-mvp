# 「最大1,100%値上げ。DeepSeekのAPI料金に『ピーク時間帯制』登場。」(2026-08-17発効・2026-08-17制作)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
中国DeepSeekがV4-Pro・V4-FlashのAPI料金を改定し、ピーク/オフピーク時間帯別の料金
体系を初めて導入したという発表(2026-08-17発効)の内容を、報道されている全体
レンジ(最大1,100%)と確認できた具体的な数字を混同せず、出典付きで中立的に
整理することを軸に構成している。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠
- 2026年8月17日、DeepSeekのV4-Pro・V4-Flash API料金改定が発効(着手日と同日、
  `docs/06_Content_R&D.md`の「着手日を含めて2日以内」という鮮度基準を満たす)
- Reuters(USNews.com・Investing.com経由)・Yahoo Finance・PYMNTS・DeepSeek公式
  APIドキュメントという独立した複数の情報源で、料金・時間帯の数値が一致している
- 「最大1,100%(約12倍)」という分かりやすい数字と、開発者コミュニティへの
  直接的な影響という、インパクトのあるテーマである
  (`research/2026-08-17_theme-evaluation-round142.md`参照、スコア推定92点)

## 既存テーマとの関係(重複でないことの確認)

`ai-company-os/assets/2026-08-03_deepseek-v4-flash-pricing/` に、DeepSeek関連の
既存テーマが1件ある。

| 既存テーマ | 扱う出来事 | 本テーマとの違い |
|---|---|---|
| `2026-08-03_deepseek-v4-flash-pricing`(2026-07-31発表) | V4-Flashの公開ベータ**提供開始**と、その時点の**当初の一律料金**(入力0.14ドル・出力0.28ドル/百万トークン)の紹介 | イベントの性質が「新モデルの提供開始・当初料金の紹介」であり、値上げは扱っていない |
| 本テーマ(2026-08-17発効) | V4-Flash・V4-Proの**料金改定(値上げ)**と、初めての**ピーク/オフピーク時間帯別料金**の導入 | イベントの性質が「既存料金からの値上げ・課金体系の変更」で、対象モデル(V4-Pro含む)・時間軸ともに既存テーマの後続にあたる、明確に異なる出来事 |

**本テーマは既存テーマの内容を再掲するものではなく、その後に発生した別の出来事
(値上げ・時間帯別料金の導入)を扱うフォローアップ回であり、重複ではない。**
既存テーマが紹介した「出力0.28ドル」という当初料金は、本テーマでは「改定前の
一律料金」という起点の数字として引き継ぎ、そこからどう値上げされたかを新たに
扱っている。既存テーマディレクトリ自体は読み取りのみで一切変更していない。
詳細は`research.md`「既存テーマとの関係」を参照。

## 適用したルール

- 30枚デッキ、bullets比率30%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(big_stat、4連続以上は一度も発生しない構成、`build_deck.py`のビルド時
  検証を通過)
- palette_presetは指示通り`slate_azure`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「最大1,100%値上げ」という
  具体的な数字をフックとして即座に提示し、挨拶・前置きを省いた
- **「報道レンジ」と「確認できた具体的な数字」の明確な区別(本テーマ最重要
  ルール)**: 報道されている全体レンジ「50%〜1,100%(最大約12倍)」と、本調査
  で確認できたV4-Flash・V4-Pro出力トークンの具体的な倍率(約2.3〜4.7倍)を
  混同させず、専用スライド(19・21)と`research.md`(3章)で一貫して区別した
- **確認済み事実のみを使用**: 改定前後の料金(V4-Flash出力0.28→1.32/0.66ドル、
  V4-Pro出力0.87→3.96/1.98ドル)・ピーク時間帯(UTC 01-04・06-10時)・
  オフピーク=半額は、すべて`research/2026-08-17_theme-evaluation-round142.md`に
  記載の確認済み事実の範囲内で扱い、数字・固有名詞の創作は一切行っていない
- **不明点の正直な開示**: 値上げの公式な理由・他のDeepSeekモデル(V3系列等)
  への影響・入力トークンの具体的な価格は、複数スライド(21・26)と
  `research.md`で繰り返し「不明」と明記した
- **Anthropic/Claudeとの価格比較は不使用**: 一部報道にDeepSeekの新料金と
  Anthropic Claude 5の料金を比較する記述があるが、本パイプライン自身が
  Anthropicのモデルで稼働していることに鑑み、この比較はいずれの成果物にも
  含めていない(`research.md`・`risk-and-quality-review.md`で確認済み)
- 初心者向け前提知識スライド(API従量課金・ピーク/オフピーク料金・V4-Pro/
  V4-Flashとは何かの解説)+ 読者の立場別(開発者・企業のAI導入担当者)の
  実践的示唆(スライド22・23)
- 実在のDeepSeekのロゴ・商標・UIスクリーンショットは使用せず、テキストベースの
  図解・アイコンのみで構成した
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誤解を招く誇張は一切
  行っていない
- 政治的な評価・地政学的な論評は行っていない(DeepSeekは中国企業だが、価格
  改定という客観的な事実のみを扱う)
