伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。

8-1で破り、ベスト4進出を決めた件を、初回に長友選手の三塁打を皮切りに一挙5点を挙げた

- 対象ジャンル「国内で活躍する日本人(高校生)」枠
- 2026年8月18日、智弁和歌山が夏の甲子園準々決勝第2試合で仙台育英を8-1で下し、
  ベスト4進出を決めた(着手日2026-08-18の当日、`docs/06_Content_R&D.md`の
  「着手日を含めて2日以内」という鮮度基準を最も新しい形で満たす)
- Yahoo!ニュース(速報)・Yahoo!スポーツナビ(バーチャル高校野球)・
  ベースボールチャンネルという複数の独立したメディアが試合結果・初回の得点経過を
  一致させて報じている(`research/2026-08-18_theme-evaluation-round175.md`参照)
- 「先頭打者の三塁打から始まった初回一挙5点」という明確な展開と、「智弁和歌山の
  4強進出・仙台育英の1-8」という両校の結果を、誇張・断定なく正確に扱う強いフックが
  ある

## 適用したルール

- 30枚デッキ、bullets比率約37%(11/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成、`build_deck.py`のビルド時検証で確認)
- palette_presetは指示どおり`crimson_gold`を使用(Primary `#7A1F2B` /
  Base `#F3E3C9` / Accent `#D4A017`)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「智弁和歌山、初回5点で仙台育英を
  圧倒だって?」というフックを提示した直後に、正確な結果(準々決勝で仙台育英に8-1)を
  添え、挨拶・前置きを省いた
- **初回得点経過の正確な明示**: 長友選手の三塁打(先頭打者)・荒井選手の振り逃げに
  よる1点先制・楠本選手の犠牲フライ等による5点到達を、title/big_stat/steps/table/
  diagram/cards/bar_chartで複数回・複数形式で明示し、確認できた3つの局面を超える
  誤解を招く表現を排除した
- **未成年選手への配慮**: 出場選手が未成年であることを踏まえ、個人の私生活には
  一切踏み込まず、チーム・学校の物語として構成する専用の方針スライド(24)を
  設け、写真・肖像は一切使用しなかった
- **敗れた仙台育英側の結果の正直な扱い**: 仙台育英の1-8という敗戦の結果を隠さず・
  誇張せず正確に伝え、専用スライド(18・19・20・21)で扱った。智弁和歌山の圧勝を
  過度に煽り立てる表現も避けた
- **背景情報の節度ある扱い**: 智弁和歌山と仙台育英の対戦が2007年以来2回目とされる
  背景情報を、独自検証していない旨を明記した上でスライド22に1枚だけ簡潔に配置し、
  本テーマの主軸にはしなかった
- 初心者向け前提知識スライド(甲子園・準々決勝・振り逃げの基礎知識)+ 読者の立場別
  (高校野球ファン・勝敗両方の結果を見る立場・発信する立場)の実践的示唆(スライド25)
- 出典のない数字は作らず、確認できなかった項目(初回5点の完全な得点経過・仙台育英の
  投手交代の経緯・2回以降の試合展開・準決勝の日程対戦相手)は正直に「不明」と明記した
  (テーブル・スライド14・15・23・28)
- 誇張回避: 仙台育英の敗戦をスピンをかけず、また過度にドラマ化しない旨を専用
  スライドで明示した(スライド20・21)
