## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(3ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。最終スコアの比較はbar_chartで扱っている)。

## このデッキ固有の注意(未成年配慮と敗戦の正直な扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「初回5点で仙台育英を圧倒」
  というフックを提示しつつ、直後に正確な結果を添えている。フック性の強い表現は
  許容するが、仙台育英の敗戦を煽り立てる方向に書き換えないこと
- **スライド7〜13は初回の得点経過(長友選手の三塁打→荒井選手の振り逃げ→楠本選手の
  犠牲フライ等→5点)と最終スコア8-1を扱う核心スライド**であり、確認できた3つの局面を
  超えて個々の打者の結果を創作・追加しないこと
- **スライド14・15は2回以降の展開・仙台育英の投手交代について確認できていないことを
  示すスライド**であり、具体的な数字や経緯を創作して埋めないこと
- **スライド18〜21は仙台育英の1-8という結果を扱う核心スライド**であり、削除しない
  こと。敗戦を『隠れた勝利』として演出したり、逆に過度に悲劇的に演出したりしないこと。
  反撃が実らなかった要因を創作して埋めないこと
- **スライド22は2007年の対戦を背景情報として触れるスライド**であり、詳細を創作したり
  主題化したりしないこと
- **スライド24は未成年選手への配慮方針を扱うスライド**であり、削除しないこと。
  選手の私生活・容姿等に関する記述を追加しないこと
- **スライド23・28は確認できていないこと(2回以降の展開・投手交代・準決勝の日程)を
  示すスライド**であり、具体的な数字や詳細を創作して埋めないこと
- 実在選手名(長友選手・荒井選手・楠本選手など)はテキストとしてのみ扱い、写真・肖像・
  実在団体のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない。政治的な話題にも触れていない
