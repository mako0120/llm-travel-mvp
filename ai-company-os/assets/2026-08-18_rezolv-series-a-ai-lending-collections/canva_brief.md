## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「インドのAI与信管理スタートアップRezolv、シリーズAで1250万ドルを調達」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: フィンテック・AI業界の資金調達ニュースに関心がある
  一般視聴者。専門知識がない前提で、与信管理・債権回収・ノンバンクと
  いった用語の基礎知識から成果指標の深掘りまで丁寧に分解して説明する
  スライドを設けている
- パレット(HEX、graphite_emeraldプリセット): Primary `#1B2A2E` / Primary
  Dark `#0F1B1E` / Base `#CFE8DE` / Base Soft `#8FC2AE` / Accent `#00D2A0`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在人物の写真・肖像、Rezolv・
  Norwest・AU Small Finance Bank等の実在企業のロゴ・商標は使用しない、
  図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| steps | 番号バッジ付き横並びステップ(矢印つき) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `diagram` / `bar_chart` / `pie_chart` / `line_chart` / `quote`
は含まれない。構成比・時系列推移を表すデータや引用素材が存在しないため、
単一時点の数字は`big_stat`/`table`/`cards`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、オーナー指示(バズ
  路線への転換)に基づき「まさかの」等フック性の強い表現を用いているが、
  直後に発表日・調達額という正確な事実を添えている。フック性の強い表現は
  許容するが、回収率改善が確定・保証された効果であるかのような表現に
  書き換えないこと
- **スライド7・8・10は核心となる数字(調達額1250万ドル・調達後評価額
  5,120万ドル)を扱う核心スライド**であり、混同・省略しないこと
- **スライド12・13・14・15は事業規模を示す数字(月間650万分・1,200万件
  超・22社超)を扱う核心スライド**であり、それぞれ別の指標として区別
  すること
- **スライド16は回収・解決率35%改善を扱う核心スライド**であり、これが
  Rezolv側発表による数字であって独立した第三者機関による検証結果では
  ない旨をスライド22で必ず補足すること
- **スライド21は調達額と評価額を明確に区別するスライド**であり、
  削除・混同しないこと
- **スライド19・20はAI技術詳細・国外展開計画が不明であることを示す
  スライド**であり、具体的な技術名・地域名を創作・推測で補わないこと
- **スライド23は見出しの印象(与信管理の課題が全て解決)と実際に確認
  できている内容のギャップを示すスライド**であり、削除しないこと
- Rezolv・Norwest・AU Small Finance Bank等の実在企業のロゴ・商標は
  使用しない
- Rezolvの製品は事実として紹介するのみで、利用を推奨する表現に書き
  換えない(スライド26)

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`graphite_emerald`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
