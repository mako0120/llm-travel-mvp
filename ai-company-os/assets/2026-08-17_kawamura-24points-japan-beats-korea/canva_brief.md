Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は

移植仕様書(ブリーフ)である。

- デッキ名: 「エースが休んでも、日本は勝った――河村勇輝24得点、日本代表が韓国に
  95-66で快勝」

  専門知識がない前提で、選手・大会形式の基礎知識から数字の深掘りまで丁寧に
  分解して説明するスライドを設けている
- パレット(HEX、cobalt_violetプリセット): Primary `#1B3A5C` / Primary Dark

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。前半・最終スコアの比較はbar_chartで
扱っている)。

## このデッキ固有の注意(数字の正確さと欠場理由の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「河村勇輝、24得点だって?」
  というフックを提示しつつ、直後に「八村塁選手は欠場でした」と正確な事実を添えて
  いる。フック性の強い表現は許容するが、八村選手の欠場を大げさな事件のように
  書き換えないこと
- **スライド10・12・13は河村選手のスタッツ(24得点・3P4本・6リバウンド・
  3アシスト)を扱う核心スライド**であり、数字を混同・省略・丸めないこと
- **スライド6・16・23は『コンディション調整』という欠場理由を正確に扱う
  スライド**であり、怪我等の未確認情報を書き加えないこと
- **スライド17・24・25は『2連勝』の1戦目の詳細・河村選手の今大会通算成績・
  次戦の日程が未確認であることを示すスライド**であり、具体的な数字や日程を
  創作して埋めないこと
- **スライド23は見出しの印象(怪我等の誤解)と実際の内容のギャップを示す
  スライド**であり、削除しないこと
- **スライド18は誇張回避を明示するスライド**であり、削除しないこと
- 実在選手名(河村勇輝選手・八村塁選手)はテキストとしてのみ扱い、写真・肖像・
  実在団体(NBA・LAクリッパーズ・日本バスケットボール協会等)のロゴ・商標は
  使用しない
- 特定企業・製品・団体の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`cobalt_violet`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
