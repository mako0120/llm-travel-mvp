## 見出し表現の方針についての正直な開示

見出し・タイトルの表現は「バズる人気」優先の意外性を強調した表現にしている
(例: 「10億台のAIエージェントを誰が守るのか。SoftBank・日立・LGが1.25億ドルを
賭けた企業」)。**ただし、数字の創作・出典のない断定・特定企業の過度な推奨・

## 適用したルール

- 30枚デッキ、bullets比率27%(40%上限クリア)、同一レイアウト連続なし
- **コールドオープン(バズ路線)**: 冒頭(1枚目・ナレーション1行目)で「10億台の
  AIエージェントを、誰が守るのか。SoftBank・日立・LGが、1.25億ドルを賭けました」
  という意外性を強調した一文を即座に提示
- **鮮度の高さの積極的な開示**: 発表から1日しか経過していない点を専用スライド
  (18)で明示している
- 初心者向け前提知識スライド(AIエージェントセキュリティとは) + 実践的な整理
  (調達概要・創業チームの経歴・投資家陣容)
- 特定企業・特定製品の利用を強く推奨する結論にはしていない
