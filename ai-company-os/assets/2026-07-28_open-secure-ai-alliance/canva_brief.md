## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| quote | 引用レイアウト(帰属を明記) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(4ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

## このデッキ固有の注意

- **スライド12の`big_stat`は「数十社」という文字を大きく見せる**(数字ではない)。
  情報源により27〜40社超と食い違うため、あえて確定数を出していない。Canvaへ
  移植する際も、具体的な数字に置き換えないこと
- スライド13の表は「情報源ごとに数字が違う」ことを見せるのが目的であり、
  どれか1つを強調表示しない
- スライド16の`quote`は、英語報道の主張を日本語に要約したものである旨を
  帰属テキストに必ず残すこと

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
