## 適用したルール

- 30枚デッキ、bullets比率20.0%(40%上限クリア)、同一レイアウト連続は最大2
- 文字中心の説明はtable/diagram/comparison/steps/quoteで図解・引用化
- **コールドオープン**: 冒頭(1枚目・ナレーション1行目)で時系列のインパクト
  (「AIが他社を攻撃した数日後」)を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド2枚(AIエージェント/サンドボックス、
  オープンウェイト/Apache 2.0) + 実践手順・「これで何が変わるか」セクション
- **因果関係を断定しない**: Hugging Face攻撃事件と連合発足の関係は「時系列が
  近い」事実のみを述べ、断定を避けた旨をスライド9・27で明示
- 一方的にオープン路線を称賛せず、閉じたAPIの利点も併記(スライド24)
- 進捗バー・カード影・タイトルアクセントの視覚強化(`docs/04_PowerPoint.md`参照)
- 前サイクルとの接続スライドは設けていない
