## タイトル案(A/Bテスト用。オーナー指示によりフック性重視の表現を許容。ただし数字・事実の誇張・捏造は行わず、「発表日」と「終了日」を混同させる表現は使わない)

1. Imagen 4 API、本日終了――generate_images()はもう動かない
2. Googleが2ヶ月前に予告した終了が、今日きた。Imagen 4 API終了の中身
3. generate_images()が消える日。Imagen 4から移行先まで出典付きで整理

## 概要欄(description)案

```
Googleが2026年6月15日に非推奨化を発表していたImagen 4(標準・Ultra・Fast)の
3つのGAモデルIDが、本日2026年8月17日にシャットダウンしました。generate_images()
というメソッドは廃止され、テキスト生成と同じgenerate_content()を使う方式に統一
されます。

具体的には、
・終了する3つのモデルID(imagen-4.0-generate-001・imagen-4.0-ultra-generate-001・
  imagen-4.0-fast-generate-001)
・technical変更点(generate_images()廃止、ImagenGenerationConfig→GenerationConfig、
  number_of_imagesの見直し)
・推奨される移行先モデル(gemini-3.1-flash-image)と、暫定的に案内されている
  gemini-2.5-flash-imageの違い
・開発者・企業のAI導入担当者にとって何が変わるか

を、Google公式ドキュメントを中心とした出典付きで整理して紹介します。

本動画で特に大切にしているのは、**「非推奨化の発表日(2026年6月15日)」と
「実際のシャットダウン日(2026年8月17日・本日)」を混同しない**ことです。
本テーマの鮮度・フックは、あくまで「本日終了した」という事実に基づいています。

なお、移行が実際に間に合わなかった具体的な企業名・サービス名は本調査の範囲では
確認できておらず、正直に「不明」として扱っています。Google・Geminiという企業・
製品を推奨する意図はなく、報じられたAPI仕様変更を中立的に紹介する動画です。
実在のロゴ・商標は使用せず、テキストベースの図解のみで構成しています。

■ 主な出典
- Google公式ドキュメント「Gemini API Deprecations」(ai.google.dev/gemini-api/docs/deprecations)
- Firebase AI Logic移行ガイド(firebase.google.com/docs/ai-logic/imagen-models-migration)
- kingy.ai・byteiota.com(開発者向けメディア)

※ 本動画はAPI仕様変更の紹介であり、Google・Geminiの利用を推奨・非推奨いずれの
  立場も取っていません。
```
