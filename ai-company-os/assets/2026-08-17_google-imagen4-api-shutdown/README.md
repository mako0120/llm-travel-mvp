# 「Imagen 4 API、本日終了。generate_images()はもう動かない。」(発表2026-06-15・終了2026-08-17・2026-08-17制作)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
Googleが2026年6月15日に非推奨化を発表していたImagen 4(標準・Ultra・Fast)の
3つのGAモデルIDが、本日2026年8月17日にシャットダウンし、`generate_images()`メソッドが
使えなくなったという事実を、「発表日」と「終了日」の違いを明確に区別しながら、出典付きで
中立的に整理することを軸に構成している。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠
- シャットダウン日(2026年8月17日)が着手日と同日(`docs/06_Content_R&D.md`の
  「着手日を含めて2日以内」という鮮度基準を満たす)
- Google公式ドキュメント(ai.google.dev/gemini-api/docs/deprecations)・Firebase AI
  Logic移行ガイドという一次情報に加え、複数の開発者向けメディアが一致して報じている
- 既存コードが警告ではなくエラーで停止するという、開発者への直接的な実務インパクトが
  あるテーマである(`research/2026-08-17_theme-evaluation-round148.md`参照、
  スコア推定91点)

## 重複チェック

`ai-company-os/assets/`ディレクトリ全体を確認し、Imagen・画像生成モデル終了関連の
既存テーマディレクトリは存在しないことを確認した(重複なし)。

## 適用したルール

- 30枚デッキ、bullets比率37%(11/30枚、40%上限クリア)、同一レイアウト連続は
  最大2(4連続以上は一度も発生しない構成、`build_deck.py`のビルド時検証を通過)
- palette_presetは指示通り`steel_amber`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「本日終了」という事実をフックとして
  即座に提示し、挨拶・前置きを省いた
- **「発表日」と「シャットダウン日」の明確な区別(本テーマ最重要ルール)**: 非推奨化の
  発表(2026年6月15日)と、実際のシャットダウン(2026年8月17日・本日)を混同させず、
  専用スライド(5・8・11)と`research.md`(0章)で一貫して区別した。発表自体が
  本日の新しい出来事であるかのような誤解を招く表現は使っていない
- **確認済み事実のみを使用**: 終了する3モデルID(imagen-4.0-generate-001・
  imagen-4.0-ultra-generate-001・imagen-4.0-fast-generate-001)・技術的変更点
  (generate_images()廃止、GenerationConfig、number_of_images見直し)・移行先
  (gemini-3.1-flash-image推奨、gemini-2.5-flash-image暫定)は、すべて
  `research/2026-08-17_theme-evaluation-round148.md`に記載の確認済み事実の範囲内で
  扱い、数字・固有名詞の創作は一切行っていない
- **不明点の正直な開示**: 移行が間に合わなかった具体的な実例(企業名・サービス名)は
  一切創作・名指ししておらず、「開発チームが移行を終えていなければ、本日からエラーが
  発生する」という一般論の範囲にとどめた(複数スライド24、`research.md`5章)
- 初心者向け前提知識スライド(API非推奨化・シャットダウンの違い、Imagen 4・
  generate_images()とは何かの解説)+ 読者の立場別(開発者・企業のAI導入担当者)の
  実践的示唆・移行チェックリスト(スライド20・21・22)
- 実在のGoogle・Geminiのロゴ・商標・UIスクリーンショットは使用せず、テキストベースの
  図解・アイコンのみで構成した
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誤解を招く誇張は一切
  行っていない
- 政治的な評価・論評は行っていない。Google・Geminiという企業・製品への過度な
  推奨は行わず、開発者への実務的な注意喚起として中立的に扱った
