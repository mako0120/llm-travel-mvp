## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない
  (推移データが限られるため数字は`big_stat`と`table`で扱い、実在人物への
  直接取材コメントが確認できなかったため`quote`は使用していない)。

## このデッキ固有の注意

- **スライド1・2・10・29の罰則数字($5,000/違反1件・1日)は本テーマの中心
  となる数字**である。「累積方式」であることを必ず併記すること
- **スライド12・13・14はMidjourneyに関する記述であり、TechTimesの単一情報源に
  基づく報道であることを必ず明示**すること。断定的な見出し・キャプションに
  書き換えないこと
- **スライド16は「EU AI Act(66本目)との比較」**であり、削除しないこと
- **スライド21は「確認できなかったこと」の一覧**であり、保持すること
- **スライド25・26は当社の推測・一般的な整理**であることを本文に明記している。
  断定形や法的助言のように書き換えないこと
- 実在企業名(Midjourney等)はテキストとしてのみ扱い、ロゴ・商標は使用しない
- カリフォルニア州・EUという公的機関の名称は事実として扱うが、政治的な評価
  コメント(規制への賛否等)は追加しないこと
- 特定企業・製品の利用を強く推奨する結論にはしていない
