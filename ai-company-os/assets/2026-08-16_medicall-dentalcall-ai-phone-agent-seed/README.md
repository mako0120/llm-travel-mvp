# 「韓国Medicall、歯科医院向けAI電話エージェント『DentalCall』でシード資金調達(金額非公開)」(2026-08-14報道・2026-08-16・round137 本日1本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
定期実行パイプラインround137の1本目。調達金額が非公開であることを、一貫して正直に
明記することを特に重視している。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠(ヘルスケア×AIエージェント)
- 2026年8月14日、韓国のスタートアップMedicallが、歯科医院向けAI電話エージェント
  「DentalCall」のシード資金調達を実施したと報じられた(着手日2026-08-16の2日前、
  `docs/06_Content_R&D.md`の「着手日を含めて2日以内」という鮮度基準を満たす)
- WOWTALE・Dealroom.coという、独立した複数の情報源が一致して報道しており、
  `docs/06_Content_R&D.md`モードB(バイラル優先モード)の基準を満たす
- 「歯科医院の電話にAIが24時間出る」という具体的で分かりやすいユースケース、
  韓国国内より先にタイ・フィリピンで有料顧客を獲得しているという意外性がフックになる
  (`research/2026-08-16_theme-evaluation-round137.md`参照)

## 適用したルール

- 30枚デッキ、bullets比率30%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大2(4連続以上は一度も発生しない構成、`build_deck.py`検証合格)
- palette_presetは指示どおり`steel_amber`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「歯科医院の電話にAIが24時間出る」
  というフックを即座に提示し、挨拶・前置きを省いた
- **金額非公開の明記**: タイトル・結論スライド(1・2)、資金調達の核心スライド
  (13・14)、扱い方スライド(22・25・27)で、一貫して「非公開」「不明」という
  表現を用い、架空の調達額・評価額を一切書いていない
- 初心者向け前提知識スライド(Medicallとは・DentalCallの仕組み図・「AI電話エージェント」
  「アウトバウンド患者管理」の用語解説)+ 読者の立場別(クリニック経営者・医療AI導入
  検討者・投資動向を追う立場)の実践的示唆(スライド21)
- DentalCallの機能(受電対応4項目・アウトバウンド患者管理3項目)、Medicallのビジョン
  (4エージェント連携)を`cards`/`diagram`で視覚化し、単なる文字の羅列にしない。
  調達金額・評価額が非公開のため時系列の定量データがなく、`bar_chart`/`line_chart`は
  使用していない(架空の数字でグラフ化することを避けた)
- 出典のない数字は作らず、確認できなかったこと(調達金額・評価額・創業時期・正社員数・
  過去の調達履歴・競合との定量比較・韓国国内の導入クリニック数)は正直に「不明」として
  一覧化した(スライド24・25)
- 同時期に資金調達した別会社(Salm Clinic・Allconnec)とMedicallを混同しないよう、
  専用スライド(23)で明示した
- 業界の一般的な文脈の整理(スライド11・19)と、出典付きの確認済み事実を明確に分けて
  表記した
- 特定企業・製品の利用を強く推奨する結論にはしていない
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張は一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- `build_deck.py`のビルド時検証(同一レイアウト4連続以上チェック・bullets比率40%以下
  チェック=30%) → 合格
- `generate_dialogue_script.py --deck deck_spec.json` によるスライド数一致・
  スライド連番検証 → 合格(30スライド全カバー)
- 著作権・品質自己評価: 94点/100点(85点以上のため修正不要)

- 調達金額は一貫して「非公開」と明記し、架空の数字を一切使用していない
- 評価額についても「不明」と明記し、推測での言及を行っていない
- Medicall・DentalCall・歯科AI電話エージェント全般への政治的評価(良い/悪いの
  価値判断)は一切行っていない

  ギャップを明示している
- 確認できなかった項目(調達金額・評価額・創業時期・正社員数・過去の調達履歴・競合との
  定量比較・韓国国内の導入クリニック数)を一覧化し、正直に「不明」として扱っている
- 同時期に資金調達した別会社(Salm Clinic・Allconnec)とMedicallの数字を混同しないよう
  明示している
- 実在企業名(Medicall・DentalCall・AI Angel Club等)はテキストとしてのみ扱い、ロゴ・
