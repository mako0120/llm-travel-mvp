  (アナハイム/エンゼルスタジアム)で、山本由伸投手が中7日で今シーズン23度目の
  先発として登板。4回2/3を投げて99球、6安打・6四死球を許し、メジャー移籍後
  ワーストとなる6失点を記録した。試合はエンゼルスが7-4でドジャースを下して
  勝利し、山本投手は今シーズン8敗目(通算10勝)を喫した
- 出典: 日刊ゲンダイDIGITAL「山本由伸は佐々木朗希を"踏み台"に12勝目へ…翌日登板で
  際立つエースの修正力」、MLB.com「yoshinobu yamamoto post game q and a 8th loss」
  「yoshinobu yamamoto 8th loss vs angels」
- **鮮度基準について正直な開示: 登板日(2026年8月11日)は着手日(2026年8月12日)
  から1日前。** `docs/06_Content_R&D.md`の鮮度基準(着手日を含めて2日以内)を
  満たしており、例外的な妥協採用ではない
- 本テーマは185本目であり、本日(2026年8月12日)の制作本数は12本目にあたる。

## トーンへの配慮(必須遵守事項・最重要)

本テーマは選手個人の不振・失敗を扱う内容であるため、以下を必ず徹底しました。

1. 揶揄・嘲笑的な表現は一切使わない
2. 客観的な記録(投球回・失点数・与四死球数等)を淡々と報告する構成にする
3. エースクラスの投手であっても好不調の波があるという野球競技の一般的な性質を
   説明し、選手への敬意を保った扱いとする(スライド17・18)
4. 「終わった」「限界」等の断定的なネガティブ表現は避け、あくまで一試合の結果
   として扱う

この方針は、専用スライド(19「【重要】トーンへの配慮についての開示」)、
`youtube_assets.md`のリスク配慮欄、`canva_brief.md`の「このデッキ固有の注意」、
`risk-and-quality-review.md`の全ファイルで一貫して明記しています。

## バズ路線の見出し方針

視聴者数を稼げる「バズる人気」路線を優先しつつ、選手を貶めるような煽り表現は
避けました。タイトル「エースにも、こんな日がある。」は、事実を伝えつつ敬意を
保った表現の例として採用したものです。数字の創作・出典のない断定・確認できな
かったことの断定的記述・政治的中立性の逸脱・著作権侵害はいずれも行っていません
(実在選手名は事実として扱うが写真・肖像は使用していません)。

## 適用したルール

- 30枚デッキ、bullets比率33.3%(10/30、40%上限クリア)、同一レイアウト連続は最大3
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_statで図解化
  (選手本人のコメントが確認できなかったため`quote`は使用せず)
- **コールドオープン(バズ路線)**: 冒頭(1枚目・ナレーション1行目)で
  「4回2/3、99球、6失点。」という出典に基づく具体的な数字を即座に提示し、
  挨拶・前置きを省いた
- **初心者向け前提知識スライド**: 「登板成績」の見方(スライド7)、「勝敗」の
  つき方(スライド8)を、野球のルールに不慣れな視聴者向けに平易な言葉で説明
- **これで何が変わるか(視聴者にとっての意味)**: スライド20で扱う
- **既存テーマとの関係を明示**: スライド5・26(comparison/tableレイアウト)で扱う
- **確定事実・不明点を明確に区別**(前節参照、スライド23・24が該当)
- 選手個人の不振を扱うことについて、専用スライド(17・18・19)でトーンへの
  配慮方針を明記
