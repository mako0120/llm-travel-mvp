## メタ情報

- デッキ名: 3Dモデルが1分で作れる時代に、過去最大の資金が入った(定期実行49本目)
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 3D制作に関わる、または関心のある一般視聴者向け。3Dに馴染みの
  ない初心者にも分かるよう、前提知識スライドを2枚設けている
- パレット(HEX、slate_azureプリセット): Primary `#2B3A55` / Base `#D3E4F5` / Accent `#1F8FD6`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在企業のロゴ・実在人物の肖像は使用しない、
  図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| quote | 引用レイアウト(帰属を明記) |
| bar_chart | 棒グラフ(Canvaのグラフ要素、数値は`deck_spec.json`参照) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(4ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

## このデッキ固有の注意

- **スライド15の`quote`は企業側の主張**である。帰属テキスト「Meshy社の説明(報道より
  要約)。第三者による検証結果ではない」を必ず残すこと。ここを削ると宣伝文句を
  事実として提示することになる
- **スライド11の`bar_chart`は単位が異なる2項目**(万人 / 百万件)を並べている。
  棒の高さの直接比較として見せないよう、ノートの注意書きを移植時も保持すること
- スライド28で「発表日が制作日から7日前」であることを明示している。鮮度の開示なので
  削除しないこと

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
