## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| quote | 引用レイアウト(引用元を帰属に明記) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(推移データ・
  構成比のデータが無かったため、数字は `big_stat` と `table` で扱っている)。

## このデッキ固有の注意

- **スライド7・15・16の「500件超」「60,000社超」「800万社超」は本テーマの
  中心となる数字**である。スライド17で3つの数字の関係(500件超が800万社の
  うちどれだけの割合かは不明)を明記していること
- **スライド19の`quote`はCEO Brendan King氏のコメントを複数媒体経由で
  引用**している。帰属テキストを必ず残すこと
- **スライド4・21は「今回の報道がプレスリリース配信中心で独立取材の裏取りが
  まだない」という正直な開示**であり、削除しないこと
- **スライド22は「Vendasta自体の日本国内の展開は不明」という開示**であり、
  保持すること
- スライド28は推測であることを本文に明記している。断定形に書き換えないこと
- 実在企業名(Vendasta)はテキストとしてのみ扱い、ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない。移植時も断定的な推奨
  文言を追加しないこと
