## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `steps` / `line_chart` / `pie_chart` / `quote` は含まれない
  (段階的な導入手順は具体的な確認情報がなく`steps`として提示していない。推移データは
  Intelligence Indexスコアの2点比較のみで`bar_chart`が最適。構成比を示すデータは
  扱っていない。出典で直接確認できたコメントの原文がなく、要旨を作文しない方針のため
  `quote`レイアウトは使用していない)。

## このデッキ固有の注意

- **スライド1・2は本テーマのコールドオープン(「出力速度最大4倍」)** である。
  性能面の断定表現に書き換えないこと
- **スライド6・8はキーワード「AIエージェント」「MoE」を説明するスライド**である。
  具体的な内部実装は未確認であるため、確定した仕組みであるかのような表現に
  書き換えないこと
- **スライド10・13は前モデルNemotron 3 Nanoのスコア「15」を扱うスライド**である。
  この数字は公表された2数値(現行スコア24、向上幅9ポイント)からの単純計算による
  推測値であり、NVIDIA公式が直接明言した数字ではないという注記を削除しないこと
- **スライド11・12は「同クラス製品と比較して」という報道表現を扱うスライド**であり、
  比較対象の具体的な競合モデル名は不明であることを保持したまま、勝手に競合モデル名を
  補って書き換えないこと
- **スライド24・25は「確認できていないこと」の一覧**であり、削除しないこと
- **スライド22は見出しの印象と実際の内容のギャップを示す核心スライド**である。
  「大規模な企業導入がすでに進んでいる」等の誇張表現に書き換えないこと
- 実在企業名(NVIDIA、Hugging Face、OpenRouter等)はテキストとしてのみ扱い、
  ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`cobalt_violet`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
