  ニュースを継続して追っている視聴者(既存の「tokenmaxxing」2テーマの視聴者を含む)。
  専門知識がない前提で、「tokenmaxxing」という用語を分解して説明するスライドを設けている

- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(Uber・Anthropicの公式ロゴ・商標は使用しない、

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |

| comparison | 2カラム比較(左右カード+リスト) |

| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(コスト下落率や
  利用者数推移の定量的な時系列データが公表されておらず、確認できない数値をグラフ化
  しないため)。引用は`quote`レイアウト(スライド7・16)でNaga氏の発言をそのまま扱う。

## このデッキ固有の注意

- **スライド13は「4倍」という数字がUber側の自己申告であることを明示**している。
  第三者検証済みの数字であるかのように書き換えないこと
- **スライド17は「確認できなかったこと」の一覧**であり、削除しないこと(予算の具体的な
  金額・傾向の定量数値・次の段階の制度・業界全体への波及を非公開として明示している)
- **スライド18・19は既存2つの「tokenmaxxing」テーマ(127本目Weave・142本目Microsoft)との
  関係を整理する回**である。3件目のテーマであることを隠さず、主体・立場の違いを明示する
  内容のため、削除・簡略化しないこと
- **スライド24は誇張回避・特定企業推奨回避についての注記**である。タイトル・冒頭フックは
  注目を集める表現を使っているが、本文の内容は誇張しておらず、Uber・Anthropicいずれの
  利用も強く推奨していない旨を明示しているため、この注記スライドは保持すること
- **スライド25は当社の推測であることを明記した概念図**である。断定形や公式見通しの
  ように書き換えないこと
- 実在企業名(Uber、Anthropic)・実在人物名(Praveen Neppalli Naga氏)はテキストとしてのみ
  扱い、ロゴ・商標・肖像は使用しない
- Naga氏の引用(スライド7・16)は複数の独立メディアで文言が一致していることを確認した
  ものであり、要約による意味の変質を避けるため原文をそのまま使うこと

## 移植手順(人間向け)

   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
