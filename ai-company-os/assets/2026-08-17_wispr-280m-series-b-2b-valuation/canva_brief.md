## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「音声AI企業Wispr、まさかの評価額20億ドルに――2億8000万ドルの新規調達」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI・スタートアップ業界の資金調達ニュースに関心がある一般視聴者。
  専門知識がない前提で、シリーズB・評価額・音声入力AIといった用語の基礎知識から
  数字の深掘りまで丁寧に分解して説明するスライドを設けている
- パレット(HEX、graphite_emeraldプリセット): Primary `#1B2A2E` / Primary Dark
  `#0F1B1E` / Base `#CFE8DE` / Base Soft `#8FC2AE` / Accent `#00D2A0`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在人物の写真・肖像、Wispr・Menlo
  Ventures等の実在企業のロゴ・商標は使用しない、図形・アイコンはCanva内蔵の
  無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `steps` / `quote` は
含まれない。過去ラウンドの評価額が確認できておらず、推移として表せる2点以上の
数値データが存在しないため、グラフ化による誤解(推移があったかのような印象)を
避け、単一時点の数字は`big_stat`/`cards`/`table`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「まさかの評価額20億ドル」
  というフックを提示しつつ、直後に発表日・調達額という正確な事実を添えている。
  フック性の強い表現は許容するが、事業の収益性を保証するような表現に書き換え
  ないこと
- **スライド7・8・16・17・21は核心となる数字(調達額2億8000万ドル・評価額
  20億ドル・利用者数百万人・利用企業12万5000社以上・誤認識率30%→10%未満)を
  扱う核心スライド**であり、数字を混同・省略・丸めないこと
- **スライド13は過去ラウンドの評価額が不明である旨を扱うスライド**であり、
  「何倍に拡大したか」という変化率を創作して埋めないこと(このデッキでは一切
  使用していない表現である)
- **スライド22・26は『Canto』の技術詳細・次回調達計画が不明であることを示す
  スライド**であり、具体的な内容を創作しないこと
- **スライド23は見出しの印象(評価額20億ドル=完全に成功)と実際に確認できている
  内容のギャップを示すスライド**であり、削除しないこと
- **スライド25は誇張回避・確認ポイントを明示するスライド**であり、削除しないこと
- Wispr・Menlo Ventures等の実在企業のロゴ・商標は使用しない
- Wisprの製品(Wispr Flow・Canto)は事実として紹介するのみで、利用を推奨する
  表現に書き換えない(スライド5・24)

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`graphite_emerald`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
