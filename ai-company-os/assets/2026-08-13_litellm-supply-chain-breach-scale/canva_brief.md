## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| comparison | 2カラム比較(左右カード+リスト) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| steps | 横並びステップカード+シェブロン矢印 |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| table | 表(ヘッダー行+データ行) |
| quote | 引用スライド(大きめの引用符+出典表記) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(時系列・比較は
  `steps`・`comparison`・`table`・`big_stat`で表現しており、数値推移や構成比を示す
  グラフ化対象のデータセットは扱っていないため)。

## このデッキ固有の注意(サプライチェーン攻撃テーマ特有の配慮を含む)

- **スライド1はコールドオープン**(「2,500社以上、43万4,000のCI/CDパイプライン。
  静かな侵入は、5カ月前からそこにあった」)。フッターに攻撃発生日(3月)と
  レポート公開日(8月11日)が別であることを明記しており、この注記を削除しないこと
- **スライド4は攻撃発生日とレポート公開日を区別する核心スライド**であり、削除・
  簡略化しないこと。左カラム(攻撃そのもの、2026年3月)と右カラム(規模を暴いた
  レポート、2026年8月11日)の対応を崩さないこと
- **スライド15・16は組織名を扱うスライド**であり、NVIDIA・AWS・Cisco Systems・
  Salesforce・Siemens AG・X Corp・Orange S.A.はいずれも「高確度で影響を受けた
  可能性がある」という位置づけで事実紹介にとどめる。実際に被害を受けたと断定する
  表現・企業への批判的な表現に書き換えないこと
- **スライド17・29は引用スライド**であり、CloudSEKレポート原文の直接引用ではなく
  「趣旨の紹介(意訳)」であることを示す出典表記を保持すること
- **スライド22・23・24は「確認できていないこと」の一覧・注意点スライド**であり、
  削除しないこと。「2,500社以上」を実害の確定情報であるかのように書き換えないこと
- **スライド25は慎重な見方を示すスライド**(CloudSEKは民間企業であり第三者検証を
  経ていない旨)であり、削除しないこと
- **スライド26・27は「推測」であることを明示するカード・ステップ**であり、断定的な
  予測に書き換えないこと
- 実在企業名・組織名(NVIDIA、AWS、Cisco Systems等)はテキストとしてのみ扱い、
  ロゴ・商標・実在人物の肖像は使用しない
- 特定のセキュリティ製品・対策サービスの利用を強く推奨する結論にはしていない
