Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「30億ダウンロード。AlibabaのQwenが、Meta・Googleを追い抜いた。」
  (本日5本目)
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI・生成AIに関心がある一般視聴者、オープンウェイトモデルの
  動向を追っている開発者・企業のAI導入担当者。専門知識がない前提で、オープン
  ウェイトモデルや「ダウンロード数」という指標の性質を分解して説明するスライドを
  設けている
- パレット(HEX、indigo_cyanプリセット): Primary `#2E2A72` / Primary Dark `#1B1846` /
  Base `#D6D9F5` / Base Soft `#A9AEE0` / Accent `#17C3B2`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在のAlibaba/Qwen・Meta/Google等の
  ロゴ・商標・UIスクリーンショットは使用しない、図形・アイコンはCanva内蔵の
  無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `quote` は含まれない(推移データ・
構成比を示す確認済みの数字や、公式コメントの直接引用がないため)。

## このデッキ固有の注意(誤解を招かない扱いが最重要)

- **スライド1・2は本テーマのコールドオープン(「30億ダウンロード」という具体的な
  数字)**である。フック性の強い表現は許容するが、「Qwenが世界一のAIになった」等、
  性能・利用者数の優劣を断定する誤解を招く書き換えはしないこと
- **スライド5・8は2つの日付(Hugging Face 8/14公開・Bloomberg 8/15報道)を区別する
  核心スライド**である。日付を入れ替えたり、Bloombergがレポート自体を発表したかの
  ような書き換えはしないこと
- **スライド9・10は初心者向けの前提知識(オープンウェイトモデル・ダウンロード数
  という指標の性質)**であり、専門用語をそのまま使わずに平易な説明を保つこと
- **スライド12〜17は3社(Qwen/Google/Meta)の数字比較の核心スライド**である。
  数値(30億超・4億1,800万・2億2,700万)や集計期間(過去6か月/2026年)を
  誤って書き換えないこと
- **スライド19・27は「確認できていないこと」の一覧**であり、削除しないこと。
  集計方法・定義の同一性を確定情報であるかのように書き換えないこと
- **スライド24・25は見出しの印象と実際の内容のギャップを示すスライド**であり、
  削除しないこと
- **スライド26は中立性(政治的な評価・優劣の論評を行わない)を明示するスライド**
  であり、削除しないこと
- 実在の「Alibaba」「Qwen」「Meta」「Google」の名称はテキストとしてのみ扱い、
  公式ロゴ・商標・UIスクリーンショットは使用しない
- 特定企業・製品の宣伝にはしていない
