# 「AIが『専門家1人』の知見だけを教える――LINEヤフー『エキスパートAI』、第1弾はふらお氏のレシピAI」(2026-08-17発表・2026-08-18制作)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
LINEヤフーが2026年8月17日、AIエージェント「Agent i」内に新機能カテゴリ
「エキスパートAI」の提供を開始した件を、開放的なWeb全体を平均化した回答ではなく
特定の実名専門家1人の知見だけに基づいて回答するという設計思想を軸に、第1弾である
料理研究家「ふらお」氏の「ふらおレシピ」の内容を正確に扱いながら構成している。

## 選定理由

- 対象ジャンル「AI/エージェント」枠
- 2026年8月17日、LINEヤフーがAIエージェント「Agent i」内に新機能カテゴリ
  「エキスパートAI」の提供を開始し、第1弾として料理研究家「ふらお」氏本人が
  知見の活用を承認・設計に協力した「ふらおレシピ」を発表した(着手日2026-08-18の
  前日、`docs/06_Content_R&D.md`の「着手日を含めて2日以内」という鮮度基準を満たす)
- LINEヤフー株式会社公式プレスリリース(PR TIMES/lycorp.co.jp)・Impress Watch・
  Yahoo!ニュース(Impress Watch配信)・TechTimes・VOIXという5つの独立した情報源
  (うち1件は企業自身の公式発表)が内容を一致させて報じている
- 「Web全体の平均ではなく実名専門家1人の知見だけに基づくAI」という他のAIエージェント
  との明確な差別化と、専門家本人が承認・協力したという著作権・同意面での安心感の
  あるフックがある(`research/2026-08-18_theme-evaluation-round171.md`参照)

## 適用したルール

- 30枚デッキ、bullets比率33.3%(10/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成)
- palette_presetは指示どおり`cobalt_violet`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「専門家1人の知見だけに基づく
  AIだって?」というフックを提示した直後に「LINEヤフーが8月17日に発表した」という
  正確な事実を添え、挨拶・前置きを省いた
- **設計思想の正確な明示(本テーマの核心)**: 「開放的なWeb全体を平均化した回答
  ではなく、特定の実名専門家1人が公開した知見だけに基づいて回答する」という
  エキスパートAIの定義を、title/big_stat/bullets/comparison/diagramで複数回・
  複数形式で明示し、誤解を招く表現を排除した
- **ふらお氏の関与の正確な扱い**: 知見の活用を承認し設計にも協力したという
  確認済みの事実のみを扱い、報酬・契約条件等の未確認情報を付け加えない旨を
  専用スライド(16・24・25・26)で明示した
- 初心者向け前提知識スライド(AIエージェント・Agent i・エキスパートAIの用語解説)
  + 読者の立場別(料理に関心がある人・情報の受け手・発信する立場)の実践的
  示唆(スライド22)
- 出典のない数字は作らず、確認できなかった項目(カテゴリの拡大予定・ふらお氏の
  報酬契約条件・提供終了日以降の扱い・利用実績の数字)は正直に「不明」と
  明記した(テーブル・スライド18・21・24・25・26)
- 誇張回避: 提供期間の日数(約45日間)が2つの確定日付からの計算値であることを
  明示し、出典が直接述べた数字であるかのように扱わない旨を専用スライドで
  明示した(スライド28)
- 見出しの印象(大規模展開・高額報酬の誤解)と実際の内容(第1弾1件のみ確認、
  条件詳細は未確認)のギャップを専用スライドで明示した(スライド27)
- 実在人物(ふらお氏)の写真・肖像は使用せず、抽象的な図解・アイコンのみで
  構成した。氏名と本人が知見の活用を承認・設計協力した事実は出典どおり正確に
  伝えた
- 特定企業・製品(LINEヤフー)の利用を強く推奨する結論にはせず、中立的な事実
  紹介にとどめる旨を専用スライドで明示した(スライド23)
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張は一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- 同一レイアウト4連続以上チェック・bullets比率40%以下チェック(33.3%) →
  合格(`build_deck.py`のビルド時検証を通過)
- `generate_dialogue_script.py --deck deck_spec.json` によるスライド数一致・
  スライド連番検証 → 合格(30スライド全カバー)
- 著作権・品質自己評価: 97点/100点(85点以上のため修正不要)
