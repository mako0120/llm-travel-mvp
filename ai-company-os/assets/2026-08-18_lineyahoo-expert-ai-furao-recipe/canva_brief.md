- デッキ名: 「AIが『専門家1人』の知見だけを教える――LINEヤフー『エキスパートAI』、
  第1弾はふらお氏のレシピAI」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AIエージェント・生成AIの新機能に関心がある一般視聴者。専門知識
  がない前提で、「AIエージェント」「エキスパートAI」といった用語の基礎知識から
  提供概要の数字まで丁寧に分解して説明するスライドを設けている
- パレット(HEX、cobalt_violetプリセット): Primary `#1B3A5C` / Primary Dark
  `#10233A` / Base `#DCE6F5` / Base Soft `#A9C0D8` / Accent `#7B4FFF`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在人物〔ふらお氏〕の写真・肖像・
  実在企業のロゴ・商標は使用しない、図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `quote` は含まれない
(構成比・推移・量比較を示す独自データや、確認済みの発言引用がないため。数字は
主に `big_stat` / `table` / `cards` で扱っている)。

## このデッキ固有の注意(未確認事項の扱いと中立性が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「専門家1人の知見だけに
  基づくAIだって?」というフックを提示しつつ、直後に正確な事実(LINEヤフーが
  8月17日に発表)を添えている。フック性の強い表現は許容するが、実態以上に
  大規模なサービスであるかのように書き換えないこと
- **スライド12・13・14はサービス提供期間(2026年8月17日〜2026年9月30日)を
  扱う核心スライド**であり、日付を混同・省略・創作しないこと
- **スライド16・18・24・25・26は『エキスパートAIカテゴリの今後の拡大予定』
  『ふらお氏への報酬・契約条件』が未確認であることを示すスライド**であり、
  具体的な時期・金額・条件を創作して埋めないこと
- **スライド23は本資料が特定企業・製品の宣伝ではなく中立的な事実紹介である
  ことを明示するスライド**であり、削除しないこと
- **スライド27は見出しの印象(大規模展開・高額報酬の誤解)と実際の内容の
  ギャップを示すスライド**であり、削除しないこと
- 実在人物名(ふらお氏)はテキストとしてのみ扱い、写真・肖像は使用しない。
  実在企業(LINEヤフー株式会社)の名称はテキストとして扱ってよいが、ロゴ・
  商標画像は使用しない
- 特定企業・製品・団体の過度な推奨・宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`cobalt_violet`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
