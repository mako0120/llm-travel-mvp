## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 番号バッジ付き横並びステップ(矢印つき) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない。構成比・時系列推移を表すデータや引用素材が本調査の範囲では確認できていない、または該当しないため、単一時点の数字は`big_stat`/`table`/`cards`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- Canva ロゴ・商標のガイドライン: アリババ・Wan3.0等の実在企業のロゴ・商標は使用しない
- **第三者評価・ランキングは情報源間で矛盾があり不採用**という判断を維持し、順位を断定する表現に書き換えない
- 実在企業(アリババ)のロゴ・商標、Wan3.0生成コンテンツを使用しない
- 既存テーマ(2026-08-23の株式売り出しテーマ)との違いを明確にする
- 公開ベータと正式リリースの時点を混同しない
- 本テーマは製品リリースという事実紹介であり、特定企業の株式購入や製品利用を推奨する表現に書き換えない
