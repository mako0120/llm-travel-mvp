## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字/1語強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない。本テーマは
  決勨結果という単発の出来事の紹介であり、推移データ・構成比データが本調査の範囲で存在せず、
  直接引用として確認できたコメントもないため、これらのレイアウトは使用していない。

## このデッキ固有の注意

- **スライド4は鮮度についての回**である。決勝の日付(8月9日)を基準にすれば着手日
  (8月11日)から2日以内であることを明示している
- **スライド10は男子決勝と女子決勝の比較回**である。結果という事実のみを淡々と扱い、
  選手・国同士の優劣を煽る表現を含めないこと。この方針をCanva移植時にも厳守すること
  (見出し・装飾での煽り表現を追加しない)
- **スライド15・19・23・28は「確認できなかったこと」「政治的中立性」「見送った切り口」
  「リスク配慮」の一覧**であり、削除しないこと(決勝スコアの詳細・両選手の通算優勝回数や
  ランキング・過去の同種事例の網羅的な有無・今後の代表選考への影響が非公開・未確認である
  ことを明示している)
- **スライド19は政治的中立性・過度な演出についての注記**である。削除・簡略化しないこと
- 実在選手名(張本智和選手、張本美和選手、オ・ジュンソン選手、陳幸同選手)は
  テキストとしてのみ扱い、写真・肖像・所属先の公式ロゴは使用しない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`forest_sand`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・事実の一致を確認
