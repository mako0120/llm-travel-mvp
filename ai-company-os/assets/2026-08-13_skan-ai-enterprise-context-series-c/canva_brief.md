## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| quote | 引用スライド(大きめの引用符+出典表記) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` は含まれない(推移データは資金調達額の
  3ラウンド比較のみで`bar_chart`が最適、構成比を示すデータは扱っていないため)。

## このデッキ固有の注意(プライバシー配慮を含む)

- **スライド1・2は本テーマのコールドオープン(「あなたの仕事の仕方を、AIが観察している」)**
  である。事実紹介であり、扇動的な監視ツールであるかのような表現に書き換えないこと
- **スライド6・7・14は「業務観察型AIコンテキストプラットフォーム」の仕組みを説明する
  スライド**である。技術・効果を誇張する表現(「完璧」「万能」等)には書き換えないこと
- **スライド18は顧客・実績紹介スライド**であり、「米国大手銀行トップ10のうち7行」等の
  分類は事実として扱うが、個別行名は未確認のため断定的な社名を追加しないこと
- **スライド19は導入効果の一例(AMLケースの60%)を紹介するスライドだが、顧客名・測定
  方法が未確認であることを明示している**。確定した一般的な効果であるかのような表現に
  書き換えないこと
- **スライド20・21はプライバシーへの配慮を扱う核心スライド**である。Skan側の説明のみを
  一方的に強調したり、逆に懸念の指摘だけを強調したりせず、両論併記のバランスを保つこと。
  削除しないこと
- **スライド22は見出しの印象と実際の内容のギャップを示すスライド**である。「監視ツール」
  等の誇張表現に書き換えないこと
- **スライド23・24は「確認できていないこと」の一覧**であり、削除しないこと
- **スライド27は誇張回避・政治的中立性を明示するスライド**であり、削除しないこと
- 実在企業名(Skan AI、Cathay Innovation等)はテキストとしてのみ扱い、ロゴ・商標・
  実在人物の肖像は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
