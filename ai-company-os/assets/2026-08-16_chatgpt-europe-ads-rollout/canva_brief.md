## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `quote` は含まれない(推移データ・
構成比を示す確認済みの数字や、公式コメントの直接引用がないため)。

## このデッキ固有の注意(誤解を招かない扱いが最重要)

- **スライド1・2は本テーマのコールドオープン(「2026年8月15日08:29のメール」)**
  である。フック性の強い表現は許容するが、「無料版が終わる」等、事実と異なる
  誤解を招く書き換えはしないこと
- **スライド9・10は初心者向けの前提知識(プラン階層・広告の種類)**であり、
  専門用語をそのまま使わずに平易な説明を保つこと
- **スライド16・17・18はデータ処理の場所・法的根拠を扱う核心スライド**である。
  GDPR第45条(1)項・第46条(2)(c)項という条文番号を誤って書き換えないこと
- **スライド19・27は「確認できていないこと」の一覧**であり、削除しないこと。
  開始日・他地域展開・広告料金・広告主を確定情報であるかのように書き換えないこと
- **スライド25は見出しの印象と実際の内容のギャップを示すスライド**であり、
  削除しないこと
- **スライド26は中立性(OpenAIは競合ではない、賛否どちらにも偏らない)を明示する
  スライド**であり、削除しないこと
- 実在の「OpenAI」「ChatGPT」の名称はテキストとしてのみ扱い、公式ロゴ・商標・
  UIスクリーンショットは使用しない
- 特定プラン・特定サービスの宣伝にはしていない
