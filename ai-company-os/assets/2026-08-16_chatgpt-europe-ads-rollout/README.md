# 「ChatGPTに広告が来る――OpenAIが欧州Free・Goユーザーに送った、2026年8月15日08:29のメール」(2026-08-15通知・2026-08-16制作・本日3本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
OpenAI Ireland Limitedが2026年8月15日(土)08:29に、EEA・スイスのChatGPT Free/Go
ユーザーへ送ったプライバシーポリシー改定通知(広告導入)の内容を、出典付きで
中立的に整理することを軸に構成している。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠
- 2026年8月15日08:29、OpenAI IrelandがEEA・スイスのChatGPT Free/Goユーザーへ、
  今月後半から広告が表示されるとするプライバシーポリシー改定の通知メールを送付した
  (着手日2026-08-16の1日前、`docs/06_Content_R&D.md`の「着手日を含めて2日以内」
  という鮮度基準を満たす)
- 専門メディアppc.landの報道と、OpenAI公式ヘルプセンター・公式ブログ2本の内容が
  整合している
- 無料でChatGPTを使っている人に直接関わる話題であり、関心を引きやすい
  (`research/2026-08-16_theme-evaluation-round138.md`参照、スコア推定91点)

## 既存テーマとの関係(重複でないことの確認)

作業開始時に`ai-company-os/assets/`配下を`chatgpt`・`openai`で検索し、既存の
OpenAI/ChatGPT関連テーマ多数(Atlas終了、Work/Codex統合、中小企業向けプログラム、
学術研究者向け施策、週間ユーザー数10億人、Appleとの営業秘密訴訟棄却等)を確認した。
いずれも扱う出来事が異なり重複ではない(詳細は`research.md`「既存テーマとの関係」を
参照)。既存テーマディレクトリ自体は読み取りのみで一切変更していない。

## 適用したルール

- 30枚デッキ、bullets比率27%(8/30枚、40%上限クリア)、同一レイアウト連続は
  最大2(4連続以上は一度も発生しない構成、`build_deck.py`のビルド時検証を通過)
- palette_presetは指示通り`cobalt_violet`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「2026年8月15日08:29」という
  具体的な通知時刻をフックとして即座に提示し、挨拶・前置きを省いた
- **確認済み事実のみを使用**: 通知日時・対象プラン(Free/Go)・対象外プラン
  (Plus/Pro/Enterprise/Business/Education)・ターゲティングの仕組み(文脈連動型/
  パーソナライズ)・データ処理の法的根拠(GDPR第45条(1)項/第46条(2)(c)項)は
  すべて`research/2026-08-16_theme-evaluation-round138.md`に記載の確認済み事実の
  範囲内で扱い、数字・固有名詞の創作は一切行っていない
- **不明点の正直な開示**: 広告表示開始の具体的日付、他地域(日本等)への展開時期、
  広告料金・広告主は、複数スライド(19・27)と`research.md`で繰り返し「不明」と
  明記した
- 初心者向け前提知識スライド(プラン階層・広告の種類・GDPR上の域外移転根拠の解説)+
  読者の立場別(ChatGPTユーザー・プライバシーを重視する立場・発信する立場)の
  実践的示唆(スライド23)
- 見出しの印象(「無料版が終わる」等)と実際の内容(広告が加わるだけ)のギャップを
  専用スライド(25)で明示した
- OpenAIは本パイプラインの運営元とは無関係の別会社であり、競合批判・宣伝いずれの
  意図もないことを専用スライド(26)で明示し、政治的中立性・企業への公平な扱いを
  保った
- 実在のOpenAI/ChatGPTのロゴ・商標・UIスクリーンショットは使用せず、テキストベースの
  図解・アイコンのみで構成した
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誤解を招く誇張は一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- 同一レイアウト4連続以上チェック・bullets比率40%以下チェック(27%) → 合格
  (`build_deck.py`のビルド時検証を通過)
- `generate_dialogue_script.py --deck deck_spec.json` によるスライド数一致・
  スライド連番検証 → 合格(30スライド全カバー)
- 著作権・品質自己評価: 95点/100点(85点以上のため修正不要)

## リスク配慮

- 「無料版が終わる」等の誤解を招く見出しにせず、実際の内容(Free/Goに広告が加わる
  だけ)とのギャップを明示している
- OpenAIは競合ではないため、批判・擁護のいずれにも偏らない中立的な扱いを徹底した
- 開始日・他地域展開・広告料金など確認できなかった項目を「不明」として正直に扱っている
- 実在企業のロゴ・商標・UIスクリーンショットは使用していない
- 政治的中立性を保っている(本テーマは企業のプロダクト方針変更の紹介であり、
  政治的評価は含まない)
- 特定企業・製品の過度な推奨・宣伝は行っていない
- 公開・投稿はまだ行っていない
