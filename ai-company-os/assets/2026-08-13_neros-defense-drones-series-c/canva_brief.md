## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| quote | 引用スライド(大きめの引用符+出典表記) |

※ このデッキに `line_chart` / `pie_chart` は含まれない(推移データは資金調達額の
  3ラウンド比較のみで`bar_chart`が最適、構成比を示すデータは扱っていないため)。

## このデッキ固有の注意(防衛テーマ特有の配慮を含む)

- **スライド1・2は本テーマのコールドオープン(「評価額、1年で25億ドルへ」)**である。
  資金調達の事実紹介であり、兵器性能の誇張表現に書き換えないこと
- **スライド11〜14はArcher AI・Banditの仕組み・役割を説明するスライド**である。
  性能を誇張する表現(「無敵」「圧倒的」等)や、軍事行動を扇動・称賛する表現には
  絶対に書き換えないこと
- **スライド15は契約先の紹介スライド**であり、米陸軍・海兵隊・USSOCOMという
  組織名は事実として扱うが、政治的評価を加えないこと
- **スライド18は単価情報が「未確認・参考値」であることを明示するスライド**であり、
  確定した公式価格であるかのような表現に書き換えないこと
- **スライド20・21は「確認できていないこと」の一覧**であり、削除しないこと
- **スライド23は見出しの印象と実際の内容のギャップを示す核心スライド**である。
  「最強の迎撃ドローン」等の誇張表現に書き換えないこと
- **スライド26は誇張回避・政治的中立性を明示するスライド**であり、削除しないこと
- 実在企業名(Neros、Sequoia Capital等)はテキストとしてのみ扱い、ロゴ・商標・
  実在人物の肖像は使用しない
- Shahed型ドローン等の言及(スライド13)は、報道された脅威分類としての技術的
  文脈に限定し、特定の紛争当事者・国家への評価的な言及を加えないこと
- 特定企業・製品の利用を強く推奨する結論にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
