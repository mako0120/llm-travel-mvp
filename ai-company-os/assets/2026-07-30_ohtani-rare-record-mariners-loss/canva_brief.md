## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `quote` は含まれない(大谷選手本人の試合後コメントが検索範囲
  では確認できなかったため)。`bar_chart` / `line_chart` / `pie_chart` も
  含まれない(推移データが限られるため、数字は`big_stat`・`table`で扱っている)。

## このデッキ固有の注意

- **スライド7・13・17の「23号」「5年3か月ぶり」「71年間唯一」は本テーマの
  中心となる数字**である。出典(Full-Count・TBS NEWS DIG等)を必ず残すこと
- **スライド18は米データ会社Opta Statsが定義した4条件の整理**であり、
  出典を明記したうえで保持すること
- **スライド22は「Opta Statsの算出方法の詳細な一次資料・大谷選手本人の
  コメントは未確認」という開示**であり、削除しないこと
- スライド15(なぜ負けたか)・27(シーズン後半への展開)は推測を含むことを
  本文に明記している。断定形に書き換えないこと
- 実在選手名・球団名(大谷翔平、ドジャース、マリナーズ等)はテキストとしての
  み扱い、肖像・ロゴは使用しない
- 特定選手・球団への断定的な評価・批判はしない。移植時も断定的な表現を
  追加しないこと

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`navy_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
