# 「AIがあなたの代わりに買い物をするのは違法か」— 連邦控訴裁判所が出した衝撃の答え(2026-08-04判決・定期実行137本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし
図解で伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話
ナレーション・スライド連動モードで制作。

## 選定理由

- PerplexityのAIショッピングエージェント「Comet」がAmazonのアカウントページに
  無断アクセスしたとされた裁判で、米第9巡回区控訴裁判所が2026年8月4日、
  Amazon側が得ていた差止命令を取り消した
- 発端は2026年3月9日、連邦地裁のMaxine M. Chesney判事が発令した仮差止命令。
  控訴裁判所は上訴審理中は執行を一時停止し、2026年6月11日にシアトルで
  口頭弁論を実施していた
- 判決の核心は、「Amazonのサーバーに'アクセス'しているのは開発企業である
  Perplexityではなく、エージェントを介して操作しているユーザー自身である」
  という法解釈で、「エージェント型コマース」の適法性をめぐる初期の重要な
  司法判断となった

社会的インパクトの大きさ、着手日の1日前という高い鮮度がバズ路線の見出しと

一つである。**

## 最重要の開示: 法的判断の当否について論評しない方針

**本テーマで最も慎重に扱った論点である。** 本テーマは実在の連邦控訴裁判所
(米連邦第9巡回区控訴裁判所)の判断を扱う法的な話題である。裁判所が実際に
何を認定したか(差止命令の取り消し・サーバーへのアクセス主体はユーザー
自身という法解釈)は確定事実として中立的に報告するが、**この判決が「良い
判決か悪い判決か」「妥当か不当か」という当否についての論評は、全成果物を
通じて一切行っていない**(専用スライド23、research.md、youtube_assets.md、
canva_brief.md、risk-and-quality-review.mdで一貫)。見出し「衝撃の答え」も、
判決内容そのもの(差止命令の取り消し)をフックとして使っており、判決の
正当性を示唆・断定するものではない。あわせて、Amazon側の今後の対応
(更なる上訴の可能性等)・Comet/Perplexityの利用者数・技術的詳細・金銭的な
数字はいずれも未確認であることを専用スライド(20・21)で明確に開示している。

見出し・タイトルの表現は「バズる人気」優先の、一般視聴者にも直感的に分かる
問いかけを強調した表現にしている(オーナー提案の「『AIがあなたの代わりに

政治的中立性の逸脱・判決の当否についての論評は一切行っていない。**

## 適用したルール

- 30枚デッキ、bullets比率30.0%(9/30枚、40%上限クリア、25〜30%の目標帯内)、
  同一レイアウト連続なし(最大連続数3)
- **コールドオープン(バズ路線)**: 冒頭(1枚目・ナレーション1行目)で
  「AIがあなたの代わりに買い物をするのは違法か。連邦控訴裁判所が答えを
  出しました」という問いかけを即座に提示
- **法的判断の当否について論評しない方針の徹底**: 専用スライド(23)で、
  裁判所が認定した事実の中立的な報告と、判決の当否についての論評回避を
  明記
- 初心者向け前提知識スライド(「Comet」とは何か・CFAAとは何か・
  「エージェント型コマース」とは何か)+ タイムライン(steps/table)による
  時系列整理
- **数字の混同防止**: 判決日・差止命令発令日・口頭弁論日という複数の日付を、
  専用のタイムライン表(スライド13)で整理
- 公平性・中立性についての開示(スライド23): 実在企業名・裁判所名・人物名は
  テキストのみで扱い、政治的な論評は一切行っていない
- 特定企業・特定製品(Comet等)の利用を強く推奨する結論にはしていない
