## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「カメラマン席に飛び込んだ相手選手へ、横浜高校の選手が水を――甲子園に
  響いた拍手」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 高校野球・甲子園に関心がある一般視聴者。専門知識がない前提で、
  甲子園・対戦カードの基礎知識から出来事の深掘りまで丁寧に分解して説明するスライドを
  設けている。未成年の選手が主役であることを踏まえ、通常より厳格な配慮を前提とした
  構成になっている
- パレット(HEX、steel_amberプリセット): Primary `#3A4750` / Primary Dark `#23292E` /
  Base `#F5D9A8` / Base Soft `#D9A857` / Accent `#E8871E`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在選手の写真・肖像・実在団体(日本高等
  学校野球連盟等)のロゴ・商標は使用しない、図形・アイコンはCanva内蔵の無料素材のみ
  を使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(4ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントの一次引用がないため)。

## このデッキ固有の注意(未成年配慮と誇張回避が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「相手選手に水を差し出した」
  という行動そのものをフックにしている。フック性の強い表現は許容するが、試合中断の
  理由を深刻な負傷であるかのように書き換えないこと
- **スライド10・11・12は4回の飛び込み好捕と試合中断を扱う核心スライド**であり、
  「身体の状態を確認するため」という報道の範囲を超えて負傷の詳細を創作しないこと
- **スライド13・14は横浜の選手が水を差し出す場面を扱う核心スライド**であり、
  経緯(駆け寄る→様子確認→ベンチに呼びかけ→差し出す)を混同・省略・誇張しないこと
- **スライド16・17は水を渡した横浜の選手の氏名が未確認であることを示すスライド**
  であり、削除しないこと。氏名を推測で補ったり、先発投手と同一人物と断定したり
  しないこと
- **スライド20は霞ケ浦の敗戦(5-2)を正直に伝えるスライド**であり、削除しないこと。
  敗戦を隠したり、逆に過度に悲劇的に演出したりしないこと
- **スライド21は未成年選手への配慮方針を扱うスライド**であり、削除しないこと。
  選手の私生活・容姿等に関する記述を追加しないこと
- **スライド22は見出しの印象と実際の内容のギャップを示すスライド**であり、
  削除しないこと
- 実在選手名(村上聖選手)はテキストとしてのみ扱い、写真・肖像・実在団体のロゴ・
  商標は使用しない。水を渡した横浜の選手には氏名を付けない
- 特定企業・製品・団体の宣伝にはしていない。政治的な話題には一切触れていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`steel_amber`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
