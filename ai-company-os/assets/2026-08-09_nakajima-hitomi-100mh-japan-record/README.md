# 「31歳が、同じ日に日本記録を2回叩き出した。」(中島ひとみ選手、170本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話ナレーション・
スライド連動モードで制作。

## 選定理由

- 2026年8月9日、山梨県富士吉田市で行われた富士北麓ワールドトライアルの女子100m
  ハードルで、中島ひとみ選手(31歳、長谷川体育施設)が予選で12秒62(追い風2.0m)を
  記録し、福部真子選手が持つ従来の日本記録12秒69を0秒07更新する日本新記録を樹立した。
  さらに決勝でも同タイム12秒62をマークし、同日に日本記録に相当するタイムを2回記録した。
  中島選手は2026年6月の第110回日本陸上競技選手権大会・女子100mハードル決勝(12秒77)で
  大会初優勝を果たしており、アジア大会代表でもある
- `ai-company-os/research/2026-08-11_theme-evaluation-round100.md`の「候補2(170本目)」
  として、バズ路線スコア73/100で採用
- **鮮度基準について正直な開示: 発表日(2026-08-09)は着手日(2026-08-11)から2日前。**
  `docs/06_Content_R&D.md`の鮮度基準(着手日を含めて2日以内)を満たしており、例外的な
  妥協採用ではない
- 「31歳が同日に日本記録を2回樹立した」という意外性、0秒07更新という具体的な数字、
  日本選手権女王・アジア大会代表という文脈がフックになる

## 本テーマ特有の扱い: バズる見出しと、非公開情報・政治的中立性の正直な開示

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)を通常より
強めにしてよいこととされている。この指示は正確さ・出典・正直さ・政治的中立性のルールを
緩めるものではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「31歳が、同じ日に日本記録を2回叩き出した」という報道された事実に基づく表現 | オーナー指示により通常より強めの表現を許容しつつ、報道内容に忠実な表現にとどめた(創作なし) |
| 決勝タイム12秒62が予選と全く同一だったことの技術的な意味・背景 | 本調査の範囲では確認できず | 断定せず「不明」として扱った(スライド10・17) |
| 追い風2.0mが公認記録の範囲内かどうかの明確な確認 | 本調査の範囲では確認できず | 「確認できなかったこと」として一覧化(スライド17) |
| 中島選手本人のコメント・心境 | 「本人仰天」という一般的な反応表現以上の具体的な発言は確認できず | 推測で埋めず「不明」として扱い、心境を推測で示唆する表現は使用していない(スライド17・22) |
| 今後のアジア大会での目標・見通し | 本調査の範囲では確認できず | 「確認できなかったこと」として一覧化(スライド17・19) |
| 旧日本記録保持者(福部真子選手)との比較 | 事実として確認できる記録の数値のみ | 記録という事実を淡々と紹介するにとどめ、選手間の優劣を煽る表現は一切使用しない(スライド9・21) |

締めのスライド30では「発表日を基準にすれば鮮度基準を満たすこと」「予選・決勝で日本新記録を
2回連続樹立という明確な出来事の構造」という、本テーマを選んだ理由そのものを端的に示す
一言で締めている。

## 適用したルール

- 30枚デッキ、bullets比率23.3%(7/30枚、40%上限クリア)、同一レイアウト連続なし
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用、最大2連続)

  `pie_chart`は該当データがないため使用せず、直接引用として確認できたコメントもなかったため
  `quote`も使用していない)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「12秒62。この記録を、同じ日に2回出した
  選手がいるらしいよ」という具体的な数字を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(「100mハードル」「追い風2.0m」「日本記録」の用語解説、
  スライド8) + 実践的な整理(「これは日本の女子ハードル界/アジア大会に向けて何を意味するか」、
  スライド18・19・20)
- **事実・推測・不明を明確に区別**: 確定タイム(6月12秒77・8月予選12秒62・8月決勝12秒62)
  という事実と、決勝タイム一致の技術的意味・追い風の公認可否・本人コメント・今後の目標という
  不明(スライド17)を分けて扱った
- **鮮度についての正直な開示**: 発表日(8月9日)を基準にすれば着手日から2日以内で基準を
  満たすことをスライド4で正直に開示した
- **政治的中立性の維持**: 旧日本記録を持つ福部真子選手との比較は記録という事実のみを扱い、
  選手間の優劣を煽る表現を一切使用しないことをスライド9・21で明示した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 実在選手名(中島ひとみ選手、福部真子選手)・実在所属先名(長谷川体育施設)は
