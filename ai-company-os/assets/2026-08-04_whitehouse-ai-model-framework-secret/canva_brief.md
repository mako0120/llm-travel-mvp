## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない
  (推移データが限られるため数字は`big_stat`と`table`で扱い、実在人物への
  直接取材コメントが確認できなかったため`quote`は使用していない)。

## このデッキ固有の注意

- **スライド2の「最大30日間」は本テーマの中心となる数字**である。誇張せず、
  「一般公開・他の信頼できるパートナーへの提供に先立って」という条件を
  必ず併記すること
- **スライド11「予定なし」(内容の一般公開)は本テーマのフックとなる事実**
  であり、削除しないこと
- **スライド15は「確認できなかったこと」の一覧**であり、保持すること
- **スライド16は政治的中立性についての注記**である。政策の是非への評価・
  特定の政党や政治家個人への評価を一切追加しないこと(本テーマで特に重要)
- **スライド19・20・27は当社の推測**であることを本文に明記している。
  断定形や公式見解のように書き換えないこと
- 実在企業名(Anthropic・OpenAI・Google・Meta・Nvidia・Microsoft)はテキスト
  としてのみ扱い、ロゴ・商標は使用しない
- ホワイトハウス・大統領職という公的機関・役職の名称は事実として扱うが、
  公式紋章・国章・肖像等は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`navy_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
