## 本テーマ特有の扱い: 政治的中立性への配慮

大統領令や政権の政策対応という事実関係(何が起きたか)のみを扱い、政策の
是非という価値判断・特定の政党や政治家個人への評価・批判・支持は一切
行っていない。「内容が非公開である」という点は、専用スライド(16)で
「透明性の観点から議論を呼びうる客観的な事実」として紹介するにとどめ、
それ以上の論評は加えていない。この方針は成果物全体(デッキ・対話台本・
YouTube素材・Canvaブリーフ)に一貫して適用した。

| 区分 | 内容 | 扱い |
|---|---|---|
| 一次情報に近い事実 | 大統領令の署名日・内容、会合の開催日・非公開方針 | Fortune・CNBC・NY1・Norton Rose Fulbright・Skaddenという複数の独立メディア・法律事務所解説を突き合わせて事実として扱う |
| 合理的推測 | 想定される論点・想定される影響 | 「当社の推測」であることを専用スライド(19・20・27)で明記し、公式見解や法的助言と区別 |
| 非公開・未確認の情報 | 評価基準の詳細、対象モデルの線引き基準、参加企業の完全なリスト、将来の義務化の有無 | 「確認できなかったこと」として一覧化(スライド15) |

締めのスライド26・30では「非公開の内容がいずれ明らかになるか、続報を
出典付きで追っていく」ことを提示している。

## 適用したルール

- 30枚デッキ、bullets比率23.3%(40%上限クリア)、同一レイアウト連続は最大2
- 文字中心の説明はtable/diagram/comparison/stepsで図解化
  (推移データが限られるため`bar_chart`ではなく`table`・`big_stat`で扱った。
  実在人物への直接取材コメントが確認できなかったため`quote`は使用していない)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「最大30日間」「Anthropic、
  OpenAI、Google、Meta、Nvidia、Microsoftなど十数社」という具体的な数字・
  固有名詞を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(大統領令の概要・枠組みの仕組みの概念図) +
  実践的な整理(公開情報/非公開情報の比較、今後注目すべきポイント)
- **公式に近い情報・法律専門メディアの要約・当社の推測を明確に区別**:
  署名日・会合日・非公開方針という事実と、想定される論点・影響という
  当社の推測を分けて扱う
- **政治的中立性を最重要事項として扱った**: 専用スライド(16)で政策の
  是非への評価を行わないことを明示し、成果物全体で徹底した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 特定企業・製品の利用を強く推奨する結論にはしていない
