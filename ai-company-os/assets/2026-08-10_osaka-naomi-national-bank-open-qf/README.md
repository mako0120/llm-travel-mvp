# 「世界2位との、初対戦が決まった。」(大坂なおみ選手、173本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話ナレーション・
スライド連動モードで制作。

## 選定理由

- カナダ・トロントで開催中のナショナルバンクオープン2026(WTA1000)のシングルス4回戦
  (日本時間2026年8月10日、現地時間8月9日)で、大坂なおみ選手(第11シード)が
  L・フェルナンデス選手(カナダ、第30シード)を6-4, 6-4のストレートで下し、2年連続
  3度目のベスト8進出を果たした。準々決勝では、世界ランク2位・第2シードのE・ルバキナ
  選手(カザフスタン)と対戦する。両選手は過去に対戦経験がなく、今回が初対戦となる
- `ai-company-os/research/2026-08-11_theme-evaluation-round102.md`の「候補1(173本目)」
  として、バズ路線スコア75/100で採用
- **鮮度基準について正直な開示: 4回戦の日付(日本時間2026-08-10、現地時間2026-08-09)は
  着手日(2026-08-11)から1日前。** `docs/06_Content_R&D.md`の鮮度基準(着手日を含めて
  2日以内)を満たしており、例外的な妥協採用ではない
- 「世界ランク2位との初対戦」という明確なフック、「2年連続3度目のベスト8進出」という
  積み重ねられた実績、著名選手同士の対戦カードという視聴者の関心を引きやすい要素が
  フックになる

## 本テーマ特有の扱い: バズる見出しと、未確定結果・正直さの明示

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)を通常より
強めにしてよいこととされている。この指示は正確さ・出典・正直さ・政治的中立性のルールを
緩めるものではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「世界2位との、初対戦が決まった。」という報道された確定事実(準々決勝の組み合わせ決定、対戦経験なし)に基づく表現 | オーナー指示により通常より強めの表現を許容しつつ、結果を先取りしない・報道内容に忠実な表現にとどめた(創作なし) |
| **準々決勝(対ルバキナ選手)の結果** | 本タスク着手時点(2026年8月11日)ではまだ行われておらず未確定 | **推測・創作を一切せず、「これから行われる対戦」として扱った(スライド16・18・21・29・30、YouTube概要欄で複数回明示)** |
| 大坂選手の1〜3回戦の具体的なスコア | 本調査の範囲では確認できず | 断定せず「不明」として扱った(スライド19・20) |
| 過去の2年連続8強の内訳(何年の大会か等) | 本調査の範囲では確認できず | 「確認できなかったこと」として一覧化(スライド12・19・20) |
| ルバキナ選手の今シーズンの詳細戦績 | 本調査の範囲では確認できず | 推測で埋めず、「不明」として扱った(スライド19・20) |
| 対戦相手(L・フェルナンデス選手・カナダ、E・ルバキナ選手・カザフスタン)との比較 | 事実として確認できるシード順位・結果・組み合わせのみ | 結果・組み合わせという事実を淡々と紹介するにとどめ、国・地域間の優劣や対立を煽る表現は一切使用しない(スライド11・17) |

締めのスライド29・30では「準々決勝は、まだこれから。」という開かれた結論と、
「準々決勝の結果は一次情報源で確認する」という呼びかけで締めている。

## 適用したルール

- 30枚デッキ、bullets比率23.3%(7/30枚、40%上限クリア)、同一レイアウト連続なし
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用、最大2連続)
- 文字中心の説明はcards/table/comparison/diagram/steps/big_statで図解化(本テーマは
  進行中トーナメントの一場面の紹介であり、推移データ・構成比データが本調査の範囲で
  存在しないため`bar_chart`/`line_chart`/`pie_chart`は使用せず、直接引用として確認
  できたコメントもなかったため`quote`も使用していない)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「世界2位との初対戦が決まったらしいよ」
  という結果を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(「WTA1000とは」スライド6、「シード順位・ベスト8とは」
  スライド7) + 実践的な整理(「これは大坂選手にとって何を意味するか」スライド22、
  「これはテニスファン・視聴者にとって何を意味するか」スライド23)
- **事実・推測・不明を明確に区別**: 4回戦の結果・ランキング・組み合わせという事実、
  初対戦の注目度という推測、準々決勝の結果・1〜3回戦の詳細・過去の内訳・ルバキナ選手の
  今シーズン戦績という不明を、専用スライド19・20で分けて扱った
- **準々決勝の結果はまだ出ていないことの複数箇所での明示**: スライド16(図解の
  キャプション)・18(対戦成績0-0)・21(専用スライド)・29(締め1)・30(締め2)、
  加えて`youtube_assets.md`の概要欄でも明示した
- **鮮度についての正直な開示**: 4回戦の日付(8月10日)を基準に着手日から1日前で
  基準を満たすことをスライド4で正直に開示した
- **政治的中立性の維持**: 4回戦の相手(カナダ代表)・準々決勝の相手(カザフスタン代表)
  ともに、結果・組み合わせという事実のみを扱い、国・地域間の優劣を煽る表現を一切
  使用しないことをスライド11・17で明示した
- 出典のない数字・事実は作らず、確認できなかったことは正直に「不明」と明記した
- 実在選手名(大坂なおみ選手・L・フェルナンデス選手・E・ルバキナ選手・L・サムソノワ選手)
  はテキストとしてのみ扱い、写真・肖像・公式ロゴは使用していない

- **準々決勝(大坂選手 対 ルバキナ選手)の結果は本タスク着手時点(2026年8月11日)では
  まだ確定していない旨を、スライド16・18・21・29・30の複数箇所、およびYouTube概要欄で

- 特定選手への過度な持ち上げ・貶めをしない構成にし、見送った切り口(準々決勝の結果の
  推測・勝敗の断定・過去の内訳の誇張)をスライド25で明示する

  結果を先取りしていない)ことの両方をリスク配慮として明示している
