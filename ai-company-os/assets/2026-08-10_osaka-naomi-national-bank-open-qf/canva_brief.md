## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字/1語強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない。本テーマは
  4回戦の結果・準々決勝の組み合わせという単発の出来事の紹介であり、推移データ・構成比
  データが本調査の範囲で存在せず、直接引用として確認できたコメントもないため、これらの
  レイアウトは使用していない。

## このデッキ固有の注意

- **スライド16・18・21・29・30は「準々決勝はまだ行われていない」ことを扱う回**である。
  結果を推測・創作せず、「これから行われる対戦」として扱っていることをCanva移植時にも
  厳守すること(結果を書き足さない、勝敗を示唆する装飾を追加しない)
- **スライド19は事実・推測・不明を明確に区別する回**であり、削除しないこと
- **スライド20は「確認できなかったこと」の一覧**であり、削除しないこと(1〜3回戦の
  詳細スコア・過去のベスト8進出の内訳・ルバキナ選手の今シーズンの詳細戦績・準々決勝の
  結果が非公開・未確認であることを明示している)
- **スライド28は90本目(既存テーマ)との違いを扱う回**であり、削除しないこと
- 実在選手名(大坂なおみ選手、L・フェルナンデス選手、E・ルバキナ選手、L・サムソノワ選手)
  はテキストとしてのみ扱い、写真・肖像・所属先の公式ロゴは使用しない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`steel_amber`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・事実の一致を確認
