## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない。時系列の
  推移データや直接引用として確認できたものが本調査の範囲になく、確認できない数値を
  グラフ化・引用化しないため、代わりに`diagram`(時系列・関係図)・`table`・`cards`で
  整理している。

## このデッキ固有の注意

- **スライド4は鮮度についての回**である。本テーマは着手日から1日前の発表であり、
  鮮度基準(2日以内)を満たすことを明示している
- **スライド6・13は『北米初』が製品発表ではなく個別の導入事象であることを示す回**
  である。R1という製品自体の新しさと混同しないよう明示的に区別しているため、
  削除・簡略化しないこと
- **スライド11・12は製品一般の仕様・価格帯を示す回**であり、St. Clair College自体の
  発表内容ではないことを明記している(削除・簡略化しないこと)。数字を推測で
  埋めないこと
- **スライド14は『製品発表ではなく導入事例』であることを明示する注記スライド**
  である。誤解防止のため保持すること
- **スライド17は「確認できなかったこと」の一覧**であり、削除しないこと(実際の
  調達価格・産業パートナー企業名・研究成果の公開時期・受領台数を非公開として
  明示している)
- **スライド22は政治的中立性・誇張回避についての注記**である。Unitreeが中国企業で
  あるという事実を淡々と扱い、米中の技術覇権論争的な文脈には踏み込まないこと、
  FCCの外国製ロボット規制の話題は本テーマでは扱わないことを明示しているため、
  この注記スライドは保持すること
- **スライド23は当社の推測であることを明記したカード**である。断定形や公式見通しの
  ように書き換えないこと
- **スライド27は『安いロボット』という見出し表現についての正直な補足**である。
  製品一般の価格帯に基づく事実表現であり、St. Clair Collegeの実際の調達価格は
  不明のままであることを明示しているため、削除しないこと
- 実在組織名(St. Clair College、Unitree等)はテキストとしてのみ扱い、ロゴ・商標・
  写真は使用しない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`cobalt_violet`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
