# 山本由伸投手、日米通算100勝を達成(2026-07-27・定期実行43本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・2026-07-24追加のコールドオープンルール)+ AI対話ナレーション・
スライド連動モードで制作。

## 選定理由

- 対象ジャンル「海外で活躍する日本人」枠(20%)。定期実行36〜42本目が
  5回連続でAI/エージェント系のテーマだったため、ジャンル配分のバランスを
  取る目的も兼ねる
- 前日(2026年7月26日、現地時間7月25日)の到達で、着手日(7月27日)から
  1日前という鮮度基準(`docs/06_Content_R&D.md`2026-07-27追記)を満たす
- スポニチアネックス・デイリースポーツ・J SPORTS・日テレNEWS NNN等、
  複数の独立系メディアが「オリックスで70勝、メジャーで30勝、通算100勝」
  という同一の数字を報じており事実確認の確度が高い
- 2016年のドラフト4位指名からの10年、NPB7年間・MLB3年目途中という
  キャリアの節目を、具体的な数字(70勝・30勝・239試合目)で構成できる

詳細な評価点は`ai-company-os/research/2026-07-24_theme-evaluation-round20.md`を参照。

## 見送った候補

- NAVER・Brookfield・NVIDIAのソブリンAIファクトリー拡大(韓国、2026-07-26頃) —
  B2Bインフラの話題で日本の視聴者への直接的な関連性・実用性が低く、既存テーマ
  (Noetra、定期実行34本目)とも近接するため見送り
- 急成長アカウント枠 — 着手時点で具体的な急成長の一次情報を確認できず、
  正直に該当なしとして報告

## 適用したルール

- 30枚デッキ、bullets比率20.0%(40%上限クリア)、同一レイアウト連続なし
- 文字中心の説明はtable/diagram/comparison/stepsで図解化
- **コールドオープン(2026-07-24〜)**: 冒頭(1枚目・ナレーション1行目)で
  具体的な事実(「日米通算100勝。10年かけて積み上げた数字」)を即座に提示し、
  挨拶・前置きを省いた
- 初心者向け前提知識スライド + 「これは何を意味するか・どう応援を楽しめるか」の実践セクション
- 進捗バー・カード影・タイトルアクセントの視覚強化(`docs/04_PowerPoint.md`参照)
- 前サイクルとの接続スライドは設けていない
- 実在選手の写真・肖像は使用しない
