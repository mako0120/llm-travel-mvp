# Canva ブリーフ: 200mも、400mも。松下知之、個人メドレー2種目制覇でパンパシフィック2冠

## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「200mも、400mも。松下知之、個人メドレー2種目制覇でパンパシフィック2冠」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 競泳・スポーツニュースに関心がある一般視聴者。専門知識がない
  前提で、個人メドレーという種目・大会形式の基礎知識から数字の深掘りまで丁寧に
  分解して説明するスライドを設けている
- パレット(HEX、slate_azureプリセット): Primary `#2B3A55` / Primary Dark
  `#1B2537` / Base `#D3E4F5` / Base Soft `#9CB8D6` / Accent `#1F8FD6`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在選手の写真・肖像・実在団体の
  ロゴ・商標は使用しない、図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。2種目のタイム比較はbar_chartで
扱っている)。

## このデッキ固有の注意(200m/400mのタイム混同回避が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「200mも400mも制したって?」
  というフックを提示しつつ、直後に正確なタイムを添えている。フック性の強い表現は
  許容するが、200mと400mのタイムを入れ替えて書かないこと
- **スライド8・9・10・13・14は200m(1分56秒02)・400m(4分06秒75・大会新記録)の
  数字を扱う核心スライド**であり、どちらの数字がどちらの種目のものか、混同・
  省略・丸めないこと
- **スライド16・17は本テーマの制作過程で発見した数字の誤帰属トラップとその訂正を
  明示するスライド**であり、削除しないこと(訂正の透明性がこのテーマの信頼性の
  核である)
- **スライド20は男子4×100mメドレーリレーの銅メダル報道・選手名を扱わない旨を
  示すスライド**であり、選手名を推測で補って書き換えないこと
- **スライド25・26は松下選手の今大会通算成績・次戦の日程等が未確認であることを
  示すスライド**であり、具体的な数字や日程を創作して埋めないこと
- **スライド24は見出しの印象(2種目とも同程度の速さという誤解)と実際の内容の
  ギャップを示すスライド**であり、削除しないこと
- 実在選手名(松下知之選手・今福和志選手)はテキストとしてのみ扱い、写真・肖像・
  実在団体(東洋大学・大会主催団体等)のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
