  という記録の意味まで丁寧に分解して説明するスライドを設けている。前日の28号・29号

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(3ノード) |
| steps | 横並びステップカード+シェブロン矢印(4ステップ) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示すデータ
や、確認済みの選手コメントがないため。打球速度・角度の比較はbar_chartで扱っている)。

## このデッキ固有の注意(前日28号・29号テーマとの区別・数字の正確性が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「30号」「6年連続6度目」という
  フックを提示しつつ、直後に正確な結果を添えている。フック性の強い表現は許容するが、
  数字の誇張・創作は追加しないこと
- **スライド6〜11は30号の場面・打球データを扱う核心スライド**であり、確認できた
  数字(飛距離136.5メートル・打球速度169.9キロ・角度33度)を超えて内容を創作・追加
  しないこと
- **スライド17〜20は前日の28号・29号(菅野智之投手・救援メヒア投手)と本テーマの
  30号(フェルトナー投手)の関係を扱う核心スライド**であり、削除・改変しないこと。
  「同じ試合で3本」のような誤った要約に書き換えないこと
- **スライド14〜16は到達ペースの比較を扱うスライド**であり、2023〜2025年の到達
  試合数を推測で追加しないこと(出典が明示したのは2021年・2022年・2026年の3年分
  のみ)
- **スライド22・23は確認できていないこと(次戦の登板・出場予定、シーズン最終盤
  までの本塁打目標設定の有無、2023〜2025年の到達試合数)を示すスライド**であり、
  具体的な予定や目標を創作して埋めないこと
- 実在選手名(大谷選手・フェルトナー投手)はテキストとしてのみ扱い、写真・肖像・
  実在球団のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない。政治的な話題にも触れていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`crimson_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の要素を
   使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストをそのまま
   コピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
