# AIが起こしたメモリ危機で、Google Pixel 11が値上げされる(2026-07-28・定期実行47本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠(70%)
- 一次情報(9to5GoogleのGoogle幹部への独占インタビュー、2026年7月24日)を起点に、
  英語圏・日本語圏の多数のメディアが7月25〜27日にかけて追随報道しており、
  着手日から1〜4日前で鮮度基準を満たす
- 「AIデータセンター需要がメモリ価格を高騰させ、一般消費者のスマホの値段まで
  上げている」という、AI業界の裏側を生活に直結させる分かりやすいフックがある
- 具体的な数字(6倍の価格高騰、BOM試算$45→$192、出荷12.9%減予測)が豊富で
  視覚化に適している

詳細な評価点は`ai-company-os/research/2026-07-24_theme-evaluation-round26.md`を参照。

## 適用したルール

- 30枚デッキ、bullets比率20.0%(40%上限クリア)、同一レイアウト連続なし
- 文字中心の説明はtable/diagram/comparison/steps/quoteで図解・引用化
- **コールドオープン**: 冒頭(1枚目・ナレーション1行目)で具体的な数字
  (「RAM価格、1年で6倍」)を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(RAM・HBM) + 「これは何を意味するか・どう判断するか」の実践セクション
- **確定情報と観測情報の区別**: Google幹部の発言に基づく確定事項と、
  RAM容量縮小・出荷減少予測等の観測情報を、研究資料・デッキ・対話原稿の
  全てで一貫して区別した(16・19・26・27枚目で明示)
- 進捗バー・カード影・タイトルアクセントの視覚強化(`docs/04_PowerPoint.md`参照)
- 前サイクルとの接続スライドは設けていない
