## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| quote | 引用スライド(ダーク背景、大見出し引用+出典) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(定量的な推移データが
  限られるため、数字・キーフレーズは`big_stat`・`table`で扱った)。`quote`はスライド10で
  OpenAIの発言要旨(報道による発言要旨、直接引用ではない)を紹介するために使用している。

## このデッキ固有の注意

- **スライド2「重大なサイバー能力がないとは言い切れない」は本テーマの核となる引用**である。
  「攻撃できる」という断定表現に書き換えないこと(OpenAIの実際の発言はより慎重な表現)
- **スライド6は同じ「Astra」の別テーマ(2026-08-03・数学証明)との混同を防ぐための
  比較スライド**であり、削除しないこと
- **スライド13「『できる』と『否定できない』の違い」は本テーマで最も誤解されやすい点**
  である。「Astraが確実にハッキングできる」かのような表現に書き換えないこと
- **スライド15・16は既存の関連テーマ(144本目・146本目)との違いを整理するスライド**
  であり、保持すること
- **スライド10は引用スライドだが、直接引用ではなく報道による発言要旨**である旨を
  本文に明記している。あたかも一次インタビューで得た直接引用のように書き換えないこと
- **スライド19は「確認できなかったこと」の一覧**であり、保持すること
- **スライド23は、OpenAIを一方的に称賛も非難もしない旨の注記**である。称賛・非難いずれの
  方向にも表現を追加しないこと(本テーマで特に重要)
- 実在企業名(OpenAI)はテキストとしてのみ扱い、ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
