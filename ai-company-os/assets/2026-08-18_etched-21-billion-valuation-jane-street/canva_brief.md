Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は

移植仕様書(ブリーフ)である。

- デッキ名: 「AIチップ企業Etched、1か月で評価額倍増の210億ドルに――Jane Streetへの初納品も完了」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI・半導体業界の資金調達ニュースに関心がある一般視聴者。
  専門知識がない前提で、ASIC・Transformer・評価額といった用語の基礎知識から
  数字の深掘りまで丁寧に分解して説明するスライドを設けている
- パレット(HEX、slate_azureプリセット): Primary `#2B3A55` / Primary Dark

  無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 番号バッジ付き横並びステップ(矢印つき) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 棒グラフ(カテゴリ2つの評価額比較) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない。構成比を表す
データや引用素材が存在しないため、単一時点・2時点比較の数字は`big_stat`/
`bar_chart`/`table`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「1か月で評価額倍増」
  というフックを提示しつつ、直後に発表日・調達額という正確な事実を添えている。
  フック性の強い表現は許容するが、製品性能を保証するような表現に書き換え
  ないこと
- **スライド7・8・9・10・11・21は核心となる数字(追加調達額7億ドル・到達
  評価額210億ドル・1か月前の評価額103億ドル・顧客契約額10億ドル超)を扱う
  核心スライド**であり、数字を混同・省略・丸めないこと
- **スライド22は Sohuのベンチマーク第三者検証が不明である旨を扱うスライド**
  であり、性能の優劣を証明済みのように書き換えないこと(このデッキでは一切
  使用していない表現である)
- **スライド23はJane Street以外の顧客の導入規模が不明であることを示す
  スライド**であり、具体的な内容を創作しないこと
- **スライド24は見出しの印象(評価額210億ドル=完全に成功)と実際に確認できて
  いる内容のギャップを示すスライド**であり、削除しないこと
- **スライド26は誇張回避・確認ポイント・GPUとの中立的な位置づけを明示する
  スライド**であり、削除しないこと
- Etched・Jane Street等の実在企業のロゴ・商標は使用しない
- Etchedの製品(Sohu)、およびNvidia等の比較対象企業の製品は、いずれも事実
  として紹介するのみで、特定製品への乗り換えを推奨する表現に書き換えない
  (スライド18・26)

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
