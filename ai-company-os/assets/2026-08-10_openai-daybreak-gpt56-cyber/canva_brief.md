## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 横/縦棒グラフ(Canvaのグラフ要素、ネイティブ編集可能なデータで再現) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `quote` / `line_chart` / `pie_chart` は含まれない(発言の直接引用となる
  一次インタビューを確認できておらず、`quote`は使用していない。構成比データもないため
  `pie_chart`は不使用。数字の比較は`bar_chart`1枚に集約した)。

## このデッキ固有の注意

- **スライド2・11・12は本テーマの核となる対照的な数字(95.0%対1.5%対2.0%)**である。
  比較対象(GPT-5.6-Cyber / Daybreak Blue下のSol / 標準の安全対策下のSol)の対応関係を
  崩さないこと
- **スライド13は「完了率」と「正確性」を混同させない、本テーマで最も誤解されやすい
  注意点**である。「95.0%正確に答えられる」のような表現に書き換えないこと
- **スライド9・10は既存147本目(Astra開発減速)との関係を整理するスライド**であり、
  削除しないこと。対象製品・方向性が異なる別の判断であるという整理を保持すること
- **スライド15・16・22・23は「ガードレール解除」というセンシティブな話題を、誇張・
  扇動なく正確に伝えるための核心スライド**である。「安全装置が全部外れた」かのような
  表現に書き換えないこと。悪用の具体的な手口を追加で書き込まないこと
- **スライド18は提供先企業の例(Accenture・IBM・CrowdStrike・Cloudflare)を紹介する
  スライドだが、あくまで報道された一例であり総数ではない**旨のキャプションを保持すること
- **スライド19は「確認できなかったこと」の一覧**であり、保持すること
- 実在企業名(OpenAI、および提供先の例として報じられた企業)はテキストとしてのみ扱い、
  ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`steel_amber`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
