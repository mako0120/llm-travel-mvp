Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

- デッキ名: 「会計AIスタートアップRillet、まさかのユニコーン入り――1年で3回目の資金調達」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI・スタートアップ業界の資金調達ニュースに関心がある一般視聴者。
  専門知識がない前提で、シリーズC・ユニコーン・ARRといった用語の基礎知識から
  数字の深掘りまで丁寧に分解して説明するスライドを設けている
- パレット(HEX、forest_sandプリセット): Primary `#24523F` / Base `#E7DCC2` /
  Accent `#C1622D`(build_deck.pyの`PALETTE_PRESETS`定義を参照)
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント

- アニメーション: なし

  無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| steps | 矢印つき横並びステップ(丸数字バッジ+ラベル+短文) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `quote` / `diagram` は
含まれない。ARRの絶対額・累計調達額の正確な内訳が確認できておらず、推移として
表せる複数時点の数値データが存在しないため、グラフ化による誤解(推移があった
かのような印象)を避け、単一時点の数字・比率は`big_stat`/`cards`/`table`/`steps`で
扱っている。

## このデッキ固有の注意(単一情報源の開示と、数字の正確さ・非公表項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「まさかのユニコーン入り」
  というフックを提示しつつ、直後に発表日・調達額という正確な事実を添えている。
  フック性の強い表現は許容するが、事業の収益性を保証するような表現に書き換え
  ないこと
- **スライド7・9・13・15・17は核心となる数字(調達額1億ドル・評価額10億ドル・
  資金調達1年で3回目・累計調達額2億ドル超・顧客数600社超)を扱う核心スライド**
  であり、数字を混同・省略・丸めないこと
- **スライド16は『ARRの絶対額は不明』を扱うスライド**であり、四半期倍増という
  比率のみを事実として扱い、絶対額を創作して埋めないこと
- **スライド21・22・28・29は『情報源はFortuneの独占記事1本のみ』という
  単一情報源の開示を扱う最重要スライド群**であり、削除・簡略化しないこと
  (本テーマ最大のリスク配慮事項)
- **スライド20・25は非テック企業への浸透の詳細・製品機能・日本展開・次回計画が
  不明であることを示すスライド**であり、具体的な内容を創作しないこと
- **スライド23は見出しの印象(評価額10億ドル=複数メディア検証済み)と実際に
  確認できている内容のギャップを示すスライド**であり、削除しないこと
- **スライド24は誇張回避・確認ポイントを明示するスライド**であり、削除しないこと
- Rillet・ICONIQ・Sequoia Capital等の実在企業のロゴ・商標は使用しない
- Rilletという企業・製品は事実として紹介するのみで、利用を推奨する表現に
  書き換えない(スライド5・23)

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`forest_sand`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
