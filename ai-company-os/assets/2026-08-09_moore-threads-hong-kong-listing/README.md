# 「株価420%、赤字94%減の『中国版NVIDIA』が香港上場を計画」(2026-08-09・155本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話ナレーション・
スライド連動モードで制作。

## 選定理由

- 2026年8月9日、Bloombergが、中国のAI半導体設計企業Moore Threads Technology
  (「中国版NVIDIA」とも呼ばれる)が香港上場を「適切なタイミング」で計画していると
  報じた。同社は2025年12月の上海証券取引所STARマーケット上場以来、株価が420%を
  超えて上昇している
- `ai-company-os/research/2026-08-10_theme-evaluation-round92.md`の「候補1
  (155本目)」として、バズ路線スコア79/100で採用
- **鮮度基準を満たす。** 発表日は2026年8月9日で、着手日(2026-08-10)から1日前。
  `docs/06_Content_R&D.md`の鮮度基準(着手日を含めて2日以内)を満たす
- Bloombergという一次報道に加え、South China Morning Post(2本)・TheNextWeb・
  CryptoBriefing・Bamboo Worksという独立した複数メディアが、株価420%上昇・売上147%増・
  純損失94%縮小という同一の財務数値を報じており、検証可能性が高い
- 「株価420%上昇」「赤字が9割以上縮小」という具体的で衝撃的な財務データが複数揃って
  おり、バズる路線と親和性が高い。AI半導体という関心の高い分野で、地理的にも米国中心
  だった直近のラウンド構成を補う多様性がある

## 重複でないことの確認

`ai-company-os/assets/`配下を確認したところ、Moore Threadsを扱う既存テーマは
見つからなかった(`ai-company-os/research/2026-08-10_theme-evaluation-round92.md`

## 政治的中立性への配慮

本テーマは中国企業(Moore Threads)を扱うため、`ai-company-os/CLAUDE.md`の
オーナー標準ルール(スタンディングルール)に基づき、以下を徹底した。

| 区分 | 内容 | 扱い |
|---|---|---|
| 話題の枠組み | Moore Threadsの上場計画・財務実績を扱う | ビジネス・財務・技術のニュースとして扱い、専用スライド(19)で方針を明示。地政学的な論評(米中対立の文脈での価値判断等)は一切行わない |
| 中国のテック産業・政府への言及 | 香港IPO市場全体の動き(2026年、調達額420億ドル超・過去6年で最高水準)に言及 | 市場動向の事実として中立的に記述し、価値判断・評価的な論評は加えていない |
| 「中国版NVIDIA」という呼称 | メディアが使う通称・市場ポジショニングの表現 | 専用スライド(7・18)で、NVIDIA製品との技術的な性能比較の結果に基づくものではないことを明示。技術的な優劣についての断定は行っていない |
| 特定企業への言及の強さ | Moore Threadsの財務改善・株価上昇を扱う | 投資・利用を強く推奨する結論にはしない旨を専用スライド(25)で明示(「Moore Threadsに投資すべき」というような結論にしていない) |

## 本テーマ特有の扱い: バズる見出しと、非公開情報の正直な開示

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)を通常より
強めにしてよいこととされている。この指示は正確さ・出典・正直さ・政治的中立性の
ルールを緩めるものではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「株価420%、赤字94%減の『中国版NVIDIA』が香港上場を計画」という報道された数値に基づく表現 | オーナー指示により通常より強めの表現を許容しつつ、報道内容に忠実な表現にとどめた(創作なし) |
| 香港上場の具体的な時期 | 「適切なタイミング」としか報じられていない | 「不明」として明記(スライド20) |
| 発行予定の株式数・調達目標額・現在の時価総額 | いずれも本調査の範囲では確認できず | 「確認できなかったこと」として一覧化(スライド20) |
| NVIDIA製品との直接的な性能比較 | 「中国版NVIDIA」は市場ポジショニングの通称であり、技術的な比較の一次情報は未確認 | 断定的な性能比較は行わず、その旨をスライド7・18で明示 |
| 株価上昇率の軽微な差異 | Bloombergの「420%超」とBamboo Worksの「425%」 | いずれも出典を明記した上で両方を正直に開示(research.md) |

締めのスライド30では「『中国版NVIDIA』が、香港市場を目指している」という、報道された
計画そのものを端的に示す一言で締めている。

## 適用したルール

- 30枚デッキ、bullets比率20%(6/30枚、40%上限クリア)、同一レイアウト連続なし
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用、最大2連続)
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_statで図解化。純損失の
  推移(2025年上半期→2026年上半期)は2点の確定値が出典から確認できたため`bar_chart`
  (ネイティブチャート)で視覚化した。株価の日次推移等、時系列の推移データが公表されて
  いない部分や直接引用として確認できたものはなかったため`line_chart`/`pie_chart`/
  `quote`は使用していない
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「株価が420%上がって、赤字が9割以上
  消えた会社があるらしいよ」という具体的な数字を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(「STARマーケット」「H株」「メインボード」の用語解説、
  スライド10) + 実践的な整理(「これは投資家/業界にとって何を意味するか」、
  スライド21・22、「実践: 確認したいこと」スライド24)
- **政治的中立性の専用スライド**: 中国企業を扱うテーマであることを踏まえ、スライド19で
  「ビジネス・財務・技術の話題として扱い、地政学的な論評は一切行わない」方針を明示した
- **事実・推測・不明を明確に区別**: 報道された財務数値・上場計画という事実と、上場時期の
  具体化・調達規模・他社との比較という当社の推測(スライド26)、香港上場の時期・株式数・
  調達額・時価総額・性能比較という不明(スライド20)を分けて扱った
- **鮮度が着手日から1日前であることの明記**: スライド4で鮮度基準を満たすことを明示した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 実在企業名(Moore Threads、NVIDIA等)はテキストとしてのみ扱い、ロゴ・商標・肖像は
  使用していない
