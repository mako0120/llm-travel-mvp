## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| bar_chart | 棒グラフ(ネイティブチャート相当、Canvaの棒グラフ要素で代替) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `quote` は含まれない。時系列の推移データ
  (株価の日次推移等)や直接引用として確認できたものが本調査の範囲になく、確認できない
  数値をグラフ化・引用化しないため、代わりに`diagram`(時系列)・`table`・`cards`で
  整理している。純損失の推移(2025年上半期→2026年上半期)のみ、2点の確定値が
  出典から確認できたため`bar_chart`(スライド14)を使用している。

## このデッキ固有の注意

- **スライド19は政治的中立性についての方針を明示する回**である。中国企業を扱う
  テーマのため、地政学的な論評・価値判断を一切行わない旨を明示しているため、この
  注記スライドは削除・簡略化しないこと
- **スライド18は『中国版NVIDIA』という呼称についての回**である。これはメディアの
  通称・市場ポジショニングの表現であり、NVIDIA製品との技術的な性能比較の結果に
  基づくものではないことを明示する内容のため、削除・簡略化しないこと
- **スライド6・9は株価420%上昇・上海上場時の調達額80億元についての回**である。
  いずれも上場来の相対的な数字・特定時点の調達額であり、現在の時価総額そのもの
  ではないことに注意すること
- **スライド16は香港上場の狙い(発表内容)についての回**であり、具体的な調達目標額・
  上場時期は公表されていないことを明示する内容のため、金額や日付を推測で埋めないこと
- **スライド20は「確認できなかったこと」の一覧**であり、削除しないこと(香港上場の
  具体的な時期・発行株式数・調達目標額・時価総額・NVIDIA製品との性能比較を非公開として
  明示している)
- **スライド25は誇張回避・特定企業推奨回避についての注記**である。タイトル・冒頭フックは
  注目を集める表現を使っているが、本文の内容は誇張しておらず、Moore Threads等への
  投資・利用を強く推奨していない旨を明示しているため、この注記スライドは保持すること
- **スライド26は当社の推測であることを明記したカード**である。断定形や公式見通しの
  ように書き換えないこと
- 実在企業名(Moore Threads、NVIDIA等)はテキストとしてのみ扱い、ロゴ・商標・肖像は使用しない
