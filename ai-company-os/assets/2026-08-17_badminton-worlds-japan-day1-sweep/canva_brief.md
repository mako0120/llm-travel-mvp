Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「バドミントン世界選手権2026開幕、日本勢が初日5戦全勝で好スタート」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: バドミントン・日本代表に関心がある一般視聴者。専門知識がない前提で、
  世界選手権の基礎知識から5試合の数字での深掘りまで丁寧に分解して説明するスライドを
  設けている。「確認できた5試合すべてに勝利」という範囲限定の表現を保ち、断定を
  避ける構成になっている
- パレット(HEX、slate_azureプリセット): Primary `#2B3A55` / Base `#D3E4F5` /
  Accent `#1F8FD6`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在選手の写真・肖像・実在団体(BWF等)の
  ロゴ・商標は使用しない、図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` / `diagram` は含まれない
(構成比を示すデータや、選手コメントの一次引用、概念図で示すべき内容がないため)。

## このデッキ固有の注意(断定回避が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「確認できた5試合すべてに
  勝利」という事実そのものをフックにしている。フック性の強い表現(「まさかの」
  「衝撃の」等)は許容するが、確認できていない選手の結果まで含めて「全員勝利」と
  書き換えないこと
- **スライド9〜18は5試合それぞれのスコアを扱う核心スライド**であり、対戦相手名・
  スコア・シード情報を`deck_spec.json`の記載どおり正確に転記すること
- **スライド19・21・22は確認できていないことを示すスライド**であり、削除しない
  こと。他の日本人選手の初日成績が未確認であることを明示する
- **スライド26は断定的な表現を避ける理由を扱うスライド**であり、削除しないこと
- 実在選手名(田中湧士選手・奈良岡功大選手・霜上雄一選手・野村拓海選手・熊谷翔選手・
  西大輝選手・大澤佳歩選手・田部真唯選手)はテキストとしてのみ扱い、写真・肖像・
  実在団体(BWF等)のロゴ・商標は使用しない
- 対戦相手の国名・地域名(中国・台湾・フランス・オーストリア)は所属としてのみ扱い、
  国・地域間の優劣評価は一切行わない。政治的な話題には触れない
- 特定企業・製品・団体の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
