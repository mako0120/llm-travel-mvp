## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない(推移
  データ・直接引用が本テーマにはないため、数字は`big_stat`と`table`で扱った)。

## このデッキ固有の注意

- **スライド19・20「94%超短縮」「15倍」は、Corma社自身の発表による自社測定値**である。
  必ず「自社発表」「第三者検証済みとは記載されていない」という注記を併記すること。
  客観的に検証済みの事実であるかのような書き方に変えないこと
- **スライド15「創業チーム構成」でイスラエルの精鋭諜報部隊「Unit 8200」出身者に言及**
  している。事実として淡々と記載するのみとし、地政学的な論評・意見・評価を一切追加
  しないこと
- **スライド21「数字を読むときの注意点」は削除しないこと**。94%超・15倍という数字への
  注意喚起の核心部分である
- **スライド18「デプロイ先とされる業界」は業界名のみ**であり、具体的な企業名を創作して
  追加しないこと(社名は不明)
- **スライド25「政治的中立性についての方針」・スライド26「確認できなかったこと」は
  削除しないこと**
- 実在人物名(Alon Pluda氏)・実在企業名(Corma、Sequoia Capital、Khosla Ventures、
  Coatue等)はテキストとしてのみ扱い、写真・肖像・ロゴは一切使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`cobalt_violet`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
