# 「評価額、シードから数か月で『約3倍』に――継続学習型AIエージェント基盤Trajectoryがシリーズ Aで4,000万ドルを出典付きで整理する」(2026-08-11前後発表・2026-08-13・189本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
定期実行パイプラインの189本目。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠
- 2026年8月11日、サンフランシスコ拠点のAI研究・プロダクトラボTrajectoryが、
  Sequoia Capital主導のシリーズAで4,000万ドルを調達し、評価額3億ドルに達したと
  報じられた(着手日2026-08-13の2日前、`docs/06_Content_R&D.md`の「着手日を含めて
  2日以内」という鮮度基準を満たす)
- cryptobriefing.com・aiweekly.co・Odaily・KuCoinという、独立した複数の情報源が
  一致して報道しており、`docs/06_Content_R&D.md`モードB(バイラル優先モード)の
  「複数の信頼できるメディアが話題と報じている」という実証済みの話題性基準を満たす
- 「使うほど賢くなるAI」という分かりやすいコンセプト、評価額が数か月で「約3倍」に
  なったという急成長ぶり、DeepMind・OpenAI・Appleなど豪華な出身企業の人材が集結して
  いる点が分かりやすいフックになる

## 適用したルール

- 30枚デッキ、bullets比率33.3%(10/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成)
- palette_presetは`steel_amber`を使用(188本目がslate_azureのため、8色ローテーション
  の新サイクル開始として指定通り採用)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「評価額、シードから数か月で
  『約3倍』に」というフックを即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(Trajectoryとは・継続学習とは・静的モデルとの比較)+
  読者の立場別(投資動向を追う立場・AI技術動向を追う立場・AIサービス導入を検討する
  立場)の実践的示唆(スライド20)
- 評価額の推移(1.15億ドル→3億ドル)を`bar_chart`でネイティブグラフ化し、単なる
  文字の羅列にしない
- 出典のない数字は作らず、確認できなかったこと(技術的な仕組み・顧客事例・株主
  構成比率・GA時期等)は正直に「不明」と一覧化した(スライド21・22)
- 評価額の倍率について、報道の表現(「約3倍」)と単純計算(約2.6倍)の差を隠さず
  両方明記した(スライド10・23)
- 特定企業・製品の利用を強く推奨する結論にはしていない
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張、技術的優位性の断定は
  一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- 同一レイアウト4連続以上チェック・bullets比率40%以下チェック(33.3%) → 合格
- `generate_dialogue_script.py --deck deck_spec.json`によるスライド数一致・
  連番検証 → 合格(30スライド、目安約7分)
- 著作権・品質自己評価: 93点/100点(85点以上のため修正不要)

## リスク配慮

- Trajectoryの技術的優位性・将来性を断定・誇張する表現は使わず、報じられている
  方向性の事実紹介にとどめている(スライド6・7・16・19)
- 評価額の倍率表現(「約3倍」)は報道の言い回しであり、単純計算では約2.6倍で
  あることを隠さず併記している(スライド10・23)
- 技術的な仕組みの詳細・顧客事例・株主構成比率・GA時期など、報道からは確認
  できなかった項目をスライド21・22で一覧化し、正直に「不明」として扱っている
- 見出しの印象(「画期的な技術がすでに実用化」)と実際の内容(資金調達の発表で
  あり性能評価の発表ではないこと)のギャップをスライド24で明示している
- Trajectory・投資家(Sequoia Capital、Jeff Dean氏、Fei-Fei Li氏等)への政治的
  評価(良い/悪いの価値判断)は一切行っていない
- 実在企業名・実在人物名はテキストとしてのみ扱い、ロゴ・商標・肖像は使用しない
- 確認できていない直接引用コメントは作文せず、`quote`レイアウトは使用していない
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 公開・投稿はまだ行っていない
