## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `quote` は含まれない(推移データは
  評価額の2ラウンド比較のみで`bar_chart`が最適。構成比を示すデータは扱っていない。
  出典で直接確認できたCEOコメントの引用文がなく、要旨を作文しない方針のため
  `quote`レイアウトは使用していない)。

## このデッキ固有の注意

- **スライド1・2は本テーマのコールドオープン(「評価額、シードから数か月で『約3倍』に」)**
  である。資金調達の事実紹介であり、技術的優位性の断定表現に書き換えないこと
- **スライド6・7・16はキーワード「継続学習」を説明するスライド**である。具体的な
  技術方式は未確認であるため、確定した仕組みであるかのような表現に書き換えないこと
- **スライド10は評価額の倍率表現を扱うスライド**である。「約3倍」という報道表現と
  「約2.6倍」という単純計算の両方を必ず残すこと(片方だけに書き換えない)
- **スライド13は出身企業の一覧であり、個々のメンバーとの対応関係を断定しないこと**
  (報道では企業名の括りのみで紹介されている)
- **スライド15はエンジェル投資家(著名創業者)の紹介スライド**であり、個人名が
  未確認であることを保持したまま、勝手に実在の個人名を補って書き換えないこと
- **スライド21・22は「確認できていないこと」の一覧**であり、削除しないこと
- **スライド24は見出しの印象と実際の内容のギャップを示す核心スライド**である。
  「画期的な技術がすでに実用化された」等の誇張表現に書き換えないこと
- **スライド26は誇張回避・中立性を明示するスライド**であり、削除しないこと
- 実在企業名(Trajectory、Sequoia Capital等)・実在人物名(Ronak Malde氏、
  Jeff Dean氏、Fei-Fei Li氏等)はテキストとしてのみ扱い、ロゴ・商標・肖像は
  使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
