## 適用したルール

- 30枚デッキ、bullets比率20%(40%上限クリア)、同一レイアウト連続なし

  「AIエージェントが脱走した、その一週間後。人間は『AIを見張るAI』に
  1億1,300万ドルを積んだ」という煽り気味だが事実に基づく一文を即座に提示
- 初心者向け前提知識スライド(コントロールプレーンの仕組み) + 実践的な
  整理(導入検討企業が確認すべきこと)

  より後退していることをスライド16で正面から扱う

  スライド18・19で明確に区別
