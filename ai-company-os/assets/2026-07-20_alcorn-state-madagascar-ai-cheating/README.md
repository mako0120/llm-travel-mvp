# AIに丸投げした学生35人中32人が、「マダガスカル」のたった1語で全員バレた(2026-08-04・定期実行130本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話ナレーション・
スライド連動モードで制作。実在の個人(Jason Gibson氏、公人ではなく大学教員)と、
匿名の学生集団(35名)の両方が関わる話題のため、双方への配慮を徹底したテーマ。

## 選定理由

- ミシシッピ州Alcorn State Universityの歴史学教授Jason Gibson氏が、中間試験の
  課題文に白背景・白文字で仕込んだ隠し指示により、AIチャットボットに丸投げして
  提出した学生を可視化した話題
- Fox News・Futurism・The Register・Upworthy・TODAY.com・RedStateという、独立した
  複数のテック・カルチャー専門メディアが報じている
- 「たった1つの隠し単語で、35人中32人が同じミスをした」という意外性の強い
  フックがあり、報道各社も軽妙な切り口で伝えている「愉快で示唆に富む」話題で
  あり、バズ路線の見出し方針と親和する

## 鮮度についての正直な開示(重要・良好)

最初の報道相当となるGibson氏本人のTikTok投稿(2026年7月20日ごろ)から、続報
The Register(2026年7月28日)、そして**着手日前日である2026年8月3日**の
RedState報道まで続いている。`docs/06_Content_R&D.md`の鮮度基準(着手日の前日
以内)を満たす良好な鮮度の話題である。着手日(2026年8月4日)当日の続報は、
本調査の時点ではまだ確認できていない。

## 見出し表現の方針についての正直な開示

見出し・タイトルの表現は「バズる人気」優先の意外性を強調した表現にしている
(例: 「AIに丸投げした学生35人中32人が、「マダガスカル」のたった1語で全員
バレた」)。**ただし、数字の創作・出典のない断定・特定企業の過度な推奨・
政治的中立性の逸脱は、これまでどおり一切行っていない。**

さらに、本テーマは実在の個人(教授)と匿名の学生集団の両方を扱うため、以下を
徹底した。学生は氏名等を一切使用せず「32人」「2人」「1人」という人数のみで
扱い、行動の事実(コピペしてAIに丸投げした)は紹介するが人格・能力を否定する
表現は使用しない。Gibson氏についても、悪意や陥れる意図があったという憶測は
行わず、報じられた事実のみを紹介している。

## 既存テーマとの関係(重複でないことの確認)

`ai-company-os/assets/`配下を確認したところ、Alcorn State University、Jason
Gibson氏、または「マダガスカル」の隠しテキストを主題として扱った既存テーマは

## 適用したルール

- 30枚デッキ、bullets比率23.3%(40%上限クリア)、同一レイアウト連続なし
  (`build_deck.py`のビルド時検証を通過)
- **コールドオープン(バズ路線)**: 冒頭(1枚目・ナレーション1行目)で
  「35人中32人。同じ課題を出したのに、驚くほど同じ間違いをした学生がいます」
  という、話題の核心となる数字を即座に提示
- **鮮度の良好さへの言及**: 着手日前日の報道まで含む点を専用スライド(25)
  で明示している
- 初心者向け前提知識スライド(9〜10: 人間が読む場合とAIに読ませる場合の比較、
  仕掛けが機能した理由)+ 実践的な整理(誰が・いつ・何が起きたか、報道の時系列)
- 「これで何が変わるか」に相当する転の章として、AI利用と教育現場をめぐる
  論点(21〜22)を、特定の是非を断定せず中立的に扱った
- 特定企業・特定製品の利用を強く推奨する結論にはしていない
- **実在個人・匿名学生への配慮**: Gibson氏の写真・肖像・ロゴ、学生の個人を
  特定できる情報は一切使用しない方針を`canva_brief.md`に明記。引用は指定
  された実際の指示文・回答例のみに限定
- **数字の視覚化**: 「35人中32人」という結果をbig_stat(11)とpie_chart(12)の
  2種類で視覚的に提示し、bulletsで数字を羅列するだけにしていない

## リスク配慮

- 実在の個人(Jason Gibson氏、公人ではなく大学教員)と、匿名の学生集団(35名)の
  両方を扱うテーマのため、以下を徹底した: 学生は匿名の人数のみで扱い個人を
  特定できる情報を使用しない、学生を揶揄する表現を使わない、Gibson氏の動機に
  ついての憶測を行わない、写真・肖像の不使用
- 具体的な再生回数・フォロワー数・大学の処分内容などの数字は確認できておらず、
  専用スライド(23)で正直に開示している
- 数字・引用は報道された内容のみを扱い、創作していない
- 配色は通常ローテーションしている3プリセット(navy_gold・forest_sand・
  slate_azure)ではなく`impact_red`プリセットを、可読性のための`muted`色の
  個別上書きとあわせて採用した。採用理由と上書き内容は`canva_brief.md`に
  明記している
- 政治的リスク・著作権リスクはなし
