## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| quote | 引用レイアウト(引用元を帰属に明記) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(推移データ・
  構成比のデータが限られたため、数字は `big_stat` と `table` で扱っている)。

## このデッキ固有の注意

- **スライド7・15・16の「1,900万ドル」「30%速い」「2,000超」は本テーマの
  中心となる数字**である。スライド15の効果数値は**顧客報告値であり第三者検証
  ではない**旨をキャプションで必ず残すこと
- **スライド18・19の`quote`はCEO Varun Krishnamurthy氏・President Rahul
  Shivkumar氏のコメントを複数媒体経由で引用**している。帰属テキストを必ず
  残すこと
- **スライド21は「資金調達のクローズ日と公表日にずれがある」という正直な
  開示**であり、削除しないこと
- **スライド22は「日本国内の展開は不明」という開示**であり、保持すること
- スライド28は推測であることを本文に明記している。断定形に書き換えないこと
- 実在企業名(Assured、Insight Partners、Houston Methodist等)はテキストと
  してのみ扱い、ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない。移植時も断定的な推奨
  文言を追加しないこと
