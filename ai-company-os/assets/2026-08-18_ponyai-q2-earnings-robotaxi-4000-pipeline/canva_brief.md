## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `steps` / `quote` は
含まれない。時系列で複数時点を比較できる推移データ(四半期を跨いだ複数期の
売上高等)が本調査の範囲では確認できていないため、グラフ化による誤解(推移が
複数期にわたって確認済みであるかのような印象)を避け、単一時点・単一指標の
数字は`big_stat`/`cards`/`table`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「まさかの691%増」という
  フックを提示しつつ、直後に発表日・総売上高・ロボタクシー売上という正確な事実を
  添えている。フック性の強い表現は許容するが、事業の採算性を保証するような表現に
  書き換えないこと
- **スライド7・8・10・12・13・15・17は核心となる数字(総売上高3620万ドル・
  前年比68.8%増、ロボタクシー売上1210万ドル・前年比691.2%増、有償運行売上
  800%超増、保有台数1975台、年内見込み3500台超、海外パイプライン4000台超、
  欧州5都市2000台超)を扱う核心スライド**であり、数字を混同・省略・丸めないこと
- **スライド14は『保有台数(実績)』と『展開パイプライン(契約済み計画)』を
  区別するスライド**であり、この2つの数字を同一視する表現に書き換えないこと
- **スライド22・23・24は稼働開始予定日・許認可進捗・1台あたりの採算性が
  不明であることを示すスライド**であり、具体的な内容を創作しないこと
- **スライド21は見出しの印象(4000台超がすでに稼働している)と実際に確認できている
  内容のギャップを示すスライド**であり、削除しないこと
- **スライド26は誇張回避・確認ポイントを明示するスライド**であり、削除しないこと
- Pony.ai・Uber・Bolt・Stellantis・ComfortDelGro等の実在企業のロゴ・商標は
  使用しない
- Pony.aiの事業(ロボタクシーサービス)は事実として紹介するのみで、利用・投資を
  推奨する表現に書き換えない(スライド5・25)
