# メジャーの歴史が、日本人4人によって塗り替えられた。(186本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話ナレーション・
スライド連動モードで制作。

カテゴリ: `sports`

## 選定理由

- 2026年8月11日(現地時間)、シカゴ・カブスの鈴木誠也選手が、元読売ジャイアンツ
  所属の投手マイコラス(Miles Mikolas)から8回にソロ本塁打を放ち20号に到達
- これにより、村上宗隆選手(ホワイトソックス)・岡本和真選手(ブルージェイズ)・
  大谷翔平選手(ドジャース)に続き、鈴木選手も同一シーズンで20本塁打に到達し、
  **日本人選手4人が同一シーズンで20本塁打を達成するのはメジャーリーグ史上初**となった
- 鈴木選手は、大谷選手に続き史上2人目となる4年連続20本塁打も達成
- 出典: スポーツ報知(dメニューニュース経由)「史上初の日本人２０本塁打カルテット
  誕生!鈴木誠也が元巨人マイコラス撃ち豪快弾で笑顔 村上、岡本、大谷に続く２０号…
  ４年連続２０発は史上２人目」、THE ANSWER(Yahoo!ニュース経由)「『凄い時代に
  なった』メジャー日本人、一昔前ではあり得ない衝撃記録」
- **鮮度基準について正直な開示: 発生日(2026年8月11日)は着手日(2026年8月13日、
  UTC暦日切り替え後の初回)から2日前。** `docs/06_Content_R&D.md`の鮮度基準(着手日を
  含めて2日以内)を満たしており、例外的な妥協採用ではない
- 「メジャーリーグ史上初」という明確なフックと、4選手という分かりやすい人数、
  具体的な本塁打数の数字が視聴者の関心を引きやすい強い材料になる

## 適用したルール

- 30枚デッキ、bullets比率26.7%(8/30、40%上限クリア)、同一レイアウト連続は最大2
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_stat/bar_chartで図解化
  (選手本人のコメントが確認できなかったため`quote`は使用せず)
- **コールドオープン(バズ路線)**: 冒頭(1枚目・ナレーション1行目)で「日本人選手
  4人が、同一シーズンで20本塁打に到達しました」という出典に基づく事実を即座に
  提示し、挨拶・前置きを省いた
- **初心者向け前提知識スライド**: 「本塁打(ホームラン)」とは何か(スライド7)、
  「シーズン20本塁打」の節目としての意味(スライド8)を、野球のルールに不慣れな
  視聴者向けに平易な言葉で説明
- **これで何が変わるか(視聴者にとっての意味)**: スライド22で扱う
- **確定事実・不明点を明確に区別**(スライド10・24・25が該当)
- 4選手全員を公平に扱い、特定の選手のみを過度に持ち上げる表現・対戦投手を
  貶める表現をしない旨を専用スライド(26)で明記

## リスク配慮

- 4選手(村上選手・岡本選手・大谷選手・鈴木選手)全員を公平に扱い、特定の選手のみを
  過度に持ち上げる表現・他選手と比較して優劣を強調する表現をしていない(スライド26)
- 対戦相手のマイコラス投手を貶める表現もしていない(スライド26)
- シーズン終了時点の最終本塁打数、4選手それぞれの詳細な打撃成績、過去に日本人選手
  3人が20本塁打を達成した際の詳細、各選手の正確な到達日、選手本人のコメントは
  確認できておらず、一切創作していない(スライド10・22・24・25・27)
- 実在選手名・球団名は事実として扱うが、肖像・ロゴは使用しない
- 本テーマはMLB(本パイプラインの提供元Anthropicとは無関係)に関するものであり、
  自己言及リスク対応は不要と判断した
