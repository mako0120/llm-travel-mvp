## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| line_chart | 折れ線グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `quote` は含まれない(構成比を示すデータや、
確認済みの選手コメント全文がないため)。

## このデッキ固有の注意(個人の活躍とチーム結果を混同しないことが最重要)

- **スライド1・2は本テーマのコールドオープン(「32分アシスト、38分ダイビング
  ヘッド」)** である。フック性の強い表現は許容するが、フェイエノールトが
  勝利したかのような表現には書き換えないこと(実際は2-2の引き分け)
- **スライド2・8・15・19・20は個人の活躍とチーム結果を明確に区別する核心
  スライド**である。上田選手個人の今季初ゴール・初アシストと、フェイエノールトの
  2-2引き分けという結果は別のものであり、混同・統合した表現に書き換えないこと
- **スライド18は「移籍期限前の最後のアピール」の正確な意味を説明するスライド**
  であり、「移籍が決まった」等の断定表現への書き換えは行わないこと
- **スライド24は見出しの印象(快勝・移籍確定等)と実際の内容のギャップを
  示すスライド**であり、削除しないこと
- **スライド25・26は「確認できていないこと」の一覧**であり、削除しないこと
- **スライド20は誇張回避を明示するスライド**であり、削除しないこと
- 実在選手名(上田綺世選手・ゼヒール選手・ハジ・ムサ選手)はテキストとしてのみ
  扱い、写真・肖像・実在クラブのロゴ・エンブレム・商標は使用しない
- 特定企業・製品・チームの宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(navy_goldプリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
