# 「上田綺世、豪快ダイビングヘッドで今季初ゴール&初アシスト――フェイエノールトはまさかの2-2引き分け」(2026-08-16試合・2026-08-17制作)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
2026年8月16日(現地時間)、オランダ1部フェイエノールト対ゴーアヘッド・イーグルス戦
(開幕2戦目)での、日本代表FW上田綺世選手の今季初ゴール(ダイビングヘッド)・
初アシストを、「個人の活躍とチーム結果(2-2の引き分け)を混同しない」ことを軸に構成
している。

## 選定理由

- 対象ジャンル「海外/国内で活躍する日本人」枠
- 2026年8月16日、オランダ1部フェイエノールト所属の日本代表FW上田綺世選手(27)が
  本拠地でのゴーアヘッド・イーグルス戦に先発出場し、32分に今季初アシスト、38分に
  ダイビングヘッドで今季初ゴールを記録した(着手日2026-08-17を基準に「着手日を
  含めて2日以内」という鮮度基準を満たす)
- livedoor News(2件)・Yahoo!ニュース(SOCCER DIGEST Web配信)・サッカーダイジェスト
  Web・チバテレ+プラス・東スポWEB・フットボールチャンネルという6媒体以上が数値・
  経緯を一致させて報じている
- 前シーズン得点王(25ゴール)という実績、豪快なダイビングヘッド、移籍市場の
  クローズ間際というタイミングという複数のフックが重なる強いストーリー性がある
  (`research/2026-08-17_theme-evaluation-round143.md`参照)

## 適用したルール

- 30枚デッキ、bullets比率30%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成)
- palette_presetは指示どおり`navy_gold`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「32分アシスト、38分ダイビング
  ヘッド」という具体的な数字によるフックを即座に提示し、挨拶・前置きを省いた
- **個人の活躍とチーム結果の明確な区別(本テーマの核心)**: 上田選手個人の
  今季初ゴール・初アシストと、フェイエノールトの2-2引き分けという結果を混同せず、
  big_stat/comparison/diagram/tableで複数回・複数形式で対比しつつ、勝利していない
  ことを正直に扱った
- 初心者向け前提知識スライド(選手紹介・「アシスト」「ダイビングヘッド」「今季初」の
  用語解説)+ 読者の立場別(サッカーファン・移籍報道を追う立場・発信する立場)の
  実践的示唆(スライド22)
- 出典のない数字は作らず、確認できなかった項目(移籍先・移籍金・今シーズン通算
  成績・年俸等)は正直に「不明」と明記した(テーブル・スライド25・26)
- 誇張回避: 「移籍が決まった」「快勝した」等、確定していない・実際と異なる表現を
  避け、断定的な将来予測(移籍の成否含む)もしない旨を専用スライドで明示した
  (スライド20)
- 「移籍期限前の最後のアピール」という報道フレームを、一部メディアの文脈紹介として
  正確に扱い、移籍の確定事実として扱わなかった(スライド18)
- 見出しの印象(「快勝した」「移籍が決まった」等)と実際の内容(2-2の引き分け、
  移籍は未確定)のギャップを専用スライドで明示した(スライド24)
- 実在選手(上田綺世選手・ゼヒール選手・ハジ・ムサ選手)、実在クラブ(フェイエ
  ノールト・ゴーアヘッド・イーグルス)の写真・肖像・ロゴ・エンブレムは使用せず、
  抽象的な図解・アイコンのみで構成した
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張、チーム勝利を示唆する
  表現は一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- 同一レイアウト4連続以上チェック・bullets比率40%以下チェック(30%) → 合格
  (`build_deck.py`のビルド時検証を通過)
- `generate_dialogue_script.py --deck deck_spec.json` によるスライド数一致・
  スライド連番検証 → 合格(30スライド全カバー)
- 著作権・品質自己評価: 95点/100点(85点以上のため修正不要)

## リスク配慮

- 個人の活躍(上田選手)とチーム結果(2-2の引き分け)を混同・統合した誇張表現を
  一切使っていない
- フェイエノールトが勝利したかのような表現をタイトル・本文に使わず、実際の結果
  (2点リードを守れず2-2の引き分け)を正直に扱っている
- 「移籍期限前の最後のアピール」を確定した移籍事実として扱わず、報道の文脈紹介
  であることを明示している
- 移籍先・移籍金・今シーズン通算成績・年俸など確認できなかった項目を「不明」として
  正直に扱っている
- 実在選手・実在クラブの写真・肖像・ロゴは使用していない
- 政治的中立性を保っている(本テーマはスポーツニュースの紹介であり、政治的評価は
  含まない)
- 特定企業・製品・チームの過度な推奨・宣伝は行っていない
- 公開・投稿はまだ行っていない
