## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「Zapierのライバル『Relay』が消える。創業者はGoogleへ電撃復帰、
  Chrome担当VPに」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI/テック業界のニュースに関心がある一般視聴者。専門知識がない
  前提で、ワークフロー自動化AI・VP職の基礎知識から、事業終了とキャリア復帰の
  時系列まで丁寧に分解して説明するスライドを設けている
- パレット(HEX、forest_sandプリセット): Primary `#24523F` / Primary Dark
  `#17362A` / Base `#E7DCC2` / Base Soft `#BFAE84` / Accent `#C1622D`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在人物の写真・肖像や実在企業の
  ロゴ・商標は使用しない、図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `quote` は含まれない
(構成比・推移データや、確認済みの人物コメントがないため)。

## このデッキ固有の注意(鮮度の混同回避と未確認情報の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「Relayが消える」という
  フックを提示しつつ、直後に「本当の新情報は創業者のGoogle復帰」と正確な
  事実を添えている。フック性の強い表現は許容するが、事業終了自体を新規性の
  高い出来事のように書き換えないこと
- **スライド4・7・20は『鮮度の混同を避ける』ための核心スライド**であり、
  Relay事業終了(2026年7月発表・背景)とバンク氏のVP就任(2026年8月17日発表・
  核心)の時期の違いを明示している。削除・統合しないこと
- **スライド8・9・10はRelay事業終了の日程(無料8/15終了・有料9/14終了予定)を
  扱う核心スライド**であり、日付を混同・省略・丸めないこと
- **スライド11・12・13はバンク氏のGoogleキャリア(Timeful買収2015年・在籍
  6年間)を扱う核心スライド**であり、数字を混同・省略しないこと
- **スライド17・18・19・27は『移籍スタッフの人数』『事業終了の具体的理由』が
  未確認であることを示すスライド**であり、具体的な人数や理由を創作して
  埋めないこと
- **スライド25は見出しの印象(全員移籍等の誤解)と実際の内容のギャップを示す
  スライド**であり、削除しないこと
- **スライド24は誇張回避・中立性を明示するスライド**であり、削除しないこと
- 実在人物名(ジェイコブ・バンク氏)はテキストとしてのみ扱い、写真・肖像は
  使用しない。実在企業(Google・Relay・Zapier・Chrome)のロゴ・商標も使用しない
- 特定企業・製品の宣伝にはしていない(中立的な事実紹介)

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`forest_sand`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
