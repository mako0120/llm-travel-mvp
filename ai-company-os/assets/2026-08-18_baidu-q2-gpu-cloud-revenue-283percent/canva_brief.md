## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| bar_chart | 棒グラフ(2カテゴリ、伸び率%の比較) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `steps` / `quote` は含まれない。
時系列で複数時点を比較できる推移データ(四半期を跨いだ複数期の売上高そのもの等)が
本調査の範囲では確認できていないため、単一時点・単一指標の数字は`big_stat`/
`cards`/`table`で扱い、GPUクラウドの伸び率推移(前四半期184%→今四半期283%)のみ
`bar_chart`(2カテゴリの棒グラフ)で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「衝撃の283%増」という
  フックを提示しつつ、直後に発表日・広告収益・AIクラウド売上という正確な事実を
  添えている。フック性の強い表現は許容するが、事業の採算性を保証するような表現に
  書き換えないこと
- **スライド7・8・9・10・11・12・13は核心となる数字(広告収益前年比19%減少、
  AIクラウド・インフラ売上高73億人民元・前年比50%増、GPUクラウド売上高前年比
  283%増・前四半期184%増から加速、Baidu Core全体前年比25%成長)を扱う核心
  スライド**であり、数字を混同・省略・丸めないこと
- **スライド14・20は『広告収益減少』と『GPUクラウド急成長』を単純に相殺した
  金額として計算していないことを示すスライド**であり、この2つの数字を差し引き
  計算した表現に書き換えないこと
- **スライド21・22・23・26は純利益・営業利益の具体的数値、次四半期以降の
  ガイダンス、GPUクラウド需要の持続性・供給体制、業種別の詳細な内訳が不明である
  ことを示すスライド**であり、具体的な内容を創作しないこと
- **スライド20は見出しの印象(広告事業はもう終わりのはず等)と実際に確認できて
  いる内容のギャップを示すスライド**であり、削除しないこと
- **スライド25は誇張回避・確認ポイントを明示するスライド**であり、削除しないこと
- Baidu等の実在企業のロゴ・商標は使用しない
- Baiduの事業(AIクラウド・GPUクラウド)は事実として紹介するのみで、利用・投資を
  推奨する表現に書き換えない(スライド5・24)
