## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `quote` / `bar_chart` / `line_chart` / `pie_chart` は含まれない。CEOブログの
  原文引用は確認できていないため`quote`は使わず(スライド13でその旨を明示)、時系列推移や
  構成比を示す確定した数値データも公表されていないためチャート類は使用していない。

## このデッキ固有の注意

- **スライド4・25は鮮度基準の例外採用(発表から4日前、3ラウンド連続)を明示する回**である。
  削除・簡略化せず、探索を尽くしても2日以内の候補が見つからなかった旨、3ラウンド連続で
  ある旨、この頻度自体が懸念だと評価表自身が指摘している旨を保持すること
- **スライド13はCEOのブログ投稿について、原文への直接アクセスができておらず具体的な
  引用文を掲載していない旨を明示する回**である。Canva版でも架空の引用文を追加しないこと
- **スライド15はSunoの既存テーマ(2026-07-21、評価額成長の話題)との違いを明示する回**
  である。重複ではないことを示す内容のため、削除・簡略化しないこと
- **スライド16は、本テーマがSunoという1企業の発表内容についての事実報道であり、訴訟
  当事者のどちらかを支持・批判する立場を取らないことを明示する回**である。削除・簡略化
  しないこと
- **スライド17は「確認できなかったこと」の一覧**であり、削除しないこと(技術の具体的な
  仕組み、ダウンロード制限の数値、対応する訴訟・原告名、導入時期を非公開・未確認として
  明示している)
- **スライド24は誇張回避・中立性についての注記**である。タイトル・冒頭フックは注目を
  集める表現を使っているが、本文の内容は誇張しておらず、訴訟当事者いずれの立場も強く
  支持していない旨を明示しているため、この注記スライドは保持すること
- **スライド22は当社の推測であることを明記したカード**である。断定形や公式見通しの
  ように書き換えないこと
- 実在企業名(Suno)への言及を含むが、ロゴ・商標は使用しない
- 具体的な訴訟・原告名(レコードレーベル名・アーティスト団体名)は確認できていないため、
  Canva版でも特定・推測記載をしないこと

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`indigo_cyan`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
