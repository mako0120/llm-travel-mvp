## 概要欄(description)案

```
2026年8月9日、TechCrunchが「Anthropicが Claude Codeの自動実行モード『Auto Mode』を
既定設定にする」と報じました。これまで操作のたびに人間の承認を求めていたClaude Codeは、
2026年8月14日からPro・Max・Teamプランの全アカウントで、「不可逆的・破壊的・環境外に
影響する」と判定された操作以外を自動的に実行するようになります。

1,053名の有償テスターを対象とした社内調査によれば、Auto Modeは有害な操作の89%を検知した
一方、人間によるレビューでは13.6%しか検知できなかったといいます。Claude Codeユーザーは
全許可プロンプトの97%を承認しており、Anthropicは従来の承認プロセスが「反射的なクリック」
と化していたと指摘しています。Auto Mode採用チームはプルリクエスト数が約25%増加したとも
報告されています。Claude Code責任者のBoris Cherny氏はX投稿で「チームは何か月も前から
Auto Modeのみを使っており、承認プロンプトに戻ることは考えられない」とコメントしました。

この動画では、
・そもそも『Auto Mode』とは何か(基礎知識)
```
