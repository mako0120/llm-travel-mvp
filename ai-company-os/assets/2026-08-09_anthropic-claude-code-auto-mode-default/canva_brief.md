## このデッキ固有の注意

- **スライド9・26は「概念図」であり、当社の推測または確認できていない仕組みの模式図**
  である旨のキャプションを保持すること。判定基準の技術的な詳細を断定的に描き直さないこと
- **スライド11〜14は89%・13.6%という調査結果の数字**であり、1,053名の有償テスターを
  対象とした調査であることの出典表記(TechCrunch)を削除しないこと
- **スライド16は「約25%増加」に選択バイアスの可能性がある旨の注記を含む**。この注記を
  省略して数字だけを強調するレイアウトに書き換えないこと
- **スライド17はBoris Cherny氏の直接引用**である。要約による意味の変質を避けるため、
  日本語訳・英語原文をあわせて原文のまま使うこと
- **スライド21は「確認できなかったこと」の一覧**であり、削除しないこと(判定基準の詳細・
  オフ切り替えの可否・セキュリティインシデントの有無を非公開として明示している)
- **スライド24・25は賛否両論と本シリーズの自己言及に関する回**である。本シリーズ自体が
  Claude Codeを使って制作・運用されている点を正直に開示し、自己宣伝にならないよう
  中立的に扱っている内容のため、削除・簡略化しないこと
- 実在企業名(Anthropic)・実在人物名(Boris Cherny氏)はテキストとしてのみ扱い、ロゴ・
  商標・肖像は使用しない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`steel_amber`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
