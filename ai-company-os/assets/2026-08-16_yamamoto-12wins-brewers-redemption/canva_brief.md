## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `quote` は含まれない(推移データ・
構成比を示すデータや、確認済みの選手コメントがないため)。

## このデッキ固有の注意(8/11との対比を保つことが最重要)

- **スライド1・2は本テーマのコールドオープン(「自己最悪級の炎上登板からわずか4日」)**
  である。フック性の強い表現は許容するが、8/11の内容を軽視・美化する書き換えは
  しないこと
- **スライド7・8・9・11・12は8/11(Before)と8/15(After)の数字を扱う核心スライド**
  である。8/11の数値(4回2/3・99球・6安打・6失点)は既存テーマ
  `2026-08-11_yamamoto-career-worst-outing-angels`の確定事実であり、上書き・
  改変・美化は一切しないこと。与四死球・奪三振など片方の出典にしかない項目を
  「不明」から確定値に書き換えないこと
- **スライド20は「好不調の波は野球競技の一般的な性質」であることを明示するスライド**
  である。「終わった」「限界」等の断定的なネガティブ表現、逆に「絶好調確定」等の
  断定的なポジティブ表現、どちらへの書き換えもしないこと
- **スライド24は見出しの印象(完全復活等)と実際の内容のギャップを示すスライド**
  であり、削除しないこと
- **スライド25・26は「確認できていないこと」の一覧**であり、削除しないこと
- **スライド23は誇張回避・敬意・中立性を明示するスライド**であり、削除しないこと
- 実在選手名(山本由伸選手)はテキストとしてのみ扱い、写真・肖像・実在チームの
  ロゴ・商標は使用しない
- 特定球団・製品の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`navy_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
