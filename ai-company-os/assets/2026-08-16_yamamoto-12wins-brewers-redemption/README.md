# 「山本由伸、渡米後最多タイ12勝目――自己最悪級の炎上登板から、わずか4日での好投」(2026-08-15登板・2026-08-16制作・本日2本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
2026年8月15日(日本時間)の対ブルワーズ戦の好投を、その4日前(8月11日、対エンゼルス戦)
の自己最悪級の不振との対比で伝えることを軸に構成している。

## 選定理由

- 対象ジャンル「海外/国内で活躍する日本人」枠
- 2026年8月15日、ドジャースの山本由伸投手が対ブルワーズ戦で6回1失点9奪三振の
  内容で今季12勝目(渡米後最多タイ)を記録した(着手日2026-08-16の1日前、
  `docs/06_Content_R&D.md`の「着手日を含めて2日以内」という鮮度基準を満たす)
- Yahoo!ニュース(J SPORTS配信)・Full-Count・デイリースポーツ・ベースボールチャンネル
  という複数のスポーツ専門メディアが数値を一致させて報じている
- 直近テーマ(`2026-08-11_yamamoto-career-worst-outing-angels`、自己最悪級の6失点)
  からわずか4日での立て直しという対比が、強いストーリー性・フックになる
  (`research/2026-08-16_theme-evaluation-round137.md`参照)

## 既存テーマとの関係(重複でないことの確認)

作業開始時に`ai-company-os/assets/`配下を`yamamoto`で検索し、既存3件
(`2026-07-27_yamamoto-yoshinobu-100wins`・`2026-08-03_yamamoto-yoshida-showdown`・
`2026-08-11_yamamoto-career-worst-outing-angels`)を確認した。いずれも扱う試合・
出来事が異なり重複ではない。特に8/11テーマとはフォローアップ関係にあり、8/11の
確定事実を「Before」として正確に引用しているが、8/11テーマの内容をそのまま複製・
再掲してはいない(詳細は`research.md`「既存テーマとの関係」を参照)。8/11テーマ
ディレクトリ自体は読み取りのみで一切変更していない。

## 適用したルール

- 30枚デッキ、bullets比率30%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成)
- palette_presetは`navy_gold`を指示通り使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「自己最悪級の炎上登板から
  わずか4日」というフックを即座に提示し、挨拶・前置きを省いた
- **8/11との対比(本テーマの核心)**: `2026-08-11_yamamoto-career-worst-outing-angels`
  の確定事実(4回2/3・99球・6安打・6失点・6四死球・10勝8敗)を一切上書き・
  改変・美化せず「Before」として正確に引用し、8/15の事実(6回・97球・4安打・
  1失点・9奪三振・12勝7敗・渡米後最多タイ・3-1勝利)を「After」として対比した
  (diagram/steps/big_stat/comparison/table/bar_chartで複数回・複数形式で視覚化)
- 初心者向け前提知識スライド(選手紹介・「勝敗」「失点」「奪三振」の用語解説)+
  読者の立場別(野球ファン・ニュースを追う立場・発信する立場)の実践的示唆(スライド22)
- 出典のない数字は作らず、片方の出典にしかない項目(8/11の奪三振数、8/15の
  与四死球数等)は正直に「不明」と明記した(テーブル・スライド25・26)
- 好不調の波は野球競技の一般的な性質であることを説明し、断定的なネガティブ表現
  ・断定的なポジティブ表現のどちらも避けた(スライド20)
- 見出しの印象(「完全復活」等)と実際の内容(1試合の好投という事実)のギャップを
  専用スライドで明示した(スライド24)
- 実在選手の写真・肖像は使用せず、抽象的な図解・アイコンのみで構成した
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張は一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- 同一レイアウト4連続以上チェック・bullets比率40%以下チェック(30%) → 合格
  (`build_deck.py`のビルド時検証を通過)
- `generate_dialogue_script.py --deck deck_spec.json` によるスライド数一致・
  スライド連番検証 → 合格(30スライド全カバー)
- 著作権・品質自己評価: 96点/100点(85点以上のため修正不要)

## リスク配慮

- 8/11の不振な内容は上書き・美化せず、既存資料どおり正確に引用している
- 8/11の内容を揶揄・嘲笑する表現は一切使わず、選手への敬意を保っている
- 好不調の波は野球競技の一般的な性質であることを説明し、断定的な表現を避けている
- 見出しの印象と実際の内容のギャップを明示している
- 次回登板日程・防御率・タイトル争いの状況等、確認できなかった項目を「不明」として
  正直に扱っている
- 実在選手の写真・肖像は使用していない
- 政治的中立性を保っている(本テーマはスポーツ記録の紹介であり、政治的評価は含まない)
- 特定企業・製品・球団の過度な推奨・宣伝は行っていない
- 公開・投稿はまだ行っていない
