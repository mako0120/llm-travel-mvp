- 目的・想定視聴者: 陸上競技・U20世界大会の結果に関心がある一般視聴者、日本人選手の
  国際大会での活躍を追っている視聴者。専門知識がない前提で、種目・年代区分の用語から
  説明するスライドを設けている
- パレット(HEX、navy_goldプリセット): Primary `#1E2761` / Base `#CADCFC` / Accent `#D9A441`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)

- 使用素材のライセンス確認: 無料素材のみ(古賀選手・大会・大学の公式ロゴ・写真・肖像は

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 棒グラフ(3カテゴリ、数値ラベル付き) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `quote` は含まれない。推移データは3点のみで
  `bar_chart`で十分に表現でき、直接引用として確認できたコメントが本調査の範囲になく、
  未確認の発言を引用として創作しないため`quote`は使用していない。

## このデッキ固有の注意

- **スライド4は鮮度についての回**である。決勝の発表日(8月9日)を基準にすれば着手日
  (8月11日)から2日以内であることを明示している。準決勝(3日前)を基準にすると
  基準を上回る点も正直に記載しているため、簡略化しないこと
- **スライド9は旧記録(陳圓将選手、中国)と新記録(古賀選手)の比較回**である。記録という
  事実のみを淡々と扱い、国家間対立を煽る表現を含めないこと。この方針をCanva移植時にも
  厳守すること(見出し・装飾での煽り表現を追加しない)
- **スライド17・22・29は「確認できなかったこと」「見送った切り口」「リスク配慮」の
  一覧**であり、削除しないこと(今後の大会予定・自己ベスト該当性・本人コメントが
  非公開・未確認であることを明示している)
- **スライド21は政治的中立性についての注記**である。中国選手との記録比較の扱い方を
  明示する内容のため、削除・簡略化しないこと
- **スライド23の「0.59秒」は、出典にある2つの確定タイム(13秒54−12秒95)を単純に
  引き算した計算値であることをキャプションで明示している。** 新しい事実であるかのように
  見出しだけを独立させないこと
- 実在選手名(古賀ジェレミー選手、泉谷駿介選手、陳圓将選手)・実在大学名(順天堂大学)は
  テキストとしてのみ扱い、写真・肖像・所属先の公式ロゴは使用しない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`navy_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
