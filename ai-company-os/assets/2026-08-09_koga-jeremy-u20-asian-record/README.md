# 「19歳の大学生が、アジア新記録をたたき出した。」(古賀ジェレミー選手、166本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話ナレーション・
スライド連動モードで制作。

## 選定理由

- 2026年8月8日(準決勝)・8月9日(決勝)、U20世界陸上競技選手権(米国・ユージン)の
  男子110mハードルで、古賀ジェレミー選手(19歳、順天堂大学)が準決勝で12秒95
  (追い風0.3m)を記録し、中国の陳圓将選手が持つU20アジア記録12秒96を0.01秒更新した。
  この記録により2018年大会の泉谷駿介選手以来となる決勝進出を果たし、決勝では
  12秒97を記録して銀メダルを獲得した
- `ai-company-os/research/2026-08-11_theme-evaluation-round98.md`の「候補2(166本目)」
  として、バズ路線スコア74/100で採用
- **鮮度基準について正直な開示: 準決勝は着手日(2026-08-11)から3日前、決勝は2日前。**
  `docs/06_Content_R&D.md`の鮮度基準(着手日を含めて2日以内)は、決勝の発表日
  (8月9日)を基準にすれば満たす。評価表(round98)にも同様の判定が明記されており、
  例外的な妥協採用ではない
- 「アジア記録を更新してからの決勝進出、そして銀メダル」という明確な物語構造、
  19歳の大学生選手という親近感、具体的なタイム(12秒95・12秒96・12秒97)という
  検証可能な数字がフックになる

## 本テーマ特有の扱い: バズる見出しと、非公開情報・政治的中立性の正直な開示

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)を通常より
強めにしてよいこととされている。この指示は正確さ・出典・正直さ・政治的中立性のルールを
緩めるものではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「19歳の大学生が、アジア新記録をたたき出した」という報道された事実に基づく表現 | オーナー指示により通常より強めの表現を許容しつつ、報道内容に忠実な表現にとどめた(創作なし) |
| 中国選手(陳圓将選手)が持つ旧記録との比較 | 事実として確認できる記録の数値のみ | 記録という事実を淡々と紹介するにとどめ、国家間対立を煽る表現は一切使用しない(スライド9・21) |
| 古賀選手の今後の大会予定・目標 | 本調査の範囲では確認できず | 「確認できなかったこと」として一覧化(スライド17) |
| 決勝タイム(12秒97)が自己ベストかどうか | 本調査の範囲では確認できず | 断定せず「不明」として扱った(スライド17) |
| 古賀選手本人のコメント・心境 | 本調査の範囲では確認できず | 推測で埋めず「不明」として扱い、心境を推測で示唆する表現は使用していない(スライド17・22) |
| 「0.59秒」「0.01秒」という数値 | 出典の確定タイムからの単純な引き算による計算値 | 新しい事実であるかのように示さず、計算値であることをキャプション・ノートで明示した(スライド15・23) |

締めのスライド30では「決勝の発表日を基準にすれば鮮度基準を満たすこと」「アジア新記録から
決勝進出、銀メダルまでの明確な物語構造」という、本テーマを選んだ理由そのものを端的に
示す一言で締めている。

## 適用したルール

- 30枚デッキ、bullets比率23.3%(7/30枚、40%上限クリア)、同一レイアウト連続なし
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用、最大2連続)
- 文字中心の説明はcards/table/comparison/diagram/steps/big_stat/bar_chartで図解化
  (推移データは予選・準決勝・決勝の3点のみで`bar_chart`を使用し、`line_chart`/
  `pie_chart`は該当データがないため使用せず、直接引用として確認できたコメントもなかったため
  `quote`も使用していない)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「12秒95。19歳の大学生が、この記録で
  アジア新記録を作ったらしいよ」という具体的な数字を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(「110mハードル」「99.0cm」「U20」「追い風0.3m」の用語解説、
  スライド8) + 実践的な整理(「これは日本の陸上界/同世代・大学生にとって何を意味するか」、
  スライド18・19・20)
- **事実・推測・計算値・不明を明確に区別**: 確定タイム(予選13秒54・準決勝12秒95・
  決勝12秒97)という事実と、そこから単純計算した「0.59秒」「0.01秒」という計算値
  (スライド15・23)、今後の大会予定・自己ベスト該当性・本人コメントという不明
  (スライド17)を分けて扱った
- **鮮度についての正直な開示**: 決勝の発表日(8月9日)を基準にすれば着手日から2日以内で
  基準を満たすが、準決勝(3日前)を基準にすると上回る点も含めてスライド4で正直に開示した
- **政治的中立性の維持**: 旧U20アジア記録を持つ中国選手(陳圓将選手)との比較は記録という
  事実のみを扱い、国家間対立を煽る表現を一切使用しないことをスライド9・21で明示した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 実在選手名(古賀ジェレミー選手、泉谷駿介選手、陳圓将選手)・実在大学名(順天堂大学)は
  テキストとしてのみ扱い、写真・肖像・公式ロゴは使用していない
