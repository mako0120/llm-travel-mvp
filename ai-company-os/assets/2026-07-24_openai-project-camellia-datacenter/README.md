## 適用したルール

- 30枚デッキ、bullets比率20.0%(40%上限クリア)、同一レイアウト連続なし
- 文字中心の説明はtable/diagram/comparison/stepsで図解化
- **コールドオープン(2026-07-24〜)**: 冒頭(1枚目・ナレーション1行目)で
  具体的な数字(「3.2ギガワット、25年契約」)を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド + 「これは何を意味するか・どう動向を追うか」の実践セクション
- **賛否両論の公平な提示**: 「経済的メリット」と「住民の懸念」を対比スライド
  (comparison)で公平に扱い、一方の立場に肩入れしない構成にした
- 進捗バー・カード影・タイトルアクセントの視覚強化(`docs/04_PowerPoint.md`参照)
- 前サイクルとの接続スライドは設けていない
