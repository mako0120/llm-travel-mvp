## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は約束しない)。
以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「代役なのに、3試合連続無失点セーブ。千賀滉大、メッツをナショナルズ3連戦スイープへ導く」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: MLB・野球ニュースに関心がある一般視聴者。専門知識がない前提で、選手・野球用語
  (セーブ・守護神・負傷者リスト)の基礎知識から数字の深掘りまで丁寧に分解して説明するスライドを
  設けている
- パレット(HEX、crimson_goldプリセット): Primary `#7A1F2B` / Primary Dark `#4A1119` /
  Base `#F3E3C9` / Base Soft `#D9B98C` / Accent `#D4A017`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在選手の写真・肖像・実在球団のロゴ・商標は使用しない、
  図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(3ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| quote | 引用強調レイアウト(大きめの引用符+発言者名) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` は含まれない(構成比を示すデータや、時系列の推移を
表すデータがなく、セーブの積み上げはbar_chartで扱っているため)。

## このデッキ固有の注意(代役であることの正確さと、不明点の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「千賀滉大、3試合連続セーブだって?」という
  フックを提示しつつ、直後に「4対3で3連戦をスイープしました」という正確な結果を添えている。
  フック性の強い表現は許容するが、数字を誇張・丸めないこと
- **スライド8・9・10・11は数字の核心スライド**(最終スコア4-3、8/16の投球内容11球・1回・
  無安打無失点・奪三振2、3試合の積み上げ)であり、数字を混同・省略・丸めないこと
- **スライド12・13・14は9回の状況(先頭の代打ビバス・1死からのテナ・フォード・お化けフォーク)を
  正確に扱うスライド**であり、打者名・球種・アウトカウントを変更しないこと
- **スライド16・19・24・25は『ウィリアムズ投手の復帰時期』『千賀投手の今後の起用方針』が未確認で
  あることを示すスライド**であり、具体的な時期や方針を創作して埋めないこと
- **スライド22・23は既存テーマ(記念球エピソード)との違い、および誤帰属トラップ(2025年6月の
  別の古いハムストリング負傷ニュースとの混同回避)を明示するスライド**であり、削除しないこと
- 実在選手名(千賀滉大選手)はテキストとしてのみ扱い、写真・肖像・実在球団(メッツ・ナショナルズ・
  ブレーブス)のロゴ・商標は使用しない
- 特定企業・製品・球団の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`crimson_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の要素を使い、
   `deck_spec.json`の該当スライドから見出し・本文・出典テキストをそのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
