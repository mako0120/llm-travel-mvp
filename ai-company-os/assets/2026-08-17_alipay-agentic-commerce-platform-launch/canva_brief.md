移植仕様書(ブリーフ)である。

  AIエージェント・エージェント型コマース・MCPといった用語の基礎知識から数字の
  深掘りまで丁寧に分解して説明するスライドを設けている

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `steps` / `quote` は
含まれない。連携企業数(5社・16社)・トークン量(1億)・株価変動率(5%)は
いずれも単一時点・単一発表の数字であり、推移として表せる2点以上の時系列データが
存在しないため、グラフ化による誤解(推移があったかのような印象)を避け、
単一時点の数字は`big_stat`/`cards`/`table`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「スマホ5ブランド・自動車
  16社と連携」というフックを提示しつつ、直後に発表の位置づけ・株価反応という
  正確な事実を添えている。フック性の強い表現は許容するが、断定的な優位性・
  成功を保証するような表現に書き換えないこと
- **スライド7・11・13・14・15・16・18・19・21は核心となる数字(中国初の位置づけ・
  AHA・Ah Bao・スマホ5社/市場シェア70%超・自動車16社・1億トークン・株価5%上昇)を
  扱う核心スライド**であり、数字を混同・省略・丸めないこと
- **スライド12は「AHA」の技術仕様の詳細が不明である旨を扱うスライド**であり、
  仕様を創作して埋めないこと(このデッキでは一切使用していない情報である)
- **スライド17はスマホ5社・自動車16社の個別企業名が不明である旨を扱うスライド**
  であり、具体的な社名を創作しないこと
- **スライド20はインセンティブプログラムの具体的な金額・割引率が不明である旨を
  扱うスライド**であり、数値を創作しないこと
- **スライド22は株価5%上昇の比較基準・単独要因かどうかが不明である旨を扱う
  スライド**であり、断定的な因果関係の表現に書き換えないこと
- **スライド23は見出しの印象(すべて公開されているはず)と実際に確認できている
  内容のギャップを示すスライド**であり、削除しないこと
- **スライド26は海外展開(日本を含む)の計画が不明であることを示すスライド**で
  あり、具体的な展開計画を創作しないこと
- Alipay・アリババ・各スマホ/自動車メーカー等の実在企業のロゴ・商標は使用しない
- Alipayの基盤・製品(AHA・Ah Bao)は事実として紹介するのみで、利用・導入を
  推奨する表現に書き換えない(スライド5・24・25)
- 中国企業を扱うテーマであるため、政治的評価・対立を煽る表現を一切用いない
