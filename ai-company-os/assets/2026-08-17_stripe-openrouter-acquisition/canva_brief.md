Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「70億ドル超。Stripeが、AIゲートウェイの新星を買収へ。」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI・生成AIやテック業界のM&Aに関心がある一般視聴者、決済・
  フィンテック業界の動向を追っている開発者・企業のAI導入担当者。専門知識がない
  前提で、AIゲートウェイという用語や「合意」と「完了」の違いを分解して説明する
  スライドを設けている
- パレット(HEX、forest_sandプリセット): Primary `#24523F` / Primary Dark `#17362A` /
  Base `#E7DCC2` / Base Soft `#BFAE84` / Accent `#C1622D`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在のStripe・OpenRouterのロゴ・商標・
  UIスクリーンショットは使用しない、図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `line_chart` / `pie_chart` / `quote` は含まれない(推移データが
1系列の棒グラフで足りる、構成比データがない、公式コメントの直接引用がないため)。

## このデッキ固有の注意(誤解を招かない扱いが最重要)

- **スライド1・2は本テーマのコールドオープン(「70億ドル超」という具体的な数字)**
  である。フック性の強い表現は許容するが、「買収が完了した」「Stripeのものになった」
  等、完了・確定を断定する誤解を招く書き換えはしないこと
- **スライド7・8は「合意」と「完了」の違いを区別する核心スライド**である。
  伝聞表現(reportedly / is said to)を断定表現に書き換えたり、公式発表があった
  かのような記述に変更したりしないこと
- **スライド9・10は初心者向けの前提知識(AIゲートウェイ・Stripeとは)**であり、
  専門用語をそのまま使わずに平易な説明を保つこと
- **スライド11〜17は評価額の急伸(13億ドル→70億ドル超)とOpenRouterの規模の
  核心スライド**である。数値(1億1,300万ドル・13億ドル・70億ドル超・800万・
  400以上)を誤って書き換えないこと
- **スライド23・25・27は「確認できていないこと」を扱うスライド**であり、
  削除しないこと。クロージング日・規制承認・ブランド存続方針を確定情報である
  かのように書き換えないこと
- **スライド24・25は見出しの印象と実際の内容のギャップを示すスライド**であり、
  削除しないこと
- **スライド26は中立性(Stripe・OpenRouterへの評価・優劣の論評を行わない)を
  明示するスライド**であり、削除しないこと
- 実在の「Stripe」「OpenRouter」等の名称はテキストとしてのみ扱い、公式ロゴ・
  商標・UIスクリーンショットは使用しない
- 特定企業・製品の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`forest_sand`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
