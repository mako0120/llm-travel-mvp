## 適用したルール

- 30枚デッキ、bullets比率13.3%(40%上限クリア)、同一レイアウト連続は最大1
- 文字中心の説明はtable/diagram/comparison/steps/quoteで図解・引用化
  (推移データが限られるため`bar_chart`ではなく`table`・`big_stat`で扱った)
- **コールドオープン**: 冒頭(1枚目・ナレーション1行目)で「15万体」という
  Gartner予測の数字を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(なぜAIエージェントの統治が問題か、非人間IDと
  APIキーの違い) + 実践的な整理(投資家一覧・創業からの軌跡)
- **公表/非公開を明確に区別**: 3,000万ドル・15万体超・96%という公表された
  数字と、企業評価額・Akamaiの出資額・日本への関連などの非公開情報を分けて扱う
- Akamai参加の意図に関する整理は推測であることを明記し、断定を避けた(スライド21)
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 前サイクルとの接続スライドは設けていない
