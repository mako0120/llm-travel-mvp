# Canva ブリーフ: OpenAI「ChatGPT for Teens」、本日13〜17歳向けの専用版を世界展開開始

<!-- docs/05_Canva.md 準拠 -->

## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「OpenAI「ChatGPT for Teens」、本日13〜17歳向けの専用版を世界展開開始」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 13〜17歳の子どもを持つ保護者、およびChatGPTを利用するティーン
  本人。専門知識がない前提で、年齢推定・未成年者向け保護機能・保護者向け機能の
  基礎から丁寧に分解して説明するスライドを設けている。特定企業(OpenAI)の製品を
  扱うが、利用を強く推奨する結論にはせず、保護者・ティーン双方にとって有用な
  情報提供にとどめる構成になっている。未成年の安全に関わるテーマのため、
  自殺・自傷行為等のセンシティブな内容は詳細を描写せず、保護機能の説明レベルに
  とどめている
- パレット(HEX、crimson_goldプリセット): Primary `#7A1F2B` / Base `#F3E3C9` /
  Accent `#D4A017`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(OpenAI社のロゴ・商標・製品スクリーン
  ショット、実在人物の写真・肖像は使用しない、図形・アイコンはCanva内蔵の無料
  素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(2ノード) |
| comparison | 2カラム比較(左右カード+リスト) |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `quote` は含まれない
(本テーマは機能・仕組みの整理が中心で、構成比・推移・量比較を示す確認済みの
数値データがないため。数値の創作を避けるため、無理にチャート化していない)。

## このデッキ固有の注意(センシティブな主題の扱い・中立性が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「まさかの本日から」
  というフックを提示しつつ、直後に正確な内容(専用版の世界展開)を添えている。
  フック性の強い表現は許容するが、未成年の安全というテーマの性質上、恐怖を
  煽る演出・扇動的な表現には転じさせないこと
- **スライド9〜13は未成年者向け保護機能を扱う**。自殺・自傷行為・恋愛/性的な
  会話の制限、有害コンテンツへのガード強化について、出典が示す高いレベルの
  分類のみを用いること。具体的な手法・詳細を書き加えたり、画像で示唆したり
  しないこと(センセーショナルな演出の禁止)
- **スライド20・21は本テーマの核心である「保護者は会話内容を見られない」
  というプライバシー配慮を扱う**。この設計上の特徴は削除・弱化せず、独立した
  論点として明確に伝えること
- **スライド25・26は本テーマの懸念点・不明点を扱う**。断定的な批判にせず、
  「公式情報の範囲では確認できていない」という正直な書き方を維持すること
- **スライド30(CTA)は「ChatGPTの利用を強く勧める」結論にしないこと**。
  あくまで「家庭でのアカウント設定確認を促す」中立的なアクションにとどめる
  (既存の文言を維持)
- 実在するOpenAI社のロゴ・商標・製品スクリーンショット、実在人物の写真・肖像の
  使用は行わない(テキストによる言及と抽象的な図解・アイコンのみで構成する)
- 顔を使った表現(表情訴求等)は本ブリーフの対象外。人物のイラスト・アイコンを
  使う場合も、特定の実在人物を想起させない汎用的なものに限る
