## 未成年配慮・災害センシティビティに関する自己評価(本テーマ固有・必須)

本テーマは通常のスポーツニュース系テーマと異なり、(1)出場選手が未成年であること、
(2)実在の自然災害(熊本地震)を扱うことの2点で、追加の配慮が必須である。以下、
それぞれの扱いを個別に自己評価する。

### 未成年選手への配慮

- [x] 個々の選手の私生活・容姿・恋愛関係等には一切踏み込まず、オンフィールドの
  活躍と既に報道で公表されている氏名のみを扱った(スライド5・23で配慮方針を明示)
- [x] チーム・学校・地域全体の物語として構成し、特定選手への扇情的な焦点化を
  避けた(逆転劇の説明でも「誰が」より「どのようなプレーで」を主軸にした)
- [x] 写真・映像・肖像は一切使用せず、抽象的なグラフィック・アイコンのみで構成
  する方針を`canva_brief.md`・`youtube_assets.md`にも明記した
- [x] 個々の選手への断定的な将来評価(「将来のプロ候補」等)を一切行っていない
- 自己評価: 標準のパイプライン方針(実在人物写真不使用)に加え、未成年であることを
  理由に専用の配慮方針スライド(23)を新設した点で、通常テーマより一段厳格な
  対応ができている

### 実在の災害(熊本地震)への配慮

- [x] マグニチュード・最大震度・観測地域・発生日時・過去の震度7との比較という、
  気象庁公式ポータルで確認できた事実の範囲にとどめた(スライド18・19・20)
- [x] 死者数・負傷者数・経済的損害額・復旧見込み等、本調査で確認していない数字は
  一切創作・推測していない(該当する数字は成果物内に一切登場しない)
- [x] 「有明高校が被災した」という事実は確認されていないため、そのように誤解
  させる表現を一切使わず、「メディアの文脈づけ」と「確認できた事実」を明確に
  区別するスライド(21・24)を設けた
- [x] 復興政策・行政の災害対応等の政治的な争点には一切触れていない
- [x] 悲劇を煽る表現(地震の被害を誇張して感動を演出する等)は一切使わず、
  フックはスポーツの記録(初出場・3試合連続逆転・8強進出)に置き、地震は正直な
  時系列の背景情報として扱った(タイトル・冒頭フックの設計方針)
- 自己評価: 「バズ路線のフック」と「悲劇の誇張回避」という相反しかねない2つの

  扱うことで両立させた。見出しの印象と実際の内容のギャップを専用スライドで
  明示している点は、通常のセンシティビティ対応より踏み込んだ配慮といえる
