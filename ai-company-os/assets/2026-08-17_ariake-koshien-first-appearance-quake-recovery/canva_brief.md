## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(4ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。3試合の得点比較はbar_chartで扱っている)。

## このデッキ固有の注意(未成年配慮と地震の事実の正確さが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「初出場で3試合連続逆転勝ち、
  8強だって?」というフックを提示しつつ、直後に3回戦の正確な結果を添えている。
  フック性の強い表現は許容するが、熊本地震の被害を煽り立てる方向に書き換えないこと
- **スライド13・14・15は3回戦(8/16)の逆転劇を扱う核心スライド**であり、8回の
  ダブルスチール→代打・広沢遼太朗選手・栄井彰選手の適時打という経過を混同・省略・
  誇張しないこと
- **スライド18・19・20は熊本地震の事実(M7.1・最大震度7・観測地域・震度7の希少性)を
  扱うスライド**であり、気象庁公式ポータルで確認できる範囲を超えて被害規模・死傷者数を
  書き加えないこと
- **スライド21・24は『被災地に勇気を届けた』という報道の文脈と、有明高校自体が
  被災したという未確認の事実を区別するスライド**であり、削除しないこと。有明高校が
  地震で直接被害を受けたかのような表現を追加しないこと
- **スライド12・22・28は確認できていないこと(2回戦の得点経過・投手負傷の詳細・
  地震による学校/選手への直接的な被害)を示すスライド**であり、具体的な数字や詳細を
  創作して埋めないこと
- **スライド5・23は未成年選手への配慮方針を扱うスライド**であり、削除しないこと。
  選手の私生活・容姿等に関する記述を追加しないこと
- 実在選手名(広沢遼太朗選手・栄井彰選手など)はテキストとしてのみ扱い、写真・肖像・
  実在団体のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない。政治的な話題(復興政策の評価等)にも
  触れていない
