## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「Google、破産したスピリット航空の社内データを1000万ドルで落札――
  AI学習への活用に労組が猛反発」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI・データ活用・労働問題に関心がある一般視聴者。専門知識が
  ない前提で、破産手続き・匿名化・AI学習データといった用語の基礎知識から、
  争いのある2つの立場(Google/客室乗務員組合)まで丁寧に分解して説明する
  スライドを設けている
- パレット(HEX、cobalt_violetプリセット): Primary `#1B3A5C` / Primary Dark
  `#10233A` / Base `#DCE6F5` / Base Soft `#A9C0D8` / Accent `#7B4FFF`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在人物の写真・肖像、Google・
  スピリット航空・Mercor等の実在企業のロゴ・商標は使用しない、図形・
  アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| table | 表(ヘッダー行+データ行) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| bar_chart | 棒グラフ(入札額の推移、3本のみ) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| quote | 引用強調レイアウト(発言者名を明記、ダーク背景+大きな引用符) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `steps` / `agenda` は含まれない。
時系列で長期間推移する確定数値が存在せず、単一時点での入札額の推移
(3段階のみ)は`bar_chart`で扱い、目次相当の内容は`cards`(スライド3)で
代替している。

## このデッキ固有の注意(両論併記と「承認待ち」フレーミングが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「1000万ドルで落札」
  というフックを提示しつつ、直後に「裁判所の承認はこれから」という正確な
  ステータスを添えている。フック性の強い表現は許容するが、取引が確定した
  かのような表現に書き換えないこと
- **「落札」と「取引確定」を必ず区別すること(最重要)**: スライド2・15・16・
  24・25・28・30は、破産裁判所の承認審理がまだ結果不明であることを扱う
  核心スライートである。承認済み・取引完了として書き換えないこと
- **両論併記(最重要)**: スライド10・19・20・22は、Googleの立場(匿名化・
  除外データ・事業上の合理性)と客室乗務員組合の反発(サラ・ネルソン会長の
  「言語道断」発言、法廷異議申し立て方針)、さらに広い論点(イノベーション論/
  懸念論)を両論併記する核心スライドである。いずれか一方に肩入れする表現に
  書き換えないこと。デッキの結論(スライド28・30)も中立的な締め方を維持する
  こと
- **スライド14は匿名化技術の具体的手法が未確認であることを示すスライド**で
  あり、具体的な技術詳細を創作して埋めないこと
- **スライド17はサラ・ネルソン会長の直接引用**であり、実在人物の写真・肖像は
  使用せず、文字の引用のみで表現すること
- **スライド25・27は確認できたこと/確認できていないことの一覧スライド**で
  あり、削除しないこと
- Google・スピリット航空・Mercor等の実在企業のロゴ・商標は使用しない
- Googleの落札内容は事実として紹介するのみで、利用・投資を推奨する表現に
  書き換えない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`cobalt_violet`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字・両論併記のバランスが一致している
   ことを確認
