## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない。時系列の
  推移データや直接引用として確認できたものが本調査の範囲になく、確認できない数値を
  グラフ化・引用化しないため、代わりに`diagram`(時系列)・`table`・`cards`で整理している。

## このデッキ固有の注意

- **スライド4は鮮度についての回**である。本テーマは着手日当日の事象であり、鮮度基準を
  例外なく完全に満たすことを明示している(他テーマのような鮮度例外の開示ではない点に注意)
- **スライド7・17は規制上の許可(NHTSA適用除外、7月31日)から本日の商用開始までの
  時系列を示す回**である。既存テーマ(2026-08-03公開)との関係を裏付ける重要な図解のため、
  削除・簡略化しないこと
- **スライド11は料金水準は分かるが、具体的な基本運賃の金額はZoox非公表(不明)である
  ことを明示する回**である。金額を推測で埋めないこと
- **スライド14は2026年3月に発表されたUber連携の計画についての回**であり、本日開始した
  有料サービスとは別の、将来予定であることを明確に区別すること
- **スライド16は既存テーマ(2026-08-03_zoox-nhtsa-safety-exemption)との関係を整理する
  回**である。規制上の許可(前提条件)と実際の商業展開(本テーマ)という別の事象である
  ことを明示する内容のため、削除・簡略化しないこと
- **スライド18は「確認できなかったこと」の一覧**であり、削除しないこと(具体的な基本運賃・
  車両台数・Uber連携の開始日・他都市展開を非公開として明示している)
- **スライド22は誇張回避・特定企業推奨回避についての注記**である。タイトル・冒頭フックは
  注目を集める表現を使っているが、本文の内容は誇張しておらず、Zoox等の利用を強く推奨して
  いない旨を明示しているため、この注記スライドは保持すること
- **スライド23は当社の推測であることを明記したカード**である。断定形や公式見通しの
  ように書き換えないこと
- 実在企業名(Zoox、Amazon、Uber等)はテキストとしてのみ扱い、ロゴ・商標・肖像は使用しない
