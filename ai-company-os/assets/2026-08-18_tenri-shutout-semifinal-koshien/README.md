# 「天理、完封で9年ぶり4強――夏の甲子園準々決勝、三重を7-0で下す」(2026-08-18試合・同日制作)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
2026年8月18日、夏の甲子園準々決勝第1試合で天理(奈良)が三重(三重)を7-0で破り、
2017年以来9年ぶりのベスト4進出を決めた件を、7回裏まで2-0だった試合が終盤2イニングで
一気に7-0まで開いたという得点経過を軸に、正確に整理している。出場選手が未成年で
あること、敗れた三重側の結果(0-7・ただし12年ぶりのベスト8進出)を扱うことを踏まえ、
通常より丁寧な配慮方針を全成果物に一貫して適用した。

## 選定理由

- 対象ジャンル「国内で活躍する日本人(高校生)」枠
- 2026年8月18日午前8時、天理が夏の甲子園準々決勝で三重を7-0で完封し、2017年以来
  9年ぶりのベスト4進出を決めた(着手日2026-08-18の当日、`docs/06_Content_R&D.md`の
  「着手日を含めて2日以内」という鮮度基準を最も新しい形で満たす)
- SANSPO(docomoニュース配信)・Yahoo!スポーツナビ(バーチャル高校野球)・
  ベースボールチャンネル・高校野球ドットコム(Yahoo!ニュース配信)という複数の
  独立したメディアが試合結果・得点経過を一致させて報じている
  (`research/2026-08-18_theme-evaluation-round173.md`参照)
- 「7回裏まで2-0の接戦が、終盤2イニングで一気に7-0の完封に変わった」という明確な
  展開と、「天理の9年ぶり4強・三重の12年ぶりベスト8」という両校の記録を、誇張・
  断定なく正確に扱う強いフックがある

熊本地震)があるが、対戦カード・出来事が完全に異なるため重複ではない。本テーマは
新規テーマである。

## 適用したルール

- 30枚デッキ、bullets比率30%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成、`build_deck.py`のビルド時検証で確認)
- palette_presetは指示どおり`graphite_emerald`を使用(Primary `#1B2A2E` /
  Base `#CFE8DE` / Accent `#00D2A0`)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「天理が7-0で完封、9年ぶり4強
  だって?」というフックを提示した直後に、正確な結果(準々決勝で三重に7-0)を
  添え、挨拶・前置きを省いた
- **得点経過の正確な明示**: 7回裏2-0・8回表5-0(大塚選手の安打とエラー+小澤選手の
  適時打)・9回表7-0(金本選手の適時三塁打+暴投)を、title/big_stat/steps/table/
  diagram/cards/bar_chartで複数回・複数形式で明示し、誤解を招く表現を排除した
- **未成年選手への配慮**: 出場選手が未成年であることを踏まえ、個人の私生活には
  一切踏み込まず、チーム・学校の物語として構成する専用の方針スライド(24)を
  設け、写真・肖像は一切使用しなかった
- **敗れた三重側の結果の正直な扱い**: 三重の0-7という敗戦の結果を隠さず・
  誇張せず正確に伝え、同時に2014年準優勝以来12年ぶりのベスト8進出という実績も
  敗戦の陰に埋もれさせず、専用スライド(19・20・21・22)で扱った
- 初心者向け前提知識スライド(甲子園・準々決勝・完封・天理三重の基礎知識)+
  読者の立場別(高校野球ファン・勝敗両方の結果を見る立場・発信する立場)の
  実践的示唆(スライド25)
- 出典のない数字は作らず、確認できなかった項目(天理投手陣の投球内容の詳細・
  三重側の反撃が実らなかった要因・試合前半の得点経過・準決勝の日程対戦相手)は
  正直に「不明」と明記した(テーブル・スライド16・23・27・28)
- 誇張回避: 三重の敗戦をスピンをかけず、また過度にドラマ化しない旨を専用
  スライドで明示した(スライド20・22)

## リスク配慮

- 天理の先発投手・救援投手の投球内容(奪三振数・被安打数等)の詳細を一切創作せず、
  「完封」という結果のみを確認済みの事実として扱っている
- 三重側の反撃が実らなかった具体的な要因を一切推測していない

  せず、12年ぶりベスト8進出という実績とあわせて正確に伝えている
