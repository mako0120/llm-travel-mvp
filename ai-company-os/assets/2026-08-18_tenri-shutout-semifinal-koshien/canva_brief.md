Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は

移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「天理、完封で9年ぶり4強――夏の甲子園準々決勝、三重を7-0で下す」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 高校野球・甲子園に関心がある一般視聴者。専門知識がない前提で、
  準々決勝・完封の基礎知識から得点経過の数字の深掘りまで丁寧に分解して説明する
  スライドを設けている。未成年の選手が主役であること、敗れた三重側の結果を正直かつ
  敬意を持って扱うことを踏まえ、通常より丁寧な配慮を前提とした構成になっている
- パレット(HEX、graphite_emeraldプリセット): Primary `#1B2A2E` / Primary Dark `#0F1B1E` /
  Base `#CFE8DE` / Base Soft `#8FC2AE` / Accent `#00D2A0`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在選手の写真・肖像・実在団体(日本高等
  学校野球連盟・朝日新聞社等)のロゴ・商標は使用しない、図形・アイコンはCanva内蔵の
  無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(3ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。得点の伸びはbar_chartで扱っている)。

## このデッキ固有の注意(未成年配慮と敗戦の正直な扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「7-0で完封、9年ぶり4強だって?」
  というフックを提示しつつ、直後に正確な結果を添えている。フック性の強い表現は
  許容するが、三重の敗戦を煽り立てる方向に書き換えないこと
- **スライド9〜14は得点経過(7回裏2-0→8回表5-0→9回表7-0)を扱う核心スライド**で
  あり、大塚選手の安打とエラー、小澤選手の適時打、金本選手の適時三塁打と暴投という
  経過を混同・省略・誇張しないこと
- **スライド16は天理の投球内容について確認できていないことを示すスライド**であり、
  奪三振数・被安打数等の具体的な数字を創作して埋めないこと
- **スライド19〜22は三重の12年ぶりベスト8進出という実績と、0-7で敗れたという結果を
  扱う核心スライド**であり、削除しないこと。敗戦を『隠れた勝利』として演出したり、
  逆に過度に悲劇的に演出したりしないこと。反撃が実らなかった要因を創作して埋めない
  こと
- **スライド24は未成年選手への配慮方針を扱うスライド**であり、削除しないこと。
  選手の私生活・容姿等に関する記述を追加しないこと
- **スライド23・28は確認できていないこと(投球内容の詳細・敗因・準決勝の日程)を
  示すスライド**であり、具体的な数字や詳細を創作して埋めないこと
- 実在選手名(大塚選手・小澤選手・金本選手など)はテキストとしてのみ扱い、写真・肖像・
  実在団体のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない。政治的な話題にも触れていない
