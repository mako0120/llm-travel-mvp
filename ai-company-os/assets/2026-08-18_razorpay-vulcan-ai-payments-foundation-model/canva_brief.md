## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「Razorpay、インド初の決済特化AI基盤モデル『Vulcan』を発表」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 決済・フィンテック・AI業界のトレンドに関心がある一般
  視聴者。専門知識がない前提で、AI基盤モデル・Transformer・UPIといった
  用語の基礎知識から成果指標の深掘りまで丁寧に分解して説明するスライドを
  設けている
- パレット(HEX、cobalt_violetプリセット): Primary `#1B3A5C` / Primary Dark
  `#10233A` / Base `#DCE6F5` / Base Soft `#A9C0D8` / Accent `#7B4FFF`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在人物の写真・肖像、Razorpay・
  NVIDIA・AWS等の実在企業のロゴ・商標は使用しない、図形・アイコンはCanva
  内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 番号バッジ付き横並びステップ(矢印つき) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `pie_chart` / `line_chart` / `quote` は含まれない。
構成比・時系列推移を表すデータや引用素材が存在しないため、単一時点の数字は
`big_stat`/`table`/`cards`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、オーナー指示(バズ
  路線への転換)に基づき「まさかの」等フック性の強い表現を用いているが、
  直後に発表日・成果指標という正確な事実を添えている。フック性の強い
  表現は許容するが、成果指標が確定・保証された効果であるかのような
  表現に書き換えないこと
- **スライド7・8は学習データ規模(40億件・3兆データポイント・3,000
  シグナル)を扱う核心スライド**であり、数字を混同・誇張しないこと
- **スライド12・13・14・15は導入後の成果指標(決済成功率8〜10%向上・
  不正検知最大5倍・UPIアプリ表示率40%増)を扱う核心スライド**であり、
  これらがRazorpay側発表による数字であって独立した第三者機関による
  検証結果ではない旨をスライド21で必ず補足すること
- **スライド20は学習規模の数字と成果指標の数字を明確に区別する
  スライド**であり、削除・混同しないこと
- **スライド18・19は技術的詳細・対象範囲が不明であることを示す
  スライド**であり、具体的な数値・地域名を創作・推測で補わないこと
- **スライド22は見出しの印象(決済問題が全て解決)と実際に確認できて
  いる内容のギャップを示すスライド**であり、削除しないこと
- Razorpay・NVIDIA・AWS等の実在企業のロゴ・商標は使用しない
- Razorpayの製品(Vulcan)は事実として紹介するのみで、利用を推奨する
  表現に書き換えない(スライド25)

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`cobalt_violet`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
