## 選定理由

- 2026年8月6日、OpenAIがAppleの営業秘密訴訟について、連邦判事に却下を申立てた。
  Appleは以前、OpenAIと元Apple社員2名を相手取り、営業秘密の不正利用・不適切な引き抜きを
  訴えていたが、OpenAIは31ページに及ぶ申立書で、Apple自身のiCloud運用(業務用に個人の
  iCloudアカウント利用を奨励する一方、会社端末に残る個人のiMessageを審査していた)が、
  退職した元エンジニアのサーバーへの継続アクセスを許した「認証情報の隙間」を生んだと
  主張している
- `ai-company-os/research/2026-08-10_theme-evaluation-round91.md`(2026年8月10日実施)の
  「候補2(154本目、鮮度基準の例外運用)」として、バズ路線スコア75/100で採用
- **鮮度基準の例外採用であることを、正直に明記する。** 発表日(2026-08-06)から着手日
  (2026-08-10)まで**4日**が経過しており、`docs/06_Content_R&D.md`の鮮度基準
  (2026-08-05追記: 着手日を含めて2日以内を必須とする)を**満たしていない**。round91
  評価表に記録の通り、13件以上の異なる切り口でWebSearchを実施したが、着手日から2日以内の
  候補が見つからなかった。一部「カリフォルニア州フロンティアAI安全法が本日可決」という
  有力に見える候補も検索結果に現れたが、二次検証の結果、実在しない/古い法案(SB1047・
  SB53)との混同であることが判明し、数字・事実の創作を避けるため正直に不採用として記録した。
  `docs/06_Content_R&D.md`が定める「探索を尽くしてもなお2日以内の候補が1本も見つからない
  場合に限り、次点として最も新しい候補を暫定的に採用してよいが、これは例外的な最終手段で
  あり常態化させない」という規定に基づき、本テーマ(発表から4日前)を鮮度基準の例外として
  採用した
- **本ラウンドは2ラウンド連続の例外運用である点も、隠さず正直に開示する。** 直前の
  round90(152本目`2026-08-07_rippling-ai-spend-console`、発表から3日前)も同様に鮮度基準の
  例外採用だった。2ラウンド連続で例外運用となったことは事実であり、これを常態化させない
  よう、次回以降のラウンドでは改めて2日以内の基準を優先して探索する
- Axios・TechCrunch・Bloombergという主要メディア3社が2026年8月6日に同日報道し、
  9to5Mac・TheNextWeb・TheAIInsiderが要点を裏付け、claimsjournal.comが翌日(8/7)に続報を
  出している。複数の独立したメディアによる裏付けが揃っている点も採用理由
- AI業界の2大企業(Apple・OpenAI)の法廷闘争という著名性、「訴えられた側が相手のセキュリティ
  体制の甘さを理由に反論した」という展開の意外性がフックとなる

## 本テーマ特有の扱い: 私企業間の商業訴訟としての中立性の徹底

本テーマはApple・OpenAIという2つの私企業間の商業(民事)訴訟を扱う。人物・政府・政治に
関する話題ではないが、著名企業同士の法廷闘争という性質上、以下の点を特に慎重に扱った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 政治的中立性 | 政府・政治的な論争ではない | 私企業間の商業訴訟についての事実報道であることをresearch.md・専用スライド(17)で明示し、政治的な主張・立場表明を一切含めていない |
| 法的中立性 | Apple・OpenAIどちらの主張が正しいか | 本テーマでは判断・断定を行わない。双方の主張を専用スライド(16)で並列に比較整理し、それぞれの提出書面・報道内容として出典を明記して紹介するにとどめた |
| Appleへの攻撃的な内容(申立書側の主張) | 「Appleは失敗している」という趣旨の主張が申立書に含まれる | OpenAI申立書の内容としてそのまま引用・紹介し(スライド8・14)、当社の評価・断定としては提示していない |
| 元Apple社員2名の氏名 | 信頼できる出典で確認できていない | 特定・言及せず、不明としてスライド18で明記した |
| 「訴えられた側が反論した」という見出し表現 | まだ係争中で結論が出ていないことが伝わりにくい可能性 | 専用スライド(20)で「却下申立ては訴訟の勝敗を意味しない」ことを明示し、誤解を防いだ |
| 鮮度(発表から4日前、2ラウンド連続の例外) | 通常の鮮度基準(2日以内)を満たさない | スライド4・25、README、research.mdで一貫して正直に開示している |

締めのスライド30では「却下されるか、審理入りするか。まだ結論は出ていない」というメッセージで、
訴訟が現在も進行中であることを明示している。

## 適用したルール

- 30枚デッキ、bullets比率23.3%(7/30枚、40%上限クリア)、同一レイアウト連続なし
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用、最大2連続)
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_stat/quoteで図解・引用化
  (申立て内容の正確な時系列推移データが数値化されていないため`bar_chart`/`line_chart`/
  `pie_chart`は使用せず、申立書からの直接引用が確認できた`quote`を1箇所で使用した)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「訴えられた側が『そっちのセキュリティが
  甘い』と反論したらしいよ」という具体的な展開を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(「却下申立て」「営業秘密訴訟」「仮差止命令」の用語解説、
  スライド9)+実践的な整理(「これは企業/エンジニア個人にとって何を意味するか」、
  スライド22・23・24)
- **事実・推測・不明を明確に区別**: 報道された事実・申立書の主張という事実と、今後の展開・
  論点という当社の推測(スライド26・27)、元社員の氏名・具体的な営業秘密の内容という不明
  (スライド18)を分けて扱った
- **政治的・法的中立性の徹底**: 私企業間の商業訴訟であることを専用スライド(17)で明示し、
  Apple・OpenAIどちらの主張が正しいかについて判断・断定を行っていない。双方の主張を
  専用の比較スライド(16)で並列に整理した
- **鮮度基準の例外採用(2ラウンド連続)の正直な開示**: 発表から着手日まで4日、通常の鮮度
  基準(2日以内)を満たさないこと、直前のround90(152本目)に続く2ラウンド連続の例外運用で
  あることをスライド4・25で明示し、探索を尽くしても2日以内の候補が見つからなかったという
  経緯を具体的に記載した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 実在企業名(Apple、OpenAI)はテキストとしてのみ扱い、ロゴ・商標・肖像は使用していない。
  元Apple社員2名の氏名は確認できていないため特定・言及していない
