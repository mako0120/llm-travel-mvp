## 適用したルール

- 30枚デッキ、bullets比率13.3%(40%上限クリア)、同一レイアウト連続は最大2
- 文字中心の説明はtable/diagram/comparison/steps/quote/bar_chartで図解・引用化
- **コールドオープン**: 冒頭(1枚目・ナレーション1行目)で「同じ日に2社・計9,000万ドル」
  を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(AIエージェントとは・権限を渡すとは、なぜ鍵が積み上がるか)
  + 実践手順(棚卸しする→範囲を見る→止め方を決める)
- **予測と実績を区別**: 調査会社の予測を実績のように提示しない
- **情報の限界を先に開示**: 記事本文を取得できなかったことを4枚目で先に言う
- 一方的に推奨せず、確かなこと/慎重に見るべきことを対比(21枚目)
- 2社を優劣で比較せず、アプローチの違いとして提示(15枚目)
- 前サイクルとの接続スライドは設けていない
