## メタ情報

- デッキ名: 半導体設計にAIエージェント参入(定期実行56本目)
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI活用・AIエージェント業界動向に関心がある一般視聴者。
  専門知識がない前提で、前提知識スライドを2枚設けている
- パレット(HEX、slate_azureプリセット): Primary `#2B3A55` / Base `#D3E4F5` / Accent `#1F8FD6`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在企業のロゴは使用しない、
  図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| quote | 引用レイアウト(要約であることを帰属に明記) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(推移データ・
  構成比のデータが無かったため、数字は `big_stat` と `table` で扱っている)。

## このデッキ固有の注意

- **スライド7・15の「1.34億ドル」「ARR6倍」は本テーマの中心となる数字**である。
  スライド8・13で前回調達(2026年2月・7,400万ドル)との比較も必ず一緒に残すこと
- **スライド18の`quote`はCEOコメントの英語原文を一次確認できておらず、
  複数媒体の要約経由**である。「原文未確認」の帰属テキストを必ず残すこと
- **スライド19・20は「エヌビディアが投資家として参加しているか未公表」という開示**
  であり、削除しないこと
- **スライド22は「ChipAgents自体の日本国内の顧客・拠点は不明」という開示**であり、
  Micronの日本拠点(投資家企業の一般的な事実)と混同しないよう文言を保持すること
- スライド10の「18億ドル」は業界全体の集計トラッカーのデータであり、ChipAgents
  自体の数字ではない旨を必ず残すこと
- スライド26・28は推測であることを本文に明記している。断定形に書き換えないこと
- 実在企業名(ChipAgents、エヌビディア、Micron、MediaTek、Ericsson、Bessemer、
  B Capital)はテキストとしてのみ扱い、ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない。移植時も断定的な推奨
  文言を追加しないこと

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
