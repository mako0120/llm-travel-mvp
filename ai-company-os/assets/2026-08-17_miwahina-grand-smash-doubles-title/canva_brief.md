## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| quote | 大見出し引用+出典(ダーク背景) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `pie_chart` / `line_chart` は含まれない(セットスコアは
表形式の方が正確に伝わるため table/steps/cards で扱っている)。

## このデッキ固有の注意(『2勝目』の正確な扱いと1勝目未確認の明示が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「『みわひな』、グランドスマッシュ
  2勝目だって?」というフックを提示しつつ、直後に正確な結果(3-1)を添えている。
  フック性の強い表現は許容するが、1勝目の存在を既知の事実であるかのように書き換え
  ないこと
- **スライド8・9・10・27は決勝のセットスコア(11-6・9-11・13-11・11-9)を扱う
  核心スライド**であり、数字を混同・省略・丸めないこと
- **スライド11・12・22・23は『グランドスマッシュ2勝目』という表現を正確に扱う
  スライド**であり、1勝目の大会名・日程を創作して書き加えないこと
- **スライド15・16は現地の賛辞を扱うスライド**であり、具体的な発言者名を創作しない
  こと(「現地の卓球関係者・メディア」という範囲を保つ)
- **スライド21は見出しの印象(圧勝との誤解)と実際の内容(第2セットは接戦)の
  ギャップを示すスライド**であり、削除しないこと
- **スライド16は今大会の他種目に触れないことを明示するスライド**であり、削除
  しないこと
- 実在選手名(張本美和選手・早田ひな選手)はテキストとしてのみ扱い、写真・肖像・
  実在団体(WTT・木下グループ・日本生命等)のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`navy_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
