## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「Synchrony、OpenAIと電撃提携――ChatGPT内でAmazon・Walmartのストアカード決済が可能に」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: AI・決済・小売業界の提携ニュースに関心がある一般視聴者。
  専門知識がない前提で、ストアカード・信販会社・エンタープライズ提携といった
  用語の基礎知識から仕組み・未確定事項まで丁寧に分解して説明するスライドを設けている
- パレット(HEX、indigo_cyanプリセット): Primary `#2E2A72` / Primary Dark
  `#1B1846` / Base `#D6D9F5` / Base Soft `#A9AEE0` / Accent `#17C3B2`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在人物の写真・肖像、Synchrony・
  OpenAI・Amazon・Walmart・Lowe's等の実在企業のロゴ・商標は使用しない、
  図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `bar_chart` / `steps` / `quote` は
含まれない。時系列で推移する確定数値(過去比較の売上・利用者数の推移等)が
存在せず、単一時点の見通し(6〜12か月等)を扱うため、グラフ化による誤解
(推移があったかのような印象)を避け、単一時点の情報は`big_stat`/`cards`/
`table`/`diagram`で扱っている。

## このデッキ固有の注意(未確定事項の扱いと自己参照回避が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「まさかのAI決済時代」
  というフックを提示しつつ、直後に発表日・提携内容という正確な事実を添えている。
  フック性の強い表現は許容するが、決済がすでに利用可能であるかのような表現に
  書き換えないこと
- **スライド12・13・16・20は実現時期の見通しを扱う核心スライド**であり、
  「汎用カードは6〜12か月」「プライベートブランドカードはさらに調整が必要」
  という情報を混同・省略・誇張しないこと。確定した提供開始日として書き換え
  ないこと
- **スライド18は手数料・取引経済性が交渉中であることを示すスライド**であり、
  具体的な手数料率・配分比率を創作して埋めないこと(このデッキでは一切
  使用していない数字である)
- **スライド19は消費者の決済情報保護への懸念を扱うスライド**であり、
  具体的な対策内容を確認できていないにもかかわらず確立済みであるかのように
  書かないこと
- **スライド17は見出しの印象(すぐ使えそう)と実際に確認できている内容
  (見通し段階)のギャップを示すスライド**であり、削除しないこと
- **スライド24・26は確認できたこと/確認できていないことの一覧スライド**であり、
  削除しないこと
- **スライド27は中立性・利用非推奨の明記スライド**であり、削除・弱体化
  しないこと
- **自己参照回避(最重要)**: Synchrony・OpenAI以外の競合AIチャット
  プラットフォームの具体名への言及・示唆は、デッキ・ノート・出典欄を含め
  一切追加しないこと。一部の情報源記事にある「他のAIプラットフォームとも
  協議中」という付随情報は、本テーマの制作方針上意図的に除外している
  (詳細はresearch.md参照)
- Synchrony・OpenAI・Amazon・Walmart・Lowe's等の実在企業のロゴ・商標は
  使用しない
- Synchrony・OpenAIの提携内容は事実として紹介するのみで、利用を推奨する
  表現に書き換えない(スライド5・27)
