# 「ジェンスン・フアンCEOが向かった先は、アメリカでも中国でもなくアルメニアだった」(2026-08-08・148本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠、AIインフラ・データセンターへの巨額投資の切り口
- オーナー指定テーマ(148本目)として制作を開始
- 2026年8月8日(土)、NVIDIA公式ブログが「FirebirdがアルメニアにCIS地域最大のAI工場を
  開所した」と発表。着手日(2026年8月9日)から見て1日前の発表であり、
  `docs/06_Content_R&D.md`の鮮度基準(着手日を含めて2日以内)を満たす
- PR Newswire・Morningstar・The AI Insider・Firebird公式サイト・Unite.AI・ARMENPRESS
  (アルメニア国営通信)・TechBuzz.ai・TahawulTechという独立した複数のメディアが同内容を
  裏付けている
- 「世界最大級のAI工場と聞いて誰もが思い浮かべる米国・中国ではなく、アルメニアに誕生した」
  という地理的な意外性と、NVIDIA創業者兼CEOのジェンスン・フアン氏本人が開所式に登壇した
  という著名性が重なり、話題性が高い

## 既存テーマとの関係(重複でないことの確認)

`ai-company-os/assets/`配下を検索した結果、Firebird・アルメニア・Hrazdan・本AI工場を
扱った既存テーマは存在しない(重複確認済み)。近縁テーマとして
`2026-07-24_openai-project-camellia-datacenter`(OpenAIのデータセンター計画)・
`2026-08-04_volta-ai-infra-300m`(Volta AI Infraの資金調達)があるが、いずれも別企業・
別の資金調達/施設のニュースであり、主題は重複しない。

## 本テーマ特有の扱い: タイトル表現と「CIS地域最大」の正確さの両立

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)のみを
通常より強めにしてよいこととされている。この指示は正確さ・出典・正直さの
ルールを緩めるものではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「アメリカでも中国でもなくアルメニアだった」という地理的な意外性を強調する表現 | オーナー指示により通常より強めの表現を許容し採用 |
| 規模表現 | 報道各社が使う「CIS地域最大」という限定的な表現 | 「世界最大」への言い換え・誇張は行わず、専用スライド(20・21)で範囲の違いを明示 |
| 政治的要素 | アルメニア首相の開所式出席という事実 | 出席の事実のみを扱い、アルメニアの政治・政府方針についての評価・論評は行わない(専用スライド26) |
| 非公開・未確認の情報 | フェーズ2/3の完成時期・Perplexity以外の顧客・投資優遇措置・Firebirdの出資構造 | 「確認できなかったこと」として一覧化(スライド22) |

締めのスライド30では「世界最大級と呼びたくなる話ほど、正確な範囲を確かめてから伝えたい」ことを提示している。

## 適用したルール

- 30枚デッキ、bullets比率26.7%(8/30枚、40%上限クリア)、同一レイアウト連続は最大2
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用)
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_statで図解化
  (推移データが限られるため`bar_chart`ではなく`table`・`big_stat`で扱った。
  実在人物への直接取材コメントが確認できなかったため`quote`は使用していない)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「アメリカでも中国でもなくアルメニア」
  「ジェンスン・フアンCEO」という固有名詞・具体的な構図を即座に提示し、挨拶・前置きを
  省いた
- 初心者向け前提知識スライド(「AI工場」「DSXプラットフォーム」の用語解説、構成の概念図) +
  実践的な整理(「これは私たちにとって何を意味するか」、スライド19)
- **事実・推測・不明を明確に区別**: 開所日・規模という事実と、今後の展開・論点という
  当社の推測(スライド23・24)、非公開項目という不明(スライド22)を分けて扱った
- **『CIS地域最大』と『世界最大』の混同回避**: 報道各社が使う限定的な表現を正確に保ち、
  専用スライド(20・21)で範囲の違いを明示的に解説した
- **政治的中立性**: アルメニア首相の開所式出席という事実は扱うが、アルメニアの政治・
  政府方針についての評価・論評は一切行わず、専用スライド(26)でその方針を明示した
- **タイトル表現の緩和と、内容面の誠実さの両立**: オーナー指示により見出しの表現は
  強めているが、専用スライド(25)で本文が誇張していないことを明示した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 実在企業名・実在人物名はテキストとしてのみ扱い、ロゴ・商標・肖像は使用していない
