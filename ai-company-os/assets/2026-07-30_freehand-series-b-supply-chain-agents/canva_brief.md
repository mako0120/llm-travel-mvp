## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| quote | 引用レイアウト(引用元を帰属に明記) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(推移データ・
  構成比のデータが限られたため、数字は `big_stat` と `table` で扱っている)。

## このデッキ固有の注意

- **スライド7・15・16の「7,500万ドル」「5〜10%」「5〜7倍・70%超」は本テーマの
  中心となる数字**である。スライド16の効果数値は**顧客報告値であり第三者検証
  ではない**旨をキャプションで必ず残すこと
- **スライド18の`quote`はCEO Nitin Jayakrishnan氏、スライド20は投資家Penny
  Pritzker氏のコメントを複数媒体経由で引用**している。帰属テキストを必ず
  残すこと
- **スライド22は「シリーズB」と「シード調達」という情報源間の表記の食い違いを
  正直に開示する**スライドであり、削除しないこと
- **スライド23は「Freehand自体の日本国内の顧客・拠点は不明」という開示**
  であり、保持すること
- スライド27は推測であることを本文に明記している。断定形に書き換えないこと
- 実在企業名(Freehand、Meta、Unilever、Johnson & Johnson、Pfizer、Dunkin'、
  Cardinal Health、Battery Ventures、NewRoad Capital Partners、PSP Growth、
  Nexus Venture Partners)はテキストとしてのみ扱い、ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない。移植時も断定的な推奨
  文言を追加しないこと

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`slate_azure`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
