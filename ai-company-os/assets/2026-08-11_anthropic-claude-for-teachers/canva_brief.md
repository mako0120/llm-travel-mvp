## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字・1キーワード強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない(推移
  データ・直接引用が本テーマにはないため、数字・要点は`big_stat`と`table`/`cards`で
  扱った)。

## このデッキ固有の注意

- **スライド9「基礎知識:教員向けAIアシスタントとは」・スライド20「AIが先生に取って
  代わるという論調への注意」は削除しないこと**。「AIが教員に取って代わる」という
  論調を避ける本テーマの核心部分である
- **スライド17「教室向けAIをめぐる企業の状況」は、Anthropic・OpenAI・Googleの3社を
  公平に扱う表現のまま維持すること**。OpenAI・Googleの具体的な製品名は本調査で確認
  できていないため、憶測で埋めないこと
- **スライド21「本テーマでの表現についての方針」・スライド22「本テーマの取り扱い
  方針(自己言及リスクへの配慮)」は削除しないこと**。スライド22は、本パイプライン
  自体がAnthropicのClaude Codeで制作されているという事実を明記する専用スライドで
  あり、必ず維持する
- **スライド23「事実・推測・不明の区別」・スライド24「確認できなかったこと」は
  削除しないこと**。出典が現時点で1記事にとどまる旨も含む
- 実在企業名(Anthropic、OpenAI、Google等)はテキストとしてのみ扱い、写真・ロゴは
  一切使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 「画期的」「最高の」「革命的」等のsuperlative・宣伝的表現を追加しないこと

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成

   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
