移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「決勝は28号2ラン――村上宗隆、首位攻防3連戦をスイープに導く」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: MLB・野球ニュースに関心がある一般視聴者。専門知識がない前提で、
  選手・野球用語(首位攻防・マジックナンバー・スイープ)の基礎知識から数字の深掘りまで
  丁寧に分解して説明するスライドを設けている
- パレット(HEX、indigo_cyanプリセット): Primary `#2E2A72` / Primary Dark `#1B1846` /

- 使用素材のライセンス確認: 無料素材のみ(実在選手の写真・肖像・実在球団のロゴ・商標は

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(3ノード) |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。スコア・スタッツの比較はbar_chart/table/
cardsで扱っている)。

## このデッキ固有の注意(数字の正確さとマジックナンバーの扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「決勝28号2ランだって?」という
  フックを提示しつつ、直後に「首位攻防の3連戦をスイープしました」という正確な結果を
  添えている。フック性の強い表現は許容するが、数字を誇張・丸めないこと
- **スライド9・10・11・13・16・17は数字の核心スライド**(最終スコア7-5、村上選手の
  スタッツ5打数1安打2打点2三振、28号、今季通算.235/28本/57打点/OPS.911)であり、
  数字を混同・省略・丸めないこと
- **スライド12・14は決勝弾の状況(7回表・無死一塁・左腕ホルトン・真ん中のシンカー)を
  正確に扱うスライド**であり、投手名・球種・アウトカウントを変更しないこと
- **スライド18・21・25・26は『マジックナンバー33』の算出根拠、3連戦の1戦目・2戦目の
  個別スコアが未確認であることを示すスライド**であり、具体的な計算過程や数字を
  創作して埋めないこと
- **スライド21は誇張回避を明示するスライド**であり、削除しないこと
- 実在選手名(村上宗隆選手)はテキストとしてのみ扱い、写真・肖像・実在球団(ホワイト
  ソックス・タイガース)のロゴ・商標は使用しない
- 特定企業・製品・球団の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`indigo_cyan`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
