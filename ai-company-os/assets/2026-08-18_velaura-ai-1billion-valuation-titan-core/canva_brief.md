## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 番号バッジ付き横並びステップ(矢印つき) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `pie_chart` / `line_chart` / `quote` は含まれない。
構成比・時系列推移を表すデータや引用素材が存在しないため、単一時点の数字は
`big_stat`/`table`で扱っている。

## このデッキ固有の注意(数字の正確さと非公表・不明項目の扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「評価額10億ドル超」
  というフックを提示しつつ、直後に発表日・調達額という正確な事実を添えている。
  フック性の強い表現は許容するが、製品性能を保証するような表現に書き換え
  ないこと
- **スライド7・8・10・11は核心となる数字(調達額1億1000万ドル・到達評価額
  10億ドル超)を扱う核心スライド**であり、数字を混同・省略・丸めないこと
- **スライド12は評価額(企業価値)の定義を扱うスライド**であり、「評価額=
  確定した企業の値段」であるかのような誤解を招く表現に書き換えないこと
- **スライド14・15は Titan Coreの電力あたり性能2〜4倍を扱う核心スライド**
  であり、この数値が独立機関による第三者検証済みであるかのように書き換え
  ないこと
- **スライド19は製品出荷時期が不明である旨を扱うスライド**であり、具体的な
  出荷時期を創作しないこと(このデッキでは一切使用していない情報である)
- **スライド21は既存顧客の有無が不明であることを示すスライド**であり、
  具体的な顧客名を創作しないこと
- **スライド22は性能改善数値の第三者検証が不明であることを示すスライド**
  であり、性能の優劣を証明済みのように書き換えないこと
- **スライド23は見出しの印象(評価額10億ドル超=完全に成功)と実際に確認
  できている内容のギャップを示すスライド**であり、削除しないこと
- **スライド24は同日発表のEtchedテーマ(229本目・既存)との違いを示す
  スライド**であり、両者が別会社・別製品・別の技術アプローチであることを
  明示する内容を保持すること(重複コンテンツと誤解されないための必須項目)
- **スライド26は誇張回避・確認ポイントを明示するスライド**であり、削除
  しないこと
- Velaura AI・Etched等の実在企業のロゴ・商標は使用しない
- Velaura AIの製品(Titan Core)は事実として紹介するのみで、特定製品への
  乗り換えを推奨する表現に書き換えない(スライド20・26)
