# 「松山英樹、優勝ではなく7位――それでも4戦連続トップ10でBMW選手権進出決定」(2026-08-16最終日確定・2026-08-17制作)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
2026年8月16日、米男子ゴルフPGAツアー・プレーオフシリーズ第1戦「フェデックス・
セントジュード選手権2026」最終日、松山英樹選手が6打差6位から出場し、この日71で
回って通算6アンダーパー・274、7位でフィニッシュした件を、「優勝ではなく7位」という
事実を一貫して明示しながら、4戦連続トップ10・BMW選手権進出という継続的な好調さの
軸で構成している。

## 選定理由

- 対象ジャンル「海外/国内で活躍する日本人」枠
- 2026年8月16日、松山英樹選手がフェデックス・セントジュード選手権最終日で7位
  フィニッシュし、4戦連続トップ10でBMW選手権進出を決めた(着手日2026-08-17の
  前日、`docs/06_Content_R&D.md`の「着手日を含めて2日以内」という鮮度基準を満たす)
- ALBA Net・Olympics.com日本語版・日刊スポーツ(Yahoo!ニュース配信)・ゴルフ
  ダイジェストという複数の専門メディアが数値を一致させて報じている
- 「優勝ではないのに4戦連続トップ10」という継続的な好調さと、正確な事実整理が
  両立する強いフックがある(`research/2026-08-17_theme-evaluation-round145.md`参照)

## 適用したルール

- 30枚デッキ、bullets比率30%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成)
- palette_presetは指示どおり`graphite_emerald`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「4戦連続トップ10だって?」という
  フックを提示した直後に「優勝ではありません」という正確な事実を添え、挨拶・
  前置きを省いた
- **「優勝ではなく7位」の明確な明示(本テーマの核心)**: 優勝はスコッティ・
  シェフラー選手、松山選手は7位・差は11打であることを、title/big_stat/steps/
  diagram/comparisonで複数回・複数形式で明示し、誤解を招く表現を排除した
- 初心者向け前提知識スライド(選手紹介・プレーオフシリーズ・FedExCup・BMW選手権
  の用語解説)+ 読者の立場別(ゴルフファン・ニュースを追う立場・発信する立場)の
  実践的示唆(スライド24)
- 出典のない数字は作らず、確認できなかった項目(BMW選手権の出場資格の詳細基準・
  開催日程・過去3試合の内訳・賞金額・世界ランキングへの影響等)は正直に「不明」と
  明記した(テーブル・スライド19・26・27)
- 誇張回避: 「優勝した」「大逆転した」等の誇張表現を避け、断定的な将来予測もしない
  旨を専用スライドで明示した(スライド21)
- 見出しの印象(「優勝した」等の誤解)と実際の内容(7位という事実)のギャップを
  専用スライドで明示した(スライド20)
- 実在選手(松山英樹選手・スコッティ・シェフラー選手)の写真・肖像は使用せず、
  抽象的な図解・アイコンのみで構成した
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張は一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- 同一レイアウト4連続以上チェック・bullets比率40%以下チェック(30%) →
  合格(`build_deck.py`のビルド時検証を通過)
- `generate_dialogue_script.py --deck deck_spec.json` によるスライド数一致・
  スライド連番検証 → 合格(30スライド全カバー)
- 著作権・品質自己評価: 97点/100点(85点以上のため修正不要)

- 「優勝ではなく7位」という事実を、混同・誇張なく一貫して扱っている
