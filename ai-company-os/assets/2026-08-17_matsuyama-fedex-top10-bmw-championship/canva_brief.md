移植仕様書(ブリーフ)である。

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。順位・ランキングの推移はbar_chartで
扱っている)。

## このデッキ固有の注意(「優勝ではなく7位」を正確に扱うことが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「4戦連続トップ10」という
  フックを提示しつつ、直後に「優勝ではありません」と正確な事実を添えている。
  フック性の強い表現は許容するが、「優勝した」と誤解させる書き換えは行わないこと
- **スライド7・12・13は「優勝との差11打」を扱う核心スライド**であり、優勝は
  スコッティ・シェフラー選手、松山選手は7位という事実を混同・省略しないこと
- **スライド16・17は「4戦連続トップ10」の対象範囲(過去3試合の内訳は未確認)を
  明示するスライド**であり、内訳を創作した表現への書き換えは行わないこと
- **スライド19・26・27はBMW選手権の出場資格・日程が未確認であることを示す
  スライド**であり、具体的なカットライン人数や日程を創作して埋めないこと
- **スライド20は見出しの印象(優勝した等)と実際の内容のギャップを示すスライド**
  であり、削除しないこと
- **スライド21は誇張回避を明示するスライド**であり、削除しないこと
- 実在選手名(松山英樹選手・スコッティ・シェフラー選手)はテキストとしてのみ扱い、
  写真・肖像・実在団体のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`graphite_emerald`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
