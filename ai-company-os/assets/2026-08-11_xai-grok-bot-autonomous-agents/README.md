# 「あなたの会社に、24時間眠らないAI社員が来た――xAI『Grok Bot』ベータ版を出典付きで整理する」(2026-08-11発表・2026-08-12・182本目)

定期実行パイプラインの182本目。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠
- 2026年8月11日、xAIが常時稼働(always-on)の自律型AIエージェント群「Grok Bot」の
  ベータ版を発表した(着手日2026-08-12の1日前、`docs/06_Content_R&D.md`の
  「着手日を含めて2日以内」という鮮度基準を満たす)
- Unite.AI・Yahoo Finance・x.ai公式ニュースページ・Basenorという、独立した4つの
  情報源が同日に報道・掲載しており、`docs/06_Content_R&D.md`モードB(バイラル
  優先モード)の「複数の信頼できるメディアが話題と報じている」という実証済みの
  話題性基準を満たす
- 各Grok Botが専用のクラウドコンピュータを持ち、監督なしに複数ステップの業務を
  完了するという具体的な仕組みの新しさ、xAI社内の具体的な利用例(夜間に営業メール
  を作成する「outbound Bot」、デモ環境の不具合を検知・修正する「demo-readiness
  Bot」等)が分かりやすいフックになる

## 適用したルール

- 30枚デッキ、bullets比率30.0%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大3(4連続以上は一度も発生しない構成)
- palette_presetは`navy_gold`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「あなたの会社に、24時間眠らない
  AI社員が来た」というフックを即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(xAI・Grok・Grok Botとは何か)+ 読者の立場別
  (ビジネス利用者・開発者/情シス担当者・AIニュースを追う立場)の実践的示唆
  (スライド22)
- 定量的な推移・比較データに乏しいテーマのため、`bar_chart`等のグラフ系レイアウト
  は使わず、`table`・`cards`・`steps`・`diagram`で仕組み・プラン・利用例を整理した
- 出典のない数字は作らず、確認できなかったこと(料金・利用者数・Grok 4.6の正確な
  リリース日・実際の評価)は正直に「不明」と一覧化した(スライド18)
- 特定企業・製品の利用を強く推奨する結論にはしていない
- xAI・イーロン・マスク氏個人への政治的評価は一切行っていない
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張は一切行っていない

## リスク配慮

- 「AIが人間の仕事を完全に奪う」といった誇張表現は使わず、常時稼働・専用クラウド
  コンピュータという公表された仕組みの事実紹介にとどめている
- ベータ版の具体的な料金・利用者数・導入企業数・Grok 4.6の正確なリリース日・
  利用者からの実際の評価は、報道からは確認できていない旨をスライド18で一覧化
- 提供プランが既存の上位契約プラン(SuperGrok Heavy・Cursor Ultra・Cursor Teams
  Premium)への組み込みであり、「誰でも無料で使える」わけではない旨を保持している
  (スライド10)
- xAI社内の利用例(outbound Bot・demo-readiness Bot等)は社内利用例であり、
  外部顧客の成果を示すものではない旨を扱いに反映している
- 見出しの印象(「AIが何でも自律してこなす」)と実際の内容(既存の上位プラン限定の
  提供)のギャップをスライド21で明示している
- 既存テーマ(26本目・109本目)との関係(対象製品・内容が異なる別のテーマである
  こと)をスライド20・本README・research.mdで明示している
- xAI・イーロン・マスク氏個人への政治的評価は一切行っていない
- 実在企業名(xAI)はテキストとしてのみ扱い、ロゴ・商標・肖像は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 政治的な価値判断・政党や政治家個人への評価は一切行っていない
- 公開・投稿はまだ行っていない
