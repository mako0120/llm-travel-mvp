## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `quote` / `bar_chart` / `line_chart` / `pie_chart` は含まれない
  (発言の直接引用となる一次インタビューは確認できておらず`quote`は不使用。
  今回のテーマは定量的な数値比較データに乏しく、`table`と`cards`・`steps`で
  仕組み・プラン・利用例を整理する構成にした)。

## このデッキ固有の注意

- **スライド1・2は本テーマのコールドオープン(「24時間眠らないAI社員」)**である。
  数字・事実の誇張ではなく、公表された仕組み(常時稼働・専用クラウドコンピュータ)の
  紹介であることを保持すること
- **スライド10は提供プランが既存の上位契約プラン(SuperGrok Heavy・Cursor Ultra・
  Cursor Teams Premium)への組み込みであることを示すスライド**であり、「誰でも
  無料で使える」という誤解を招く表現に書き換えないこと
- **スライド12〜15はxAI社内の利用例(outbound Bot・demo-readiness Bot等)**であり、
  これらは社内利用例であって外部顧客の成果を示すものではない旨を保持すること
- **スライド18は「確認できなかったこと」の一覧**であり、削除しないこと
- **スライド20は既存テーマ(26本目・109本目)との関係を整理するスライド**であり、
  削除しないこと。対象製品・内容が異なる別のテーマであるという整理を保持すること
- **スライド21は見出しの印象と実際の内容のギャップを示す核心スライド**である。
  「AIが何でも自律してこなす」かのような表現に書き換えないこと
- 実在企業名(xAI)はテキストとしてのみ扱い、ロゴ・商標・イーロン・マスク氏の
  肖像は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
