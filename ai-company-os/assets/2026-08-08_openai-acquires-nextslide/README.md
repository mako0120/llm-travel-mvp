# 「AIによる資料作成が、AI業界最大手に丸ごと買収された日」(2026-08-08・145本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠、企業M&A・ChatGPTのプロダクト拡張の切り口
- オーナー指定テーマ(145本目)として制作を開始
- 2026年8月8日、TechCrunchが「OpenAIがAIプレゼン生成スタートアップNextSlideを
  買収し、チーム全員をChatGPT開発チームへ統合した」と報道。着手日
  (2026年8月9日)から見て1日前の報道であり、`docs/06_Content_R&D.md`の
  鮮度基準(着手日を含めて2日以内)を満たす
- Yahoo Finance・Unite.AI・BigGo Finance・CryptoBriefingという独立した複数の
  メディアが同内容を裏付けている
- 「プロンプトから資料を自動生成するAIツールの会社が、AI業界最大手にまるごと
  買収された」という構図は、本パイプライン(AI Company OS)自身がまさに行って
  いる作業(調査→構成→JSON→生成→検品→原稿)と直接重なる自己言及的な
  フックがあり、話題性が高い

## 本テーマ特有の扱い: タイトル表現と誇張回避の両立

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)のみを
通常より強めにしてよいこととされている。この指示は正確さ・出典・正直さの
ルールを緩めるものではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「AIで資料を作るAIが、AI業界最大手に丸ごと買収された」等の注目を集める表現 | オーナー指示により通常より強めの表現を許容し採用 |
| 本文・スライド内容 | 事実(報道内容)と当社の推測を全編で区別、断定的結論を避ける | 誇張・断定はせず、専用スライド(26)で「本文は誇張していない」ことを明示 |
| 非公開・未確認の情報 | 買収金額・チーム人数・統合スケジュール・資金調達履歴・正確な成立日 | 「確認できなかったこと」として一覧化(スライド19) |

締めのスライド30では「事実と推測は分けて追っていく」ことを提示している。

## 適用したルール

- 30枚デッキ、bullets比率23.3%(40%上限クリア)、同一レイアウト連続は最大3
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_statで図解化
  (推移データが限られるため`bar_chart`ではなく`table`・`big_stat`で扱った。
  実在人物への直接取材コメントが確認できなかったため`quote`は使用していない)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「AIで資料を作るAI」
  「AI業界最大手に丸ごと買収」という固有名詞・具体的な構図を即座に提示し、
  挨拶・前置きを省いた。冒頭でNextSlide・OpenAIという固有名詞も発話している
- 初心者向け前提知識スライド(人材獲得型買収の概念解説、買収構造の概念図) +
  実践的な整理(ChatGPTユーザーにとって今何が変わるか、スライド20)
- **事実・推測・不明を明確に区別**: 買収日・報道内容という事実と、統合後の
  姿・今後の論点という当社の推測(スライド21・23)、非公開項目という不明
  (スライド19)を分けて扱った
- **タイトル表現の緩和と、内容面の誠実さの両立**: オーナー指示により見出しの
  表現は強めているが、専用スライド(26)で本文が誇張していないことを明示した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 実在企業名・実在人物名はテキストとしてのみ扱い、ロゴ・商標・肖像は使用していない
