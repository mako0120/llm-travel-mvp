# 「169.7キロの史上最速から、大谷は三塁打を放った。それでもドジャースは敗れた。」(2026-08-16試合・2026-08-16制作)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
2026年8月16日(日本時間)、ドジャー・スタジアムでのブルワーズ戦を、ブルワーズ先発
ミジオロウスキー投手の「先発投手として史上最速」となる105.5マイル(約169.7キロ)の
投球記録と、その中で大谷翔平選手が放った適時三塁打、そしてドジャースが1-4で敗れた
という結果を軸に構成している。

## 選定理由

- 対象ジャンル「海外/国内で活躍する日本人」枠
- 2026年8月16日、大谷翔平選手が1番・DHで先発出場したドジャース対ブルワーズ戦で、
  ブルワーズ先発ミジオロウスキー投手が先発投手として史上最速の105.5マイル(約169.7
  キロ)を記録し、大谷選手も3回に一塁線を破る適時三塁打を放った(着手日当日、
  `docs/06_Content_R&D.md`の「着手日を含めて2日以内」という鮮度基準を最も新しい形で
  満たす)
- BASEBALL KING・TBS NEWS DIG(docomoニュース経由)・livedoor Newsという独立した
  3媒体が数値を一致させて報じている
- 「史上最速の剛速球」というフックと、大谷選手の個人成績・チームの敗戦という3つの
  異なる事実が同じ試合で重なったという、強いストーリー性がある
  (`research/2026-08-16_theme-evaluation-round140.md`参照)

## 適用したルール

- 30枚デッキ、bullets比率23%(7/30枚、40%上限クリア)、同一レイアウト連続は最大1
  (4連続以上は一度も発生しない構成)
- palette_presetは指示どおり`crimson_gold`を使用
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「先発投手、史上最速169.7キロ」と
  いうフックを即座に提示しつつ、同じ導入部分で「それでもドジャースは敗れた」という
  結果も隠さず示し、挨拶・前置きを省いた
- **敗戦を勝利のように示さない(本テーマの核心)**: タイトル・冒頭スライド(1・2)・
  結論スライドから一貫して1-4の敗戦という結果を明示し、大谷選手個人の活躍(適時
  三塁打)とチームの結果を混同していない。見出しの印象と実際の結果のギャップを専用
  スライド(16)、誇張回避の補足を専用スライド(17)で明示している
- **2つの打席の明確な区別**: 第1打席(165キロ超が続き、167キロで三飛)と3回の適時
  三塁打(一塁線)を混同せず、bar_chart・table・bulletsで複数回・複数形式で区別を
  明示した。169.7キロの記録がどの打席の球かは出典で特定されていない旨も明記した
- **記録の条件明示**: 「先発投手として史上最速」という条件つきの記録であることを
  専用テーブル(スライド20)で明示し、無条件の史上最速であるかのような誇張はしていない
- 初心者向け前提知識スライド(マイル→キロ換算・適時打・「先発投手として」の条件)+
  読者の立場別(野球ファン・ニュースを追う立場・発信する立場)の実践的示唆
  (スライド23)
- 出典のない数字は作らず、確認できなかった項目(シーズン成績・順位への影響・球種球速
  等)は正直に「不明」と明記した(テーブル・スライド24・25)
- 実在選手(大谷翔平選手・ミジオロウスキー投手・ロブレスキー投手)の写真・肖像は
  使用せず、抽象的な図解・アイコンのみで構成した
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき相対的に
  強い表現を用いているが、数字・事実の捏造や誇張、および結果の歪曲は一切行っていない
