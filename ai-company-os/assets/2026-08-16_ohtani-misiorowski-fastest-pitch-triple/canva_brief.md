## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `quote` / `line_chart` は含まれない(構成比を示す
データや、確認済みの選手コメント、推移データがないため)。

## このデッキ固有の注意(勝敗の誠実な扱いが最重要)

- **スライド1・2は本テーマのコールドオープン**である。「史上最速169.7キロ」という
  フック性の強い表現を1行目に置きつつ、同じ導入部分で「それでもドジャースは敗れた」
  という結果を隠さず示す構成になっている。フックだけを残して結果部分を削る書き換えは
  行わないこと
- **スライド15・16は最終スコア(1-4)と「見出しの印象/実際の結果」のギャップを示す
  核心スライド**である。「大谷の一撃で勝利」等、試合結果と矛盾する誇張表現への書き換え
  は行わないこと
- **スライド9・10・22は、第1打席(167キロで三飛)と3回の適時三塁打(一塁線)という
  別の打席を区別するスライド**である。この2つを1つの場面のように統合した表現に書き
  換えないこと
- **スライド20は「先発投手として史上最速」という記録の条件(範囲)を明示する
  スライド**であり、無条件の史上最速であるかのような表現への書き換えは行わないこと
- **スライド24・25は「確認できていないこと」の一覧**であり、削除しないこと
- **スライド17は誇張回避を明示するスライド**であり、削除しないこと
- 実在選手名(大谷翔平選手・ミジオロウスキー投手・ロブレスキー投手)はテキストとして
  のみ扱い、写真・肖像・実在球団のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`crimson_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
