## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `quote` / `bar_chart` / `line_chart` / `pie_chart` は含まれない
  (発言の直接引用となる一次資料への直接アクセスは確認できておらず`quote`は不使用。
  今回のテーマは経年推移などの定量チャート向けデータに乏しく、`table`・`comparison`・
  `steps`で違い・時系列・事実一覧を整理する構成にした)。

## このデッキ固有の注意

- **スライド1・2は本テーマのコールドオープン(「ついに、突破した」)**である。数字・
  事実の誇張ではなく、CEO本人が発表した節目の紹介であることを保持すること
- **スライド8・10・24は既存87本目との関係を整理する核心スライド**であり、削除しない
  こと。「接近」から「突破」への続報であり、87本目を否定・軽視する表現に書き換え
  ないこと
- **スライド16は「確認できなかったこと」の一覧**であり、削除しないこと(地域別内訳・
  有料/無料内訳・X投稿原文全文・算出根拠の詳細)
- **スライド19は見出しの印象と実際の内容のギャップを示す核心スライド**である。
  「Geminiが他を完全に上回った」かのような表現に書き換えないこと
- **スライド21は誇張回避・中立性の宣言スライド**であり、削除しないこと
- 実在企業名(Google)・CEO氏名(サンダー・ピチャイ)はテキストとしてのみ扱い、
  ロゴ・商標・肖像は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
