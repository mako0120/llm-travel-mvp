## 選定理由

- 対象ジャンル「AI/エージェント系」枠(70%)
- `research/2026-07-24_theme-evaluation-round30.md`(2026-07-29実施)で**75点の次点**として
  「次サイクル以降の候補として残す」と明示的に記録されていた候補
- **「常に最新の原則」(docs/06_Content_R&D.md)に従い、着手時点(2026-07-29)で最新ニュースを
  再確認したが、これを上回るAI/エージェント系候補は見つからなかった**(Businessolver、
  Cyabra、RHA Technologies、Unstop等を確認したが、いずれも著名度・一次情報の厚みで
  Microsoftの公式発表に及ばないと判断)
- Microsoft公式ニュースに加え、TechCrunch・Axios・SecurityWeek等の**複数の独立した専門
  メディアが同じ発表を報じている**
- 「専用AIモデル+汎用モデルの役割分担でコストを抑える」という設計思想は、新モデルの
  性能自慢より**視聴者の現場(コスト・運用設計)に直結する**内容

評価スコア(次点時点): 75/100(詳細は`ai-company-os/research/2026-07-24_theme-evaluation-round30.md`)

## 適用したルール

- 30枚デッキ、bullets比率13.3%(40%上限クリア)、同一レイアウト連続は最大2
- 文字中心の説明はtable/diagram/comparison/steps/quoteで図解・引用化
  (グラフ化に適した時系列・比較データが無かったため`bar_chart`は使っていない)
- **コールドオープン**: 冒頭(1枚目・ナレーション1行目)で「9割・半分」という数字を
  即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(専用AIモデルとエージェント基盤の違い)
  + 実践手順(現状整理→分担の当てはめ→検証の有無の確認)
- **数値の食い違いを両論併記**: 96%/95.95%を混ぜず、どちらか一方に断定しない
- **情報の限界を先に開示**: 6サイトすべて403で本文を読めていないことを4枚目で先に言う
- 一方的に持ち上げず、確かなこと/慎重に見るべきことを対比(21枚目)
- 特定企業のサービスを推奨する結論にはしていない
- 前サイクルとの接続スライドは設けていない
