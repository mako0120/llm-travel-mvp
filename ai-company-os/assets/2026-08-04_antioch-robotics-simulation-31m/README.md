- ロボティクスシミュレーション基盤企業Antiochが、SEC提出書類(Form D)に
  基づき新たに3,140万ドルの資金調達を行ったことが、2026年8月4日、
  AlleyWatchの報道によって判明した
- 元Tesla Autopilotチームに在籍していたHarry Mellsop氏を含む4名が2025年に
  共同創業、「ロボットをソフトウェアだけで構築・テスト・展開する」という
  分かりやすいフックと、着手日当日という最高水準の鮮度がバズ路線と親和する

### 正直な開示: round79評価表でスコア73/100での採用

本テーマは
`ai-company-os/research/2026-08-04_theme-evaluation-round79.md`のround79
評価表において、**スコア73/100**で採用された。これは通常の採用基準(70点
未満は不採用)を上回る水準である。採用理由は、着手日当日という最高水準の
鮮度、「ソフトウェアだけでロボットをテストする」という分かりやすいフック、
元Tesla Autopilotチームという創業者の経歴がバズ路線と親和する点である。
一方で、出典がSEC提出書類の報道のみであり、企業公式発表と比べて情報の厚みに
欠ける点も、round79評価表・本README・research.md・risk-and-quality-
review.mdで一貫して開示している。

## 出典の性質についての重大な開示(SEC提出書類報道であること)

**今回の3,140万ドルという数字は、Antioch自身のプレスリリースや公式発表に
基づくものではない。** AlleyWatchが、SECに提出されたForm D(私募増資の届出
書類)を確認して報じた二次情報である。これはGritt(BusinessWire等、企業
発表)のようなこれまでの資金調達テーマと比べて、明確に情報の厚みが薄い
ソーシング状況である。主導投資家の名前、8名の投資家の具体的な社名・個人名、
本ラウンドの資金使途は、この出典からは得られない。この点を水増しせず積極的
に開示し、専用スライド(15・16)を設けている。累計調達額(4,400万ドル)が、
以前のシード(850万ドル)+今回のラウンド(3,140万ドル)の単純合計(3,990
万ドル)と一致しない点(約410万ドルの差)についても、差額の理由が出典から
確認できない旨を明記し、推測で埋めていない(スライド14キャプション)。

## 鮮度についての開示(このシリーズで最高水準)

本発表(判明)は2026年8月4日であり、着手日(2026年8月4日)**当日**である。
`docs/06_Content_R&D.md`の鮮度基準(着手日の前日以内)を明確に満たしており、
これまでこのシリーズで制作した全テーマの中でも最高水準の鮮度である。専用
スライド(25)で開示している。**ただし、鮮度が最高水準だからといって、出典
の薄さ(risk-and-quality-review.mdの出典の明確さ13/20)を他項目で水増しして
穴埋めすることはしていない。**

## 見出し表現の方針についての正直な開示

見出し・タイトルの表現は「バズる人気」優先の意外性を強調した表現にしている
(例: 「ロボットを壊さずに鍛える。元Teslaオートパイロット開発者が作った
『シミュレーションだけの道場』に3,140万ドル」)。**ただし、数字の創作・出典
のない断定・特定企業の過度な推奨・政治的中立性の逸脱は、これまでどおり一切
行っていない。**

## 既存テーマとの関係(重複でないことの確認)

`ai-company-os/assets/`配下を確認し(`ls assets/ | grep -i antioch`)、

ソフトウェアのみのシミュレーション基盤)が異なり、本テーマ(Antioch)と重複
するものではない。

本テーマでは`indigo_cyan`(深紫+ラベンダー+シアン)というパレットプリセット
を使用した。`indigo_cyan`は前回のGrittテーマ(`steel_amber`)と同時期
(2026-08-04)に`scripts/build_deck.py`の`PALETTE_PRESETS`へ新規追加された
2つ目のプリセットで、`docs/04_PowerPoint.md`にも「シミュレーション・デジタル
ツイン・仮想空間系(Antioch等)」として反映されている。本テーマの`deck_spec.

`#D6D9F5` / Accent `#17C3B2`)を指定しており、シミュレーション・仮想空間と
いう本テーマの内容にも配色イメージが合致する。既存プリセット(`navy_gold`/
`forest_sand`/`slate_azure`/`steel_amber`/`impact_red`)の定義・挙動は変更
していない。
