## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字・1キーワード強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない(推移
  データ・直接引用が本テーマにはないため、数字・要点は`big_stat`と`table`/`cards`で
  扱った)。

## このデッキ固有の注意

- **スライド9〜11「基礎知識:EU AI Act第50条・電子透かし・来歴情報とは」は削除しない
  こと**。専門用語を初心者向けに分解する本テーマの前提知識部分である
- **スライド23「確認できなかったこと(一覧)」・スライド24「事実・推測・不明の区別」は
  削除しないこと**。技術的仕組み・検出方法・UX影響・対象モダリティ・競合動向が不明
  である旨を含む
- **スライド25「競合他社の動向について(正直な開示)」は削除しないこと**。OpenAI・
  Google等の同種の取り組みについて、本ラウンドの調査範囲では確認できていない旨を
  正直に開示する部分であり、憶測で埋めないこと
- **スライド26「本テーマの取り扱い方針(自己参照リスクへの配慮・削除禁止)」は絶対に
  削除しないこと**。本パイプライン自体がAnthropic社のClaude(Claude Code)を基盤に
  制作されているという事実を明記する専用スライドであり、必ず維持する
- 実在企業名(Anthropic等)はテキストとしてのみ扱い、写真・ロゴは一切使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 「画期的」「最高の」「業界をリードする」等のsuperlative・宣伝的表現を追加しないこと
- EU規制そのものへの評価的な立場を追加しないこと(政治的中立性)
