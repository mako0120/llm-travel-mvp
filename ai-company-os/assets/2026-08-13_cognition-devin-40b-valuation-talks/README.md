# 「Cognition(Devin開発元)、評価額400億ドルでの資金調達交渉中と報道」(2026-08-11〜12報道・2026-08-13・195本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。
定期実行パイプラインの195本目。「資金調達交渉中」という報道段階の情報であることを、
一貫して断定表現を避けて明示することを特に重視している。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠
- 2026年8月11〜12日、AIコーディングエージェント「Devin」を開発するCognition社が、
  評価額少なくとも400億ドルでの新規資金調達に向け投資家と交渉中であるとBloombergが
  報じた(着手日2026-08-13の1〜2日前、`docs/06_Content_R&D.md`の「着手日を含めて2日
  以内」という鮮度基準を満たす)
- Bloomberg・TechCrunch・PYMNTS・Benzinga・TechFundingNewsという、独立した複数の
  情報源が一致して報道しており、`docs/06_Content_R&D.md`モードB(バイラル優先モード)の
  「複数の信頼できるメディアが話題と報じている」という実証済みの話題性基準を満たす
- 「3か月足らずで評価額が50%以上上昇」という急成長ぶり、「AIにエンジニアの仕事を
  任せる」というDevinのコンセプトの分かりやすさ、400億ドルという規模感がフックになる
  (`research/2026-08-13_theme-evaluation-round135.md`参照)

## 適用したルール

- 30枚デッキ、bullets比率30%(9/30枚、40%上限クリア)、同一レイアウト連続は
  最大2(4連続以上は一度も発生しない構成)
- palette_presetは`slate_azure`を使用(194本目がcrimson_goldだったため、8色
  ローテーションの次番として指定通り採用)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「3か月足らずで評価額が1.5倍」という
  フックを即座に提示し、挨拶・前置きを省いた
- **報道段階であることの明記**: タイトル・結論スライド(1・2)、交渉に関する
  スライド(10・15・16)、扱い方スライド(27)で、「決定した」「確定した」という断定を
  避け、一貫して「交渉中」「〜と報じられている」という表現を用いた
- 初心者向け前提知識スライド(Cognitionとは・Devinの仕組み図・「評価額」「ARR」の
  用語解説)+ 読者の立場別(投資動向を追う立場・AI技術動向を追う立場・社内でAI導入を
  検討する立場)の実践的示唆(スライド23)
- 評価額の推移(20億→102億→260億ドル)、ARRの推移(約100万→約7,300万→約4億9,200万
  ドル)を`bar_chart`/`line_chart`でネイティブグラフ化し、単なる文字の羅列にしない
- 出典のない数字は作らず、確認できなかったこと(交渉の進捗・新規投資家の具体名・
  正確なARR・Devinの顧客詳細等)は正直に「不明」と一覧化した(スライド24・25)
- 独立した開発者による検証・懐疑的な指摘(デモの再現性、ベンチマーク評価方法への
  留保)も隠さず紹介し、称賛一辺倒にしなかった(スライド21)
- 特定企業・製品の利用を強く推奨する結論にはしていない
- タイトル・冒頭フックは、オーナーの今回の指示(バズ路線の見出し方針)に基づき
  相対的に強い表現を用いているが、数字・事実の捏造や誇張は一切行っていない

## 検品結果

- `verify_pptx.py --min-slides 30 --max-slides 30` → 合格
- 同一レイアウト4連続以上チェック・bullets比率40%以下チェック(30%) → 合格
- `generate_dialogue_script.py --deck deck_spec.json` によるスライド数一致・
  スライド連番検証 → 合格(30スライド全カバー)
- 著作権・品質自己評価: 95点/100点(85点以上のため修正不要)

## リスク配慮

- 「評価額400億ドルになった」という断定表現は使わず、一貫して「交渉中」
  「〜と報じられている」という表現を用いている
- Bloombergが報じた「初期段階の交渉であり、条件が変わる・成立しない可能性もある」
  という留保を明記している
- Cognition・Devin・AIコーディングエージェント全般への政治的評価(良い/悪いの
  価値判断)は一切行っていない
- 独立した開発者による検証・懐疑的な指摘(デモの再現性、ベンチマーク評価方法への
  留保)も隠さず紹介し、称賛一辺倒にしていない
- 見出しの印象(評価額400億ドルが確定した等)と実際の内容(交渉の初期段階の報道で
  あること)のギャップを明示している
- 交渉の進捗・新規投資家の具体名・正確なARRの数値・Devinの顧客詳細など、報道からは
  確認できなかった項目を一覧化し、正直に「不明」として扱っている
- 実在企業名(Cognition・Devin等)はテキストとしてのみ扱い、ロゴ・商標・実在人物の
  肖像は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 公開・投稿はまだ行っていない
