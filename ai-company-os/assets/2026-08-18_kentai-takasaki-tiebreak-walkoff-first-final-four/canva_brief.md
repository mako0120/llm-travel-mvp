## 前提

Canva コネクタ(MCP)は本セッション時点で未接続(承認境界のため接続前提の作業は
約束しない)。以下は人間(または接続後の自動化)が Canva 上でデッキを再現するための
移植仕様書(ブリーフ)である。

## メタ情報

- デッキ名: 「健大高崎、延長タイブレークの死闘を制す――夏初のベスト4進出」
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 高校野球・甲子園に関心がある一般視聴者。専門知識がない前提で、
  準々決勝・タイブレーク・ビデオ検証の基礎知識から延長10回の決着経過の数字の
  深掘りまで丁寧に分解して説明するスライドを設けている。未成年の選手が主役である
  こと、対戦相手・有明高校の敗戦を主題化せず簡潔・中立的に扱うことを踏まえた
  構成になっている
- パレット(HEX、navy_goldプリセット): Primary `#1E2761` / Base `#CADCFC` /
  Accent `#D9A441`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント
  Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(実在選手の写真・肖像・実在団体(日本高等
  学校野球連盟・朝日新聞社等)のロゴ・商標は使用しない、図形・アイコンはCanva内蔵の
  無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(3ノード) |
| steps | 横並びステップカード+シェブロン矢印(4個) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。両チームの得点比較はbar_chartで扱っている)。

## このデッキ固有の注意(主役は健大高崎、有明の敗戦は主題化しないことが最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「延長10回タイブレークの末
  1-0でサヨナラ勝ち」というフックを提示しつつ、直後に正確な結果を添えている。
  フック性の強い表現は許容するが、有明の敗戦を煽り立てる方向に書き換えないこと
- **スライド10〜15は延長10回の決着経過(送りバント→石田選手の内野安打→藤村選手の
  本塁突入→ビデオ検証→セーフ確定)を扱う核心スライド**であり、確認できた範囲を
  超えて創作・追加しないこと
- **スライド16・17は石垣聡志投手の110球完封を扱う核心スライド**であり、大会通算の
  投球回数など未確認の数字を追加しないこと
- **スライド21は対戦相手・有明高校の結果を扱う唯一のスライド**であり、「健闘の末に
  惜しくも敗れた」という中立的な事実を簡潔に伝えるにとどめる。悲劇性を強調する
  演出・追加のスライド展開はしないこと
- **スライド22は敗者を主題化しない方針を明示するスライド**であり、削除しないこと。
  有明の初出場・熊本地震復興文脈(別テーマ212本目で既に扱っている)を再掲・
  持ち込まないこと
- **スライド24・25は確認できていないこと(準決勝の日程・対戦相手、石垣投手の大会
  通算投球回数)を示すスライド**であり、具体的な数字や詳細を創作して埋めないこと
- 実在選手名(石垣選手・石田選手・藤村選手など)はテキストとしてのみ扱い、写真・
  肖像・実在団体のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない。政治的な話題にも触れていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`navy_gold`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
