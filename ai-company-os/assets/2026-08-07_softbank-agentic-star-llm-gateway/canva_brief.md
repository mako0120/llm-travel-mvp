## メタ情報

- デッキ名: 「社員がこっそり使っていたAIコーディングツールが、会社に丸見えになる時代へ」(149本目)
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 企業のAI活用・AIガバナンスに関心がある一般視聴者、情報システム部門・
  エンジニア。専門知識がない前提で、「AIコーディングツール」「AGENTIC STAR」「LLM Gateway」
  といった用語を分解して説明するスライドを設けている
- パレット(HEX、indigo_cyanプリセット): Primary `#2E2A72` / Base `#D6D9F5` / Accent `#17C3B2`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(ソフトバンクの公式ロゴ・商標は使用しない、
  図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3〜4枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` / `quote` は含まれない
  (推移データ・構成比データが確認できず、実在人物への直接取材コメントも
  確認できなかったため使用していない)。

## このデッキ固有の注意

- **スライド21は「確認できなかったこと」の一覧**であり、削除しないこと(対応ツール名・
  利用企業数・価格・展開完了時期を非公開として明示している)
- **スライド22・23は当社の推測**であることを本文に明記している。断定形や公式ロード
  マップのように書き換えないこと
- **スライド24・25・26は誇張回避・特定製品推奨回避・「監視ではなくガバナンス」についての
  注記**である。タイトル・冒頭フックは注目を集める表現を使っているが、本文の内容は
  誇張しておらず、ソフトバンク製品の利用を強く推奨してもいない旨を明示しているため、
  これらの注記スライドは保持すること
- **スライド26は『監視』と『ガバナンス』の違いを整理する回**である。本発表から断定できない
  内容(従業員個人の評価・査定への利用等)を、断定できる内容であるかのように書き換えないこと
- 実在企業名(ソフトバンク)はテキストとしてのみ扱い、ロゴ・商標は使用しない
- 特定企業・製品の利用を強く推奨する結論にはしていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`indigo_cyan`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
