# 「社員がこっそり使っていたAIコーディングツールが、会社に丸見えになる時代へ」(2026-08-07・149本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール)+ AI対話ナレーション・スライド連動モードで制作。

## 選定理由

- 対象ジャンル「AI/エージェント系」枠、企業のAIガバナンス・コンプライアンスへの関心が
  高まる中でのタイムリーな機能追加
- オーナー指定テーマ(149本目)として制作を開始
- 2026年8月7日(金)、AI Watch(Impress)が「ソフトバンクが法人向けAIエージェント基盤
  『AGENTIC STAR』のSaaS版に『LLM Gateway』機能を標準搭載する」と発表。着手日
  (2026年8月9日)から見て2日前の発表であり、`docs/06_Content_R&D.md`の鮮度基準
  (着手日を含めて2日以内)を満たす
- ロボスタ(Robot Start)・BUSINESS NETWORKという独立した複数のメディアが同内容を
  裏付けている
- 「社員が個人的に使っているAIコーディングツールの利用実態が、会社から見えるように
  なる」という誰にとっても身近な切り口と、企業のAIガバナンスへの関心の高まりが重なり、
  話題性が高い

## 既存テーマとの関係(重複でないことの確認)

`ai-company-os/assets/`配下を検索した結果、AGENTIC STAR・LLM Gatewayを扱った既存
テーマは存在しない(重複確認済み)。既存のソフトバンク関連テーマ
(`2026-07-21_softbank-sierra-case-study`・`2026-07-26_softbank-patching-as-a-service`・
`2026-08-03_seven-i-softbank-paypay-capital-alliance`)はいずれも別のSoftBankトピック
(Sierraとの協業事例、パッチ適用サービス、セブン&アイ・PayPayとの資本業務提携)であり、
主題は重複しない。

## 本テーマ特有の扱い: タイトル表現と「監視ではなくガバナンス」の両立

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)のみを
通常より強めにしてよいこととされている。この指示は正確さ・出典・正直さの
ルールを緩めるものではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「社員がこっそり使っていたAIコーディングツールが、会社に丸見えになる時代へ」という身近な意外性を強調する表現 | オーナー指示により通常より強めの表現を許容し採用 |
| 機能の性質 | 本発表はAIコーディングツールの利用実態を企業が把握・管理できるようにする機能 | 「社員監視」という煽り文句には言い換えず、専用スライド(24・25・26)で正当な企業ガバナンス・コンプライアンス機能であることを明示 |
| 自社製品の扱い | ソフトバンク自身の製品発表である | 特定企業・製品の利用を強く推奨する結論にはせず、専用スライド(25)で明示 |
| 非公開・未確認の情報 | 対応AIコーディングツールの具体名、利用企業数、価格・費用体系、展開完了時期 | 「確認できなかったこと」として一覧化(スライド21) |

締めのスライド30では「『監視』ではなく『ガバナンス』。その線引きを、正確に伝えたい」ことを提示している。

## 適用したルール

- 30枚デッキ、bullets比率30.0%(9/30枚、40%上限クリア)、同一レイアウト連続は最大2
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用)
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_statで図解化
  (数値の推移データが限られるため`bar_chart`ではなく`table`・`big_stat`で扱った。
  実在人物への直接取材コメントが確認できなかったため`quote`は使用していない)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「社員がこっそり使っていたAI
  コーディングツール」「会社に丸見え」という固有名詞・具体的な構図を即座に提示し、
  挨拶・前置きを省いた
- 初心者向け前提知識スライド(「AIコーディングツール」「AGENTIC STAR」「LLM Gateway」の
  用語解説、構成の概念図) + 実践的な整理(「これは企業/従業員にとって何を意味するか」、
  スライド19・20)
- **事実・推測・不明を明確に区別**: 発表日・機能内容という事実と、今後の展開・論点
  という当社の推測(スライド22・23)、非公開項目という不明(スライド21)を分けて扱った
- **『監視』と『ガバナンス』の混同回避**: 本機能を「社員を監視する機能」と単純化せず、
  専用スライド(26)で公表内容と断定できない内容を明示的に区別した
- **特定製品推奨の回避**: 本テーマがソフトバンク自社製品の発表であることを認めた上で、
  利用を強く推奨する結論にはしていない旨を専用スライド(25)で明示した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 実在企業名(ソフトバンク)はテキストとしてのみ扱い、ロゴ・商標・肖像は使用していない

## リスク配慮

- 対応AIコーディングツールの具体名、利用企業数、価格・費用体系、既存顧客への展開完了時期が非公開・未確認である旨を明示する
- 本機能を「社員を監視するだけの機能」と単純化せず、正当な企業ガバナンス・コンプライアンス機能であることを明示する
- 本テーマがソフトバンク自社製品の発表であることを認めた上で、特定企業・製品の利用を強く推奨する結論にはしていない
- 想定される今後の展開・論点はいずれも当社の推測であり、断定ではない旨を明示する
- タイトル・冒頭フックの表現が通常より強めであることと、本文が誇張していないことの両方を専用スライドで明示している
- 実在企業名(ソフトバンク)はテキストとしてのみ扱い、ロゴ・商標・肖像は使用しない
- 今回のLLM Gateway機能そのものについてのソフトバンク公式プレスリリース(一次情報)は検索で発見できず、AI Watch等の報道メディア経由の確認にとどまっている旨を明示する

## 注意

- 本セッションのネットワーク制約(プロキシによるegressブロック)により、AI Watch
  記事本文への直接アクセス(`WebFetch`)を試みたところ`EGRESS_BLOCKED`となり、
  WebSearchの検索結果要約を通じた確認に留まった旨を`research.md`と

  いるため、内容の信頼性は相互に裏付けられている
- 対応AIコーディングツールの具体名、利用企業数、価格、展開完了時期は「非公表」以上の
  情報が確認できておらず、その旨をスライド21に明記した
- 公開・投稿はまだ行っていない
