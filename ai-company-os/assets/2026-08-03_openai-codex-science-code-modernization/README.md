## 見出し表現の方針変更・AIの限界についての正直な開示

本テーマもオーナー指示により、見出し・タイトルの表現を「バズる人気」
優先の煽り気味な表現にしている(例: 「誰も触りたがらなかった『死んだ
コード』を、AIが書き換えた」)。**ただし、数字の創作・出典のない断定・
特定企業の過度な推奨・政治的中立性の逸脱・著作権侵害は、これまでどおり
一切行っていない。** また、OpenAI自身が報告している「科学的な正しさは
AIには判断できない」「ボトルネックがレビューに移った」という限界を、
成果と同じ比重で専用スライド(13・14・15)にて開示している。本報告が
OpenAI自身の一次報告であり、成果を強調するバイアスの可能性がある点も
research.mdに明記している。

## 適用したルール

- 30枚デッキ、bullets比率20%(40%上限クリア)、同一レイアウト連続なし
- **コールドオープン(バズ路線)**: 冒頭(1枚目・ナレーション1行目)で
  「誰も触りたがらなかった、20年ものの『死んだコード』。AIエージェントは、
  それを書き換えた──ただし、正しさまでは判断できなかった」という
  煽り気味だが事実に基づく一文を即座に提示
- 初心者向け前提知識スライド(RNA配列解析・ゲノムアライナーの解説) +
  実践的な整理(研究機関が確認すべきこと)
- **鮮度の妥協を正直に開示**: 発表日が着手日の6日前であり、70本目・71本目
  より後退していることをスライド16で正面から扱う
- **AIの限界を成果と同じ比重で開示**: 「科学的な正しさはAIには判断できない」
  という限界をスライド13・14・15で明確に扱う
- **一次報告のバイアスの可能性を明示**: OpenAI自身の報告である点を
  research.mdで開示
- 特定企業・製品の利用を強く推奨する結論にはしていない
- 前サイクルとの接続スライドは設けていない(70本目・72本目との比較・
  関連整理スライドのみ)
