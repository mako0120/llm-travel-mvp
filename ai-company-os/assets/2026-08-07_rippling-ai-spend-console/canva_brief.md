## メタ情報

- デッキ名: 「R&D予算の40%がAIトークン代に消えた会社が、社員のAI利用を丸ごと可視化するツールを作った」(152本目)
- 元になる PowerPoint / 構成 Markdown: `deck_spec.json` / `deck.pptx`(30枚)
- 目的・想定視聴者: 企業のAI活用・AIコスト管理に関心がある一般視聴者、AI/エージェント系
  ニュースを継続して追っている視聴者(既存の「tokenmaxxing」系3テーマの視聴者を含む)。
  専門知識がない前提で、AIトークン課金の仕組みから説明するスライドを設けている
- パレット(HEX、cobalt_violetプリセット): Primary `#1B3A5C` / Base `#DCE6F5` / Accent `#7B4FFF`
- フォント指定(Canva 代替): 見出し・本文ともに Noto Sans JP(pptx版は既定フォント Yu Gothic)
- アニメーション: なし
- 使用素材のライセンス確認: 無料素材のみ(Rippling・Anthropic等の公式ロゴ・商標は使用しない、
  図形・アイコンはCanva内蔵の無料素材のみを使う)

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(2〜3枚、ラベル+短文、影付き) |
| big_stat | 1数字強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ |
| steps | 横並びステップカード+シェブロン矢印 |
| table | 表(ヘッダー行+データ行) |
| comparison | 2カラム比較(左右カード+リスト) |
| quote | 大見出し引用+出典クレジット |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `bar_chart` / `line_chart` / `pie_chart` は含まれない(支出の正確な総額・
  時系列の推移データが公表されておらず、確認できない数値をグラフ化しないため)。引用は
  `quote`レイアウト(スライド16)でAdam Swiecicki氏の発言をそのまま扱う。

## このデッキ固有の注意

- **スライド4・25は鮮度基準の例外採用(発表から3日前)を明示する回**である。削除・簡略化
  せず、探索を尽くしても2日以内の候補が見つからなかった旨を保持すること
- **スライド11は「10〜15%の社員が60%」「月5万ドル超」という数字がRippling社内調査の
  自己申告に基づくもの**であることを前提に扱う。第三者検証済みの数字であるかのように
  書き換えないこと
- **スライド17の導入効果(40%→約15%、7月支出が4月比37%)はRippling自身の発表**であり、
  第三者による検証結果ではない旨を保持すること
- **スライド19・20は既存3つの「tokenmaxxing」系テーマ(127本目Weave・142本目Microsoft・
  150本目Uber)との関係を整理する回**である。4件目のテーマであることを隠さず、主体・
  立場の違いを明示する内容のため、削除・簡略化しないこと
- **スライド21は「確認できなかったこと」の一覧**であり、削除しないこと(正確な支出総額・
  算出期間の詳細・機能の全容・業界全体への波及を非公開として明示している)
- **スライド25は誇張回避・鮮度例外・特定企業推奨回避についての注記**である。タイトル・
  冒頭フックは注目を集める表現を使っているが、本文の内容は誇張しておらず、Rippling等の
  利用を強く推奨していない旨を明示しているため、この注記スライドは保持すること
- **スライド26は当社の推測であることを明記したカード**である。断定形や公式見通しの
  ように書き換えないこと
- 実在企業名(Rippling、Anthropic等)・実在人物名(Adam Swiecicki氏)はテキストとしてのみ
  扱い、ロゴ・商標・肖像は使用しない
- Adam Swiecicki氏の引用(スライド16)は複数の独立メディアで文言が一致していることを
  確認したものであり、要約による意味の変質を避けるため原文をそのまま使うこと

## 移植手順(人間向け)

   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
