# 「R&D予算の40%がAIトークン代に消えた会社が、社員のAI利用を丸ごと可視化するツールを作った」(2026-08-07・152本目)

生成方式A(30枚・エンゲージメント設計ルール・初心者配慮ルール・文字を減らし図解で
伝えるルール・コールドオープンルール、バズ路線見出し方針)+ AI対話ナレーション・
スライド連動モードで制作。

## 選定理由

- 2026年8月7日、TechCrunchがHR/給与計算SaaS大手Ripplingの内部事情を報じた。「After
  Rippling blew millions on AI in months, it built an employee ROI tool」という記事で、
  同社が2026年3月、AIトークン支出がR&D部門の人件費予算の40%に達する軌道にあると
  経営陣に報告された経緯と、その後開発した社員別ROI可視化ツール「AI Spend Console」
  を紹介している
- `ai-company-os/research/2026-08-10_theme-evaluation-round90.md`(2026年8月10日実施)の
  「候補2(152本目)」として、バズ路線スコア80/100で採用
- **鮮度基準の例外採用であることを、正直に明記する。** 発表日(2026-08-07)から着手日
  (2026-08-10)まで**3日**が経過しており、`docs/06_Content_R&D.md`の鮮度基準
  (2026-08-05追記: 着手日を含めて2日以内を必須とする)を**満たしていない**。round90
  評価表に記録の通り、AIエージェント資金調達・AI企業の新規発表・日本人選手の記録/移籍・
  AI企業の予算/コスト動向・ゲーム業界のAI活用など複数の切り口で着手日から2日以内
  (8/8〜8/10発表)の候補を探索したが、2026-08-10未明(UTC)時点では着手日当日分の
  ニュースがまだ十分にインデックスされておらず、探索を尽くしてもなお2日以内の候補が
  1本も見つからなかった。`docs/06_Content_R&D.md`が定める「探索を尽くしてもなお2日以内の
  候補が1本も見つからない場合に限り、次点として最も新しい候補を暫定的に採用してよいが、
  これは例外的な最終手段であり常態化させない」という規定に基づき、本テーマ(発表から
  3日前)を鮮度基準の例外として採用した。この妥協は常態化させず、次回以降のラウンドでは
  改めて2日以内の基準を優先して探索する
- TechCrunchに加え、Rippling公式ブログ・製品ページ、stockpil・bitcoinworld・Pebblous・
  techrseries・TechBuzz.ai・01net・Startup Fortuneという独立した複数のメディアが同内容
  (具体的な数字・CFOの発言を含む)を報じている
- 具体的な数字(R&D人件費予算の40%、月次80%増、10〜15%の社員が支出の60%、月5万ドル超、
  導入後は40%→約15%に削減)が豊富で、検証可能性が高い点、そして「危機を可視化ツールの
  自社開発・外販という形で解決した」という展開の具体性が採用理由

## 本テーマ特有の扱い: バズる見出しと、自己申告データ・鮮度例外の慎重な扱い

オーナー指示により、本ラウンドは見出し・冒頭フックの表現(バズる路線)を通常より
強めにしてよいこととされている。この指示は正確さ・出典・正直さのルールを緩めるもの
ではないため、以下の対応を行った。

| 区分 | 内容 | 扱い |
|---|---|---|
| 見出し・冒頭フック | 「R&D予算の40%がAIトークン代に消えていた」という報道された事実に基づく数字を強調する表現 | オーナー指示により通常より強めの表現を許容しつつ、報道内容に忠実な表現にとどめた(創作なし) |
| 「消えていた」という表現 | 予算全体が失われたかのような誤解を招く余地がある | 本文・スピーカーノートでは一貫して「相当する金額」という正確な言い回しを併用し、専用スライド(25)で誇張していないことを明示 |
| 「10〜15%の社員が60%」「月5万ドル超」「導入後40%→約15%」等の数字 | Rippling社内調査・自社発表に基づく | 第三者検証済みであるかのように書かず、Rippling自身の発表・自己申告である旨をスライド11・17・18で明示 |
| 鮮度(発表から3日前) | 通常の鮮度基準(2日以内)を満たさない | スライド4・25、README、research.mdで例外採用であることを一貫して正直に開示 |
| 正確な支出総額・算出期間の詳細・機能の全容 | 未公表・未確認 | 「確認できなかったこと」として一覧化(スライド21) |

締めのスライド30では「『いくら使ったか』ではなく、『何が生まれたか』」というCFOの発言の
思想を提示している。

## 適用したルール

- 30枚デッキ、bullets比率26.7%(8/30枚、40%上限クリア)、同一レイアウト連続なし
  (`docs/04_PowerPoint.md`が定める上限「3連続まで許容」よりさらに厳格に運用、最大2連続)
- 文字中心の説明はtable/diagram/comparison/steps/cards/big_stat/quoteで図解・引用化
  (支出の正確な総額・時系列の推移データが公表されていないため`bar_chart`/`line_chart`/
  `pie_chart`は使用せず、CFOの直接引用が確認できた`quote`を1箇所で使用した)
- **コールドオープン**: 冒頭(1枚目・対話1行目)で「R&D予算の40%がAIトークン代に消えて
  たらしいよ」という固有名詞・具体的な数字を即座に提示し、挨拶・前置きを省いた
- 初心者向け前提知識スライド(「AIトークン支出」「Rippling社」の用語解説、スライド10)
  + 実践的な整理(「これは企業/エンジニア個人にとって何を意味するか」、スライド22・23・24)
- **事実・推測・不明を明確に区別**: 報道された数字・CFOの発言という事実と、今後の展開・
  論点という当社の推測(スライド26・27)、機能の全容・正確な総額という不明(スライド21)を
  分けて扱った
- **自己申告データの明示**: 「10〜15%の社員が60%」「月5万ドル超」「導入後40%→約15%」
  という数字がRippling社内調査・自社発表に基づくものであり、第三者検証が確認できていない
  ことをスライド11・17・18で明示した
- **鮮度基準の例外採用の正直な開示**: 発表から着手日まで3日、通常の鮮度基準(2日以内)を
  満たさないことをスライド4・25で明示し、探索を尽くしても2日以内の候補が見つからなかった
  という経緯を具体的に記載した
- **同一問題領域を扱う4件目であることの正直な開示**: 既存3テーマ(Weave・Microsoft・
  Uber)との関係を専用スライド(19・20)で明示し、重複ではなく対応の具体性が異なることを
  説明した
- 出典のない数字は作らず、確認できなかったことは正直に「不明」と明記した
- 実在企業名(Rippling、Anthropic等)・実在人物名(Adam Swiecicki氏)はテキストとしてのみ
  扱い、ロゴ・商標・肖像は使用していない
