  丁寧に分解して説明するスライドを設けている。未成年の選手が主役であること、敗れた

## レイアウト種別 → Canva要素の対応(スライド全体で共通)

| pptx側レイアウト | Canva要素 |
|---|---|
| title | タイトルスライド(大見出し+サブコピー+出典フッター) |
| agenda | 見出し+丸数字バッジ付きリスト(ダーク背景) |
| bullets | 見出し+ブレットリスト(最大5項目) |
| cards | カードグリッド(3枚、ラベル+短文、影付き) |
| big_stat | 1数字(または短いキーフレーズ)強調レイアウト(ダーク背景、中央に巨大テキスト) |
| diagram | ノード(角丸ボックス)+矢印コネクタ(3ノード) |
| steps | 横並びステップカード+シェブロン矢印(5ステップ) |
| comparison | 2カラム比較(左右カード+リスト) |
| table | 表(ヘッダー行+データ行) |
| bar_chart | 縦棒グラフ(Canva内蔵チャート要素) |
| cta | CTAスライド(大見出し+サブ+アクション文、ダーク背景) |

※ このデッキに `pie_chart` / `line_chart` / `quote` は含まれない(構成比を示す
データや、確認済みの選手コメントがないため。最終スコアの比較はbar_chartで扱っている)。

## このデッキ固有の注意(未成年配慮と花巻東への配慮が最重要)

- **スライド1・2は本テーマのコールドオープン**であり、「まさかの18年ぶり」
  というフックを提示しつつ、直後に正確な結果を添えている。フック性の強い表現は
  許容するが、花巻東の敗戦を煽り立てる方向に書き換えないこと
- **スライド11〜15は織田投手の投球データ(9回7安打10奪三振無失点・最速155〜156キロ
  計7球・直球平均152.5キロ)を扱う核心スライド**であり、確認できた数字を超えて
  内訳(155キロ・156キロそれぞれの本数等)を創作・追加しないこと
- **スライド17・18は花巻東の投手・打撃内容、次戦の対戦相手・日程について確認できて
  いないことを示すスライド**であり、具体的な氏名や経緯を創作して埋めないこと
- **スライド22は花巻東への配慮方針を扱うスライド**であり、削除しないこと。敗因を
  過度に貶める表現を追加しないこと
- **スライド23は未成年選手への配慮方針を扱うスライド**であり、削除しないこと。
  選手の私生活・容姿等に関する記述を追加しないこと
- **スライド26・27・28は確認できていないこと(花巻東の詳細・次戦の対戦相手・日程)を
  示すスライド**であり、具体的な数字や詳細を創作して埋めないこと
- 実在選手名(織田選手・江坂選手・安食選手など)はテキストとしてのみ扱い、写真・肖像・
  実在団体のロゴ・商標は使用しない
- 特定企業・製品・団体の宣伝にはしていない。政治的な話題にも触れていない

## 移植手順(人間向け)

1. Canva で 16:9 プレゼンテーションを新規作成
2. ブランドカラーに上記 HEX(`steel_amber`プリセット)を登録
3. 各スライドのレイアウト種別ごとに「レイアウト種別 → Canva要素の対応」表の
   要素を使い、`deck_spec.json`の該当スライドから見出し・本文・出典テキストを
   そのままコピーする
4. 完成後、PowerPoint 版と並べて構成・数字の一致を確認
