## 採用した2候補

### 候補1(139本目): Rustプログラミング言語、コア開発でのLLM利用に関する公式ポリシーを採択

- 発表日: **2026年8月5日**(着手日当日、最高水準の鮮度)
- 出典: Rust公式ブログ「Inside Rust Blog」(2026-08-05)「rust-lang/rust is
  adopting an LLM policy」、Linuxiac、Socket.dev、rust-lang/rust-forge
  リポジトリのPull Request #1040
- 概要: rust-lang/rustリポジトリの5つのチームが、コア開発でLLM(大規模言語
  モデル)をどう使ってよいかを定めた公式ポリシーを採択した。質問への回答・
  コード分析・要約・非公開レビュー・改善案の提案には利用を認める一方、
  個人アカウントからのコメント・Issue本文・PR説明文がLLM生成であること、
  非自明なソースコメント・ドキュメントコメント・安全性コメント・複数段落の
  コメント・コンパイラの診断メッセージをLLMで生成することは禁止。LLMによる
  レビューはあくまで参考情報に留め、マージ可否の判断には使えない。方針の
  核心は「LLMは(人間の)理解・著作・レビューを代替するのではなく、より
  良く書くために使う」というもの
- 採用理由(スコア78/100): 「大規模開発プロジェクトがAIにコードを書かせない
  と宣言した」という開発者コミュニティで大きな話題となっている意外性のある
  フック、着手日当日という最高水準の鮮度がバズ路線と親和する

### 候補2(140本目): SK hynix・SanDisk、AI推論向け新メモリ規格「HBF」の標準仕様を発表

- 発表日: **2026年8月3日**(着手日の2日前、鮮度基準を満たす)
- 出典: SanDisk公式プレスリリース(2026-08-03)、SK hynix Newsroom、
  HPCwire、PR Newswire
- 概要: SK hynixとSanDiskが、Open Compute Project(OCP)を通じてAI推論
  ワークロード向けの新メモリ規格「HBF(High Bandwidth Flash)」の初の
  技術仕様を発表した。HBFは既存のHBM(高帯域幅メモリ)とSSDの間に位置する
  新しいメモリ層で、8層または16層のNANDダイスタックにより最大512GBの
  容量、約0.4TB/s〜3.0TB/sの3段階の帯域幅クラスをサポートする。UCIe
  (Universal Chiplet Interconnect Express)規格を採用し、GPU・CPUなど
  異種プロセッサとのオープンなチップレット接続を可能にする。米カリフォルニア
  州で開催中のFlash Memory Summit 2026(8月4〜6日)で発表された
- 採用理由(スコア72/100): 「AIチップのボトルネックを解消する新メモリ層」
  という具体的で分かりやすいフック、業界標準化団体を通じた発表という
  信頼性の高さ、着手日の2日前という鮮度基準ぎりぎりながら満たしている点を
  評価した
